## 先记住这几句话

1. 报告想解释一个"悖论"：骨丢失和血管钙化方向相反，却常常出现在同一批人身上。它的假说是：CHIP 突变的髓系细胞，在骨髓里和血管壁里开启了同一套"破骨样"程序，只是后果相反。
2. 要验证这个假说，需要三类证据：遗传学证据（两种表型是否共享遗传基础、是否共享同一个变异）、单细胞证据（风险是否富集在髓系细胞、两个组织的程序是否重叠）、队列证据（CHIP 携带者里骨和血管结局是否一起出现）。
3. 每一类证据都有一个常见的坑：遗传相关会被"正负抵消"掩盖；共定位会被"多个因果变异"骗；单细胞分析会把细胞当成独立样本；队列分析会被年龄混杂。本讲义每章先讲这个坑。
4. 纯计算只能做到"程序层面的比对"，要证明因果，报告自己也说小鼠实验不可省。本讲义不讲实验。

## 0. 术语速查（先扫一眼，看不懂再回来查）

| 术语 | 一句话解释 |
|---|---|
| CH、CHIP | 克隆性造血：造血干细胞带上体细胞突变并扩增成克隆。CHIP 指没有血液肿瘤的那一类，常用阈值是 VAF 不低于 2% |
| DNMT3A、TET2、ASXL1 | 最常见的三个 CHIP 驱动基因 |
| VAF | 变异等位基因比例：支持突变的读段数 ÷ 总读段数 |
| 大克隆、小克隆 | 报告里用 VAF 不低于 0.1 区分大克隆和小克隆 |
| BMD、eBMD、DXA | 骨密度；eBMD 是跟骨超声估计的骨密度；DXA 是双能 X 线测的骨密度 |
| CAC、AAC | 冠状动脉钙化、腹主动脉钙化 |
| 汇总统计 | GWAS 公开的结果表，每个 SNP 一行：beta、SE、p 等（详见 MR 讲义第 5 章） |
| z 分数 | beta ÷ SE。z 的平方是 χ² 统计量 |
| LD、LD 分数 | 相邻 SNP 一起遗传；LD 分数是一个 SNP 与周围 SNP 的 r² 之和，衡量它"代表"了多少邻居 |
| 遗传度 h² | 性状的方差中，由 SNP 的加性效应解释的比例 |
| 遗传协方差、遗传相关 rg | 两个性状的遗传效应一起变化的程度；rg 是把它按两个遗传度标准化后的相关系数 |
| 全局、局部遗传相关 | 全局：整个基因组合起来；局部：某一小段基因组 |
| 有效样本量 | 病例对照研究换算成"相当于多少个均衡样本"：4 ÷ (1/病例 + 1/对照) |
| 共定位 | 判断两个性状在同一区域的信号，是否来自同一个因果变异 |
| PP.H0 到 PP.H4 | 共定位的五个假设的后验概率 |
| 可信集 | 一小撮 SNP，包含因果变异的概率不低于某个值（如 95%） |
| 计数矩阵 | 单细胞数据：行是细胞，列是基因，格子里是读到的分子数 |
| 伪重复 | 把同一个供体的很多细胞当成互相独立的重复，导致假阳性大量出现 |
| 伪批量 | 先把同一个供体的细胞汇总，再在供体层面做比较 |
| MAGMA | 把 SNP 水平的 GWAS 信号合并成基因水平分数的工具 |
| scDRS | 给每个单细胞打一个"疾病相关分数"的方法 |
| 基因程序、程序评分 | 一组一起升降的基因；程序评分是每个细胞里这组基因的"活跃程度" |
| GRN | 基因调控网络：谁调控谁 |
| 虚拟扰动 | 用计算模型预测基因被敲除或抑制后，细胞状态会怎样变化 |
| 线性基线 | 一个简单的线性预测，作为对照；复杂模型必须打赢它才算有价值 |
| 配体活性 | NicheNet 的输出：哪个配体最能解释受体细胞里观察到的基因变化 |
| 观察/期望比（O/E） | 共病分析：观察到的同时出现次数 ÷ 假设两件事独立时的期望次数 |
| Go/No-Go | 预实验结束时"继续还是放弃"的判定点 |

## 1. ★ 这份报告在做什么：问题、假说和技术地图

> 这一章带走什么：报告的核心问题和假说是什么；三阶段分析链各用了哪些技术；这些技术各自能回答什么、不能回答什么。

### 1.1 问题和假说

**观察。** 临床上，骨密度低的人，血管钙化往往反而更多，这叫"钙化悖论"。它很容易让人想到"钙从骨里流失，又沉积到血管里"，于是猜"骨丢失导致血管钙化"。

**一个负面结果。** 报告引用的文献说，用 MR 检验"骨密度 → 冠状动脉钙化"，两次都是阴性。也就是说，两者看起来不是因果关系。

**报告的假说。** 既然不是因果，那就是同一个上游的两个并行后果。衰老相关的克隆性造血（CHIP）使髓系细胞获得一套共同的"破骨样、促钙化"分泌程序：

- 在骨髓里，这套程序表现为破骨增强、骨丢失；
- 在血管壁里，这套程序表现为基质降解和代偿性钙化。

这个假说有一个好处：**可以证伪**。如果两个组织里的程序不重叠，假说就错了，而这本身也是一个可发表的结果。

### 1.2 三阶段分析链

下表是报告推荐的分析链（MR 的部分略去，另有讲义）。

| 阶段 | 步骤 | 技术 | 数据 | 本讲义 |
|---|---|---|---|---|
| 第一阶段（4–6 周，零成本） | 遗传相关 | LDSC、HDL | 公开 GWAS 汇总统计 | 第 3 章 |

| | 共定位 | coloc、SuSiE-coloc | 同上 | 第 5 章 |
| | 风险细胞定位 | scDRS、scPagwas | 汇总统计 + 单细胞图谱 | 第 7 章 |
| | 程序评分与比对 | 基因集评分 | CHIP 外周血、斑块、骨髓单细胞数据 | 第 8 章 |
| 第二阶段（3–6 个月） | 个体级分层分析、共病分析 | 回归、Cox 模型 | UK Biobank Tier 1 | 第 10 章 |

### 1.3 每类证据能回答什么、不能回答什么

| 证据 | 能回答 | 不能回答 |
|---|---|---|
| 遗传相关、局部相关 | 两种表型是否共享遗传基础 | 共享的是不是同一个变异；是不是因果 |
| 共定位 | 某个区域里两个信号是否来自同一个变异 | 这个变异通过哪个基因、哪类细胞起作用 |
| 风险细胞定位（scDRS） | 遗传风险偏向哪类细胞 | 这类细胞里的哪个通路在起作用 |
| 程序评分与比对 | 两个组织里是否出现同一套基因程序 | 程序是原因还是结果 |
| 个体级队列分析 | CHIP 携带者里骨和血管结局是否一起出现 | 为什么一起出现 |
| 虚拟扰动 | 计算上抑制某个节点，程序会怎样变 | 真实生物学里会不会这样（要实验验证） |

报告自己指出了最关键的一个缺口：**没有任何公开数据集同时具备"人骨组织或骨髓 + CHIP 基因型"**。所以纯计算路径只能做到"程序层面的跨组织比对"，要做到因果，小鼠骨髓移植实验不可省。

### 1.4 立项规则：三取二

报告在第 6 周设了 Go/No-Go 判定点，以下三条满足两条则立项：

1. CHIP（或其任一亚型）与 eBMD、AAC、CAC 中至少两个表型存在显著的局部遗传相关或共定位信号；
2. scDRS 显示至少一个钙化相关 GWAS 的风险富集在髓系细胞上；
3. 破骨样程序评分在 CHIP 携带者单核细胞与钙化斑块巨噬细胞中同方向升高。

三条全部不满足，就不花 UK Biobank 的钱。第 12 章会用几行 R 算一算这条规则的统计性质。

### 1.5 读报告时要留意的三处

这三处是我在核对时发现的，详见第 11 章：

1. 报告里的"HDL"指 **High-Definition Likelihood**（高清似然法），不是高密度脂蛋白胆固醇。
2. 报告把 CHIP 汇总统计（GCST90102618 到 622）的出处写成"Kessler 等，Nat Genet 2022"。GWAS Catalog 的元数据显示，这批数据来自 **Kar 等的 Nat Genet 2022**（PMID 35835912）。Kessler 等的那篇是 Nature 2022 的另一项工作。
3. 报告说"版本 B（ASXL1）遗传学层会缺一块"。但 2025 年那套多表型 CH GWAS（PMID 39948438，编号 GCST90435341 到 376）里**有 ASXL1**（GCST90435344、356、368）。

### 小结

- 报告的假说是"同一套破骨样程序在骨和血管里的并行后果"，它可以被证伪。
- 技术分三层：遗传学、单细胞、队列；每层有自己的坑。
- 纯计算做不到因果，只能做程序层面的比对。

## 2. ★ CHIP 与 VAF：数据从哪来

> 这一章带走什么：CHIP 是什么；VAF 怎么换算成"克隆有多大"；测序深度怎样决定你能不能看见小克隆；为什么单细胞数据里"带突变的细胞"很少。

### 2.1 CHIP 是什么

造血干细胞在人的一生中会积累体细胞突变。偶尔某个突变让这个干细胞获得生长优势，它的后代就会占据血细胞的一部分，形成一个"克隆"。如果这个人没有血液肿瘤，这种状态叫 CHIP。

三件事要记住：

- 发生率随年龄明显上升；
- 最常见的驱动基因是 DNMT3A、TET2、ASXL1；
- 克隆越大，对心血管等结局的影响通常越明显（报告提到已有研究显示大克隆的心血管风险更高，但这一分层在骨这一侧还没有人做过）。

### 2.2 VAF 怎么读

VAF = 支持突变的读段数 ÷ 覆盖该位点的总读段数。

对常染色体上的杂合突变，每个带突变的细胞只有一半的拷贝是突变的，所以：

```text
带突变的细胞比例 = 2 × VAF
```

```r
# 常染色体上的杂合体细胞突变：VAF 约等于“带突变的细胞比例”的一半
vaf <- c(0.02, 0.05, 0.10, 0.20)
data.frame(VAF = vaf, 带突变的细胞比例 = 2 * vaf)
```

```text
   VAF 带突变的细胞比例
1 0.02             0.04
2 0.05             0.10
3 0.10             0.20
4 0.20             0.40
```

所以报告里的"大克隆（VAF 不低于 0.1）"，意思是至少约 20% 的血细胞带这个突变。

### 2.3 VAF 的不确定性

VAF 是读段数的比例，读段数有限，所以有误差。例：100 条读段里有 12 条支持突变。

```r
alt <- 12; depth <- 100
c(VAF = alt / depth)
round(as.numeric(binom.test(alt, depth)$conf.int), 3)      # 精确二项 95% 区间
```

```text
 VAF 
0.12 
[1] 0.064 0.200
```

VAF = 0.12，精确二项 95% 区间是 0.064 到 0.200。单个样本的 VAF 在深度只有 100 左右时误差不小，所以按 VAF 是否不低于 0.1 来分大小克隆时，靠近 0.1 的样本分类本身就不稳。

### 2.4 能不能看见小克隆：测序深度

一个突变要被"检出"，通常要求至少有几条支持读段。下面假设至少 4 条（真实流程的阈值以原文为准）。

```r
# 假设：至少 4 条支持突变的读段才算检出（真实流程的阈值以原文为准）
detect_prob <- function(vaf, depth, k = 4) 1 - pbinom(k - 1, depth, vaf)
vafs <- c(0.01, 0.02, 0.05, 0.10)
depths <- c(30, 60, 100, 200)
tab <- outer(vafs, depths, detect_prob)
dimnames(tab) <- list(paste0("VAF=", vafs), paste0("深度", depths, "x"))
round(tab, 3)
```

```text
         深度30x 深度60x 深度100x 深度200x
VAF=0.01   0.000   0.003    0.018    0.142
VAF=0.02   0.003   0.032    0.141    0.569
VAF=0.05   0.061   0.353    0.742    0.991
VAF=0.1    0.353   0.863    0.992    1.000
```

读法：

- 深度 30x 时，VAF = 0.05 的克隆只有 6% 的机会被检出，VAF = 0.1 也只有 35%。
- 深度 100x 时，VAF = 0.05 约 74%，VAF = 0.02 只有 14%。
- 也就是说，**外显子测序对小克隆不敏感**，所谓"小克隆"在数据里是被截尾的。这也是为什么 CHIP 研究都有一个 VAF 下限（常用 2%），以及为什么"携带者 vs 非携带者"里的"非携带者"其实混着一些没被看见的小克隆携带者。

### 2.5 从外显子"调用"CHIP 的流程（概念）

报告说，UK Biobank 已在 2025 年 8 月发布了 CHIP 衍生字段（30106 是变异，30107 是 VAF），所以不需要自己调用。了解流程有助于理解这些字段的含义：

1. 用体细胞突变检出工具（如 Mutect2）在外显子数据上检出突变；
2. 只保留一份已知造血驱动基因清单里的位点；
3. 按读段数、深度、已知热点、人群频率等过滤，排除胚系变异；
4. 保留 VAF 不低于阈值的突变，记录基因和 VAF。

报告说这套流程按 Vlasschaert 等 2023 年发表在 Blood 上的方法整理。具体阈值和基因清单以原文为准。

### 2.6 单细胞数据里的"突变细胞"为什么很少

假设每个供体取 2,800 个细胞（报告里 CNGB TrueBlood 数据约 6.7 万细胞、24 个供体，平均约 2,800）。要在单个细胞的读段里"看到"突变位点，需要这个细胞恰好测到了那个位点，这一比例通常很低。下面假设 20%：

```r
# 单细胞数据里：每个供体约 2,800 个细胞（报告：约 6.7 万细胞 / 24 个供体）
cells <- 2800
eff   <- 0.2        # 假设：能在单个细胞的读段里读到突变位点的比例
vaf   <- c(0.02, 0.05, 0.10)
data.frame(VAF = vaf, 预期能确认带突变的细胞数 = round(cells * 2 * vaf * eff))
```

```text
   VAF 预期能确认带突变的细胞数
1 0.02                       22
2 0.05                       56
3 0.10                      112
```

VAF = 0.05 的克隆，一个供体里能直接确认带突变的细胞大约只有 56 个。所以报告说"以携带者 vs 对照为主，突变细胞标注作辅助"是有道理的：分析的主单位是供体，细胞层面的突变标注只做补充。

### 小结

- 带突变的细胞比例约等于 2 × VAF；大克隆（VAF 不低于 0.1）至少约 20% 的血细胞。
- 外显子深度有限，小克隆会被漏掉；"非携带者"里混着看不见的小克隆。
- 单细胞里能确认带突变的细胞很少，分析要以供体为单位。

## 3. ★ 遗传相关：LDSC 与 HDL

> 这一章带走什么：遗传度、遗传协方差和遗传相关是什么；LD 分数回归怎么靠"信号随 LD 分数上升、混杂不随 LD 分数上升"把两者分开；样本重叠为什么只改截距；CHIP 的有效样本量为什么是个大问题。

### 3.1 先认识三个概念

- **遗传度 h²：** 一个性状的差异里，有多大比例能由全基因组 SNP 的加性效应解释。
- **遗传协方差 ρ_g：** 两个性状的 SNP 效应"一起变化"的程度。如果让某个 SNP 的效应使性状 1 升高，也使性状 2 升高，协方差为正。
- **遗传相关 rg：** 把协方差按两个遗传度标准化：

```text
rg = ρ_g ÷ √(h²₁ × h²₂)
```

可以把 rg 想成两张"信号地图"的重合度：1 表示完全重合，0 表示毫无关系，负数表示方向相反。

### 3.2 汇总统计 + LD：LDSC 的出发点

只有汇总统计，没有个体基因型，怎么估计遗传度？

关键事实：SNP 之间互相连锁（LD）。一个因果变异会让它周围一串 SNP 都带上一点信号。所以：

- 一个 SNP 周围"邻居"越多、关联越强，它就越能"代表"周围的因果信号；
- 这个"代表能力"用 LD 分数衡量：ℓ_j = 该 SNP 与周围所有 SNP 的 r² 之和（包括它自己）。例：块内有 20 个 SNP，彼此 r² 约 0.25，则 ℓ ≈ 1 + 19 × 0.25 = 5.75。

对一个多基因性状（成千上万个小效应变异），**LD 分数大的 SNP，平均的 χ² 就更大**。这条规律是 LDSC 的全部出发点。

### 3.3 LDSC 的核心公式

```text
E[χ²_j] = N h² ℓ_j / M  +  N a  +  1
          └ 斜率 × LD分数 ┘   └ 混杂 ┘
```

- N 是样本量，M 是 SNP 个数，ℓ_j 是第 j 个 SNP 的 LD 分数；
- **斜率** = N h² / M，可以反推出遗传度；
- **截距** = 1 + N a，其中 a 衡量人群分层等混杂。没有混杂时截距是 1。

为什么能把两者分开？因为真正的多基因信号随 LD 分数升高；而混杂（如人群分层）带来的虚假关联，大体上与 LD 分数无关。所以：把 χ² 对 LD 分数做回归，**斜率给信号，截距给混杂**。

对比一个更简单的指标 λGC（χ² 的中位数 ÷ 0.455）：它只能看到总的膨胀，分不清是多基因性还是混杂。

### 3.4 两个性状：遗传相关

把 χ² 换成两个性状 z 分数的乘积：

```text
E[z1_j × z2_j] = √(N1 N2) ρ_g ℓ_j / M  +  ρ N_s / √(N1 N2)
                 └ 斜率：遗传协方差 ┘    └ 截距：样本重叠 ┘
```

- 斜率给遗传协方差，再用两个遗传度标准化得到 rg；
- **样本重叠只改变截距，不改变斜率**。其中 N_s 是两份 GWAS 里重叠的人数，ρ 是两个性状在这些人身上的表型相关；
- 所以 LDSC 估计的 rg 对样本重叠是稳健的，这是它相对 MR 的一个优点（MR 要求样本不重叠，见 MR 讲义）。

### 3.5 报告里的第一个问题：有效样本量

CHIP GWAS 是病例对照设计，病例很少。病例对照数据的"有效样本量"是：

```text
有效样本量 = 4 ÷ (1/病例数 + 1/对照数)
```

```r
# 病例对照研究的“有效样本量”：4 / (1/病例 + 1/对照)
eff_n <- function(ncase, nctrl) 4 / (1 / ncase + 1 / nctrl)
cases <- c(10203, 5185, 2041, 4049, 6154)
data.frame(性状 = c("CHIP 总体", "DNMT3A-CH", "TET2-CH", "大克隆", "小克隆"),
           病例 = cases, 对照 = 173918, 有效样本量 = round(eff_n(cases, 173918)))
```

CHIP 总体的有效样本量约 3.9 万；TET2-CH 只有约 8,000。与 BMD GWAS 的几十万人相比，CHIP 这一侧的统计功效很低，所以报告把"遗传层算不出信号"列为第一风险是对的。

经验上，两个性状各自的遗传度估计都要足够准（常用的经验线是遗传度的 z 分数不低于约 4），rg 才可信。具体以 LDSC 文档为准。

### 3.6 实战：搭一个迷你基因组，亲手做 LDSC

真实 LDSC 要用上百万个 SNP 和参考面板。我们造一个迷你版，看原理对不对。

这段代码做了四件事：

1. 造 4000 个 SNP，分成大小不同的连锁块（5 到 80 个 SNP），每块有各自的块内相关强度；
2. 造三批人：两个 GWAS 样本（各 8000 人，互不重叠）和一个只用来算 LD 分数的参考样本（3000 人）；
3. 每个人有一个"祖源因子"，同时轻微影响基因型和表型，用来制造混杂；
4. 算每个 SNP 的 LD 分数。

```r
set.seed(2026)
M <- 4000; N <- 8000                                 # 4000 个 SNP；每个 GWAS 样本 8000 人
bsizes <- c()                                        # 连锁块大小不一：5、10、20、40、80 个 SNP
while (sum(bsizes) < M) bsizes <- c(bsizes, sample(c(5, 10, 20, 40, 80), 1))
bsizes[length(bsizes)] <- bsizes[length(bsizes)] - (sum(bsizes) - M)
blk    <- rep(seq_along(bsizes), bsizes)             # 每个 SNP 属于哪个连锁块
rho_b  <- runif(length(bsizes), 0.2, 0.9)            # 每个块内部的相关强度
maf    <- runif(M, 0.10, 0.50)                       # 效应等位基因频率
load_s <- rnorm(M, 0, 0.04)                          # 每个 SNP 受“祖源因子”影响的程度（用来制造混杂）

sim_people <- function(n) {
  anc <- rnorm(n)                                    # 看不见的祖源因子
  G <- matrix(0L, n, M)
  for (b in seq_along(bsizes)) {
    cols <- which(blk == b)
    u <- rnorm(n)                                    # 块内共享的成分，决定块内 SNP 一起变
    Z <- sqrt(rho_b[b]) * u + sqrt(1 - rho_b[b]) * matrix(rnorm(n * length(cols)), n)
    Z <- Z * rep(sqrt(1 - load_s[cols]^2), each = n) + outer(anc, load_s[cols])
    G[, cols] <- (Z > rep(qnorm((1 - maf[cols])^2), each = n)) +     # 阈值切成 0/1/2
                 (Z > rep(qnorm(1 - maf[cols]^2), each = n))
  }
  list(G = G, anc = anc)
}

s1 <- sim_people(N); Gs1 <- scale(s1$G); s1$G <- NULL        # GWAS 样本 1（标准化基因型）
s2 <- sim_people(N); Gs2 <- scale(s2$G); s2$G <- NULL        # GWAS 样本 2，与样本 1 是不同的人
ref <- sim_people(3000)                                      # 另一批人，专门用来算 LD 分数

# LD 分数：每个 SNP 与块内所有 SNP（含自己）的校正 r² 之和
ld <- numeric(M)
for (b in seq_along(bsizes)) {
  cols <- which(blk == b)
  r2 <- cor(ref$G[, cols, drop = FALSE])^2
  ld[cols] <- rowSums(r2 - (1 - r2) / (3000 - 2))
}
rm(ref)
c(SNP数 = M, 连锁块数 = length(bsizes))
round(summary(ld), 1)
```

```text
   SNP数 连锁块数 
    4000      110 
   Min. 1st Qu.  Median    Mean 3rd Qu.    Max. 
    1.1     4.0     9.3    12.7    20.2    43.3 
```

迷你基因组只有 110 个连锁块。LD 分数从 1.1 到 43.3，范围够宽，回归才有"杠杆"。

下一步写三个函数：迷你 GWAS（每个 SNP 一次回归）、LDSC 回归、块刀切。

```r
gwas_z <- function(Gs, y) {                          # 迷你 GWAS：每个 SNP 一次回归，返回 z 分数
  n <- length(y); ys <- as.vector(scale(y))
  r <- as.vector(crossprod(Gs, ys)) / (n - 1)
  r * sqrt((n - 2) / (1 - r^2))
}

ldsc_uni <- function(z, N, idx) {                    # 单性状：chi2 对 LD 分数做加权回归
  y <- z[idx]^2; l <- ld[idx]
  h0 <- max(unname(coef(lm(y ~ l))[2]) * M / N, 0.001)
  f <- lm(y ~ l, weights = 1 / (l * (1 + N * h0 * l / M)^2))
  c(int = unname(coef(f)[1]), h2 = unname(coef(f)[2]) * M / N)
}

ldsc_cross <- function(z1, z2, N1, N2, idx) {        # 两性状：z1*z2 对 LD 分数做加权回归
  u1 <- ldsc_uni(z1, N1, idx); u2 <- ldsc_uni(z2, N2, idx)
  y <- z1[idx] * z2[idx]; l <- ld[idx]
  w <- 1 / (l * (1 + N1 * u1[["h2"]] * l / M) * (1 + N2 * u2[["h2"]] * l / M))
  f <- lm(y ~ l, weights = w)
  rho_g <- unname(coef(f)[2]) * M / sqrt(N1 * N2)    # 遗传协方差
  c(h2_1 = u1[["h2"]], h2_2 = u2[["h2"]], int_1 = u1[["int"]], int_2 = u2[["int"]],
    int_x = unname(coef(f)[1]), rho_g = rho_g, rg = rho_g / sqrt(max(u1[["h2"]] * u2[["h2"]], 1e-6)))
}

jackknife <- function(fun, nj = 40) {                # 块刀切：每次去掉 1/40 的基因组重算
  full <- fun(seq_len(M)); grp <- cut(seq_len(M), nj, labels = FALSE)
  jk <- t(sapply(seq_len(nj), function(i) fun(which(grp != i))))
  list(est = full, se = sqrt((nj - 1) / nj * colSums(sweep(jk, 2, colMeans(jk))^2)))
}
```

**遗传度和混杂的分离。** 造 40 个性状，真实遗传度都是 0.30。一半没有混杂，一半有混杂（祖源因子同时影响基因型和表型）。

```r
set.seed(11)
R <- 40; h2_true <- 0.30                              # 重复造 40 个表型，看估计的平均值和波动
B <- matrix(rnorm(M * R, 0, sqrt(h2_true / M)), M, R) # 每次重复各自的真实效应：每个 SNP 的方差 = h2/M
sim_y <- function(Gs, anc, B, gamma) {                # 表型 = 遗传 + gamma×祖源因子 + 噪声
  n <- nrow(Gs)
  Gs %*% B + gamma * anc + matrix(rnorm(n * ncol(B), 0, sqrt(1 - h2_true - gamma^2)), n)
}
run_h2 <- function(gamma) {
  Y <- sim_y(Gs1, s1$anc, B, gamma)
  t(sapply(seq_len(R), function(i) ldsc_uni(gwas_z(Gs1, Y[, i]), N, seq_len(M))))
}
r0 <- run_h2(0)                                       # 没有混杂
r1 <- run_h2(0.25)                                    # 有混杂（祖源因子同时影响基因型和表型）
data.frame(混杂 = c("无", "有"),
           截距_平均 = round(c(mean(r0[, "int"]), mean(r1[, "int"])), 2),
           截距_SD   = round(c(sd(r0[, "int"]),   sd(r1[, "int"])), 2),
           h2_平均   = round(c(mean(r0[, "h2"]),  mean(r1[, "h2"])), 2),
           h2_SD     = round(c(sd(r0[, "h2"]),    sd(r1[, "h2"])), 2))
```

```text
  混杂 截距_平均 截距_SD h2_平均 h2_SD
1   无       1.0    0.51    0.29  0.06
2   有       1.7    0.49    0.28  0.07
```

读法：

- 没有混杂时，截距平均 1.0，遗传度平均 0.29（真值 0.30）。
- 有混杂时，截距升到平均 1.7，而遗传度估计几乎不变（0.28）。**这就是"截距吸收混杂、斜率只管信号"。**
- 单次估计的波动很大：截距的 SD 约 0.5。原因是迷你基因组只有 110 个连锁块，真实数据有上百万个 SNP，截距的标准误常常只有 0.01 到 0.02。

**实际分析只有一份数据。** 这时用块刀切估计标准误：每次去掉基因组的 1/40，重算一遍，看估计的波动。

```r
# 实际分析时只有一份数据：用块刀切估计标准误
z_one <- gwas_z(Gs1, sim_y(Gs1, s1$anc, B[, 1, drop = FALSE], 0.25)[, 1])
jk <- jackknife(function(idx) ldsc_uni(z_one, N, idx))
round(rbind(估计 = jk$est, 刀切SE = jk$se), 2)
```

```text

估计   2.48 0.20
刀切SE 0.45 0.06
```

这一份数据的截距是 2.48，刀切标准误 0.45，与上面 40 次重复的实际波动（SD 0.49）吻合，说明刀切标准误是可信的。

**遗传相关与样本重叠。** 两个性状的真实 rg = 0.5。重复 30 次，两种设计：

- 不重叠：两个性状来自两批不同的人；
- 完全重叠：两个性状在同一批人身上测，环境噪声相关 0.4。

```r
set.seed(12)
rho_beta <- 0.5                                       # 两个性状的真实效应相关 0.5：真实 rg = 0.5
noise_sd <- sqrt(1 - h2_true)
one_rep <- function() {
  b1 <- rnorm(M, 0, sqrt(h2_true / M))
  b2 <- rho_beta * b1 + sqrt(1 - rho_beta^2) * rnorm(M, 0, sqrt(h2_true / M))
  # 情形一：两个性状来自两批不同的人（样本不重叠）
  zA <- gwas_z(Gs1, as.vector(Gs1 %*% b1) + rnorm(N, 0, noise_sd))
  zB <- gwas_z(Gs2, as.vector(Gs2 %*% b2) + rnorm(N, 0, noise_sd))
  a <- ldsc_cross(zA, zB, N, N, seq_len(M))
  # 情形二：两个性状在同一批人身上测（样本完全重叠），环境噪声相关 0.4
  e  <- matrix(rnorm(2 * N), N, 2) %*% chol(matrix(c(1, 0.4, 0.4, 1), 2)) * noise_sd
  y1 <- as.vector(Gs1 %*% b1) + e[, 1]; y2 <- as.vector(Gs1 %*% b2) + e[, 2]
  o <- ldsc_cross(gwas_z(Gs1, y1), gwas_z(Gs1, y2), N, N, seq_len(M))
  c(rg_不重叠 = a[["rg"]], 截距_不重叠 = a[["int_x"]], rg_重叠 = o[["rg"]], 截距_重叠 = o[["int_x"]],
    表型相关 = cor(y1, y2))
}
reps <- t(replicate(30, one_rep()))
out <- rbind(平均 = colMeans(reps), SD = apply(reps, 2, sd))
round(out, 2)
```

```text
     rg_不重叠 截距_不重叠 rg_重叠 截距_重叠 表型相关
平均      0.48        0.02    0.49      0.39     0.43
SD        0.14        0.26    0.14      0.30     0.01
```

读法：

- 两种设计里 rg 的平均都接近 0.5（0.48 和 0.49）：**样本重叠没有改变 rg**。
- 跨性状截距：不重叠时约 0.02（≈ 0），完全重叠时约 0.39，接近两个性状的表型相关 0.43。**样本重叠只出现在截距里。**

### 3.7 真实使用时的要点

官方 LDSC 是命令行工具（Python）。流程示意如下（依据 LDSC 文档，没有在本环境运行）：

```bash
# 1. 把汇总统计整理成 LDSC 格式（只保留 HapMap3 SNP，统一等位基因）
munge_sumstats.py --sumstats chip.tsv.gz --snp variant_id --a1 effect_allele --a2 other_allele \
    --p p_value --signed-sumstats beta,0 --N-cas 10203 --N-con 173918 \
    --merge-alleles w_hm3.snplist --out chip

# 2. 算两个性状的遗传相关；二分类性状要给出样本中和人群中的患病率，用于换算尺度
ldsc.py --rg chip.sumstats.gz,ebmd.sumstats.gz \
    --ref-ld-chr eur_w_ld_chr/ --w-ld-chr eur_w_ld_chr/ \
    --samp-prev 0.055,nan --pop-prev 0.05,nan --out chip_vs_ebmd   # 患病率数值只是示例
```

使用时的几个坑：

1. **尺度。** 二分类性状的遗传度有"观察尺度"和"liability 尺度"之分，后者需要人群患病率。第 11 章显示，报告用到的 CHIP 汇总统计文件里有 `CHISQ_BOLT_LMM` 一列，说明是混合线性模型（BOLT-LMM）的结果，beta 是线性尺度，不是 log OR。
2. **人群。** 欧洲人群的 LD 分数只适用于欧洲人群的 GWAS。
3. **SNP 集合。** 通常只用 HapMap3 的约 120 万个 SNP，并排除 MHC 区域。
4. **样本量。** 病例对照要用有效样本量（或分别给病例数和对照数）。

### 3.8 HDL（高清似然法）

报告里的 HDL 是 High-Definition Likelihood（Ning、Pawitan、Shen，Nat Genet 2020）。它同样用汇总统计估计遗传度和遗传相关，但不像 LDSC 那样只用 LD 分数这一个一维摘要，而是用完整的 LD 矩阵写出 z 分数的联合似然。信息利用得更充分，原文报告相比 LDSC 估计方差降低约 60%。代价是要用专门的 LD 参考面板，计算更重。

两者互为交叉验证，报告同时用两种方法是合理的。注意它们对同一份数据的结论应当方向一致，数字不必相同。

### 小结

- LDSC 把 χ² 对 LD 分数回归：斜率给遗传度，截距给混杂。
- 两个性状：斜率给遗传协方差，截距给样本重叠；所以 rg 对样本重叠稳健。
- CHIP 的有效样本量只有几万到几千，功效是这一层最大的风险。
- 单次估计噪声大，要看标准误，也要明白"没有信号"可能只是功效不足。

## 4. ★ 全局为零，局部不一定为零：LAVA 与 SUPERGNOVA

> 这一章带走什么：为什么全局遗传相关等于 0 不代表"没有共享"；局部方法的思路；一个"区域版"的玩具估计，以及它能看见什么。

### 4.1 全局为零，可能是正负抵消

报告引用的 Bone 2026 说：CAC 与 eBMD **没有全局遗传相关**，但有 211 个共享基因，集中在 17 号染色体。

这并不矛盾。全局 rg 是整个基因组"平均"出来的一个数。设想基因组分成两半：

- 一半里，让性状 1 升高的变异也让性状 2 升高（局部相关为 +0.9）；
- 另一半里，反过来（局部相关为 −0.9）。

两半一平均，全局 rg 约等于 0。但这两个性状明明有强烈的、结构化的共享。如果还只看全局数，就会得出"没有关系"的错误结论。

### 4.2 局部方法的思路

局部遗传相关方法（报告提到 LAVA 和 SUPERGNOVA）的做法是：

1. 把基因组切成约 2,500 个近似独立的 LD 区块（每块约 1 Mb，具体划分以原文为准）；
2. 在每个区块里，分别估计两个性状的局部遗传度，并检验是否显著。**没有局部遗传信号，就谈不上局部相关**；
3. 只在两个性状局部遗传度都显著的区块里，估计局部遗传协方差和局部 rg，给出 p 值；
4. 样本重叠用 LDSC 的跨性状截距校正（见第 3 章）；
5. 区块数量大，要做多重检验校正（如 Bonferroni，阈值约 0.05 ÷ 检验的区块数）。

LAVA 和 SUPERGNOVA 做的是同一件事，估计量的细节不同。报告写"二选一"，我的建议是两个都跑，互相当交叉验证。

与全局方法相比，局部方法的代价是：每个区块的 SNP 少、信号弱，所以**统计功效更低、标准误更大**。

### 4.3 实战：区域版估计

我们沿用第 3 章的迷你基因组（同一个 R 会话里继续运行）。设计：

- 把基因组分成 6 个区域（各含约 1/6 的 SNP）；
- 前 3 个区域里，两个性状的效应相关 +0.9；后 3 个区域里相关 −0.9；
- 两个性状来自两批不重叠的人。

下面是一个"区域版"的估计方法，用的还是 LDSC 的思路：在每个区域内，用 LD 分数加权，估计局部遗传度和局部协方差，再相除。**这是教学简化版，不是 LAVA 本身**（LAVA 用的是区块内完整的 LD 矩阵）。为了让演示干净，截距直接取真值（没有混杂、没有重叠：1、1、0）。

```r
set.seed(21)
mid <- cumsum(bsizes) - bsizes / 2                    # 每个连锁块在基因组上的中点位置
region_of_block <- cut(mid, 6, labels = FALSE)        # 把基因组分成 6 个区域，各含约 1/6 的 SNP
region <- region_of_block[blk]                        # 每个 SNP 属于哪个区域
rho_r  <- c(0.9, 0.9, 0.9, -0.9, -0.9, -0.9)          # 前 3 个区域效应同向，后 3 个区域效应反向
h2_loc <- 0.5

two_traits <- function(rho_vec) {                     # 造两个性状（样本不重叠）的 z 分数
  b1 <- rnorm(M, 0, sqrt(h2_loc / M))
  b2 <- rho_vec[region] * b1 + sqrt(1 - rho_vec[region]^2) * rnorm(M, 0, sqrt(h2_loc / M))
  list(z1 = gwas_z(Gs1, as.vector(Gs1 %*% b1) + rnorm(N, 0, sqrt(1 - h2_loc))),
       z2 = gwas_z(Gs2, as.vector(Gs2 %*% b2) + rnorm(N, 0, sqrt(1 - h2_loc))))
}

# 区域版估计（教学简化版，不是 LAVA 本身）：
#   局部协方差 = sum(z1*z2*LD分数) / (N*sum(LD分数^2))；局部遗传度 = sum((z^2-1)*LD分数) / (N*sum(LD分数^2))
#   局部 rg = 局部协方差 / sqrt(局部遗传度1 * 局部遗传度2)
# 截距直接取真值（没有混杂、没有重叠：1、1、0）
local_rg <- function(z1, z2, blocks_in) {
  idx <- which(blk %in% blocks_in); l <- ld[idx]; d <- N * sum(l^2)
  v1 <- sum((z1[idx]^2 - 1) * l) / d
  v2 <- sum((z2[idx]^2 - 1) * l) / d
  sum(z1[idx] * z2[idx] * l) / d / sqrt(max(v1 * v2, 1e-12))
}
```

### 4.4 使用时的要点

1. **先过滤再检验。** 只在两个性状局部遗传度都显著的区块里估计局部 rg，否则 rg 的分母接近 0，结果不稳。CHIP 的样本量小，很多区块会被过滤掉，这是功效问题，不是方法问题。
2. **多重检验。** 区块数约 2,500，每对性状都要校正；报告里 4 个 CHIP 表型 × 3 个结局表型共 12 对，校正的强度要写在方案里（第 12 章会算这条的后果）。
3. **局部相关不是因果。** 它只说明"这一段基因组上两个性状的遗传效应共变"。接下来要用共定位判断是不是同一个变异（第 5 章）。
4. **方向要两头看。** 正相关和负相关的区块都要报告，不要只挑一种。

### 小结

- 全局 rg 是平均数，正负抵消会把它压成 0。
- 局部方法逐区块估计，只在有局部遗传信号的区块里检验。
- 代价是功效更低、要做多重检验；CHIP 的有效样本量小，需要有心理准备。

## 5. ★ 共定位：coloc 与 SuSiE-coloc

> 这一章带走什么：为什么"两个性状在同一个区域都显著"不等于"同一个变异"；coloc 怎么算五个后验概率；单一因果变异的假设什么时候会骗你；SuSiE-coloc 怎么补救。

### 5.1 要回答的问题

一个基因组区域里，一个因果变异会让它周围一串 SNP 都显著（因为 LD）。设想 CHIP 和骨密度在同一个区域都有显著信号：

- 可能是**同一个变异**同时影响两个性状（这是我们想要的）；
- 也可能是**两个不同的变异**碰巧靠得很近，各影响一个性状。

只看"都显著"分不清这两种情形。共定位（colocalization）就是来判断：两个性状的信号来自同一个因果变异的概率有多大。

### 5.2 五个假设

对一个区域，coloc 比较五个互斥的假设：

| 假设 | 含义 | 默认先验 |
|---|---|---|
| H0 | 两个性状都没有关联 | 其余的补足 |
| H1 | 只有性状 1 有关联 | 每个 SNP 对性状 1 有因果的概率 p1 = 1e-4 |
| H2 | 只有性状 2 有关联 | p2 = 1e-4 |
| H3 | 两个性状都有关联，但因果变异不同 | p1 × p2 |
| H4 | 两个性状都有关联，共享同一个因果变异 | p12 = 1e-5 |

注意 H4 与 H3 的先验比：对每一对 SNP，H4 的先验是 1e-5，H3 的先验是 1e-4 × 1e-4 = 1e-8，**H4 比 H3 有 1000 倍的先验优势**。这个优势会在后面的"多信号"例子里起作用。

输出是五个后验概率 PP.H0 到 PP.H4，加起来等于 1。

### 5.3 近似贝叶斯因子

coloc 的核心是给每个 SNP 算一个"贝叶斯因子"：这个 SNP 有因果效应的证据有多强。用 Wakefield 的近似，只需要 beta 和 SE：

```text
V = SE²                              （效应估计的方差）
W = (0.15 × sdY)²                    （先验：真实效应的方差，连续性状的默认值）
r = W ÷ (W + V)
z = beta ÷ SE
log ABF = 0.5 × ( log(1 − r) + r × z² )
```

手算一个例子：beta = 0.25，SE = 0.025，sdY = 1。

```text
V = 0.025² = 0.000625；  W = 0.15² = 0.0225
r = 0.0225 ÷ (0.0225 + 0.000625) = 0.973
z = 0.25 ÷ 0.025 = 10
log ABF = 0.5 × ( log(0.027) + 0.973 × 100 ) = 0.5 × ( −3.61 + 97.30 ) = 46.84
```

z 越大，log ABF 越大，证据越强。

### 5.4 汇总成五个后验

对每个性状，把区域内所有 SNP 的 ABF 加起来得到 H1、H2 的证据；把两个性状同一 SNP 的 ABF 相乘再加起来得到 H4 的证据；"所有 SNP 对"的乘积之和减去"同一 SNP"的部分得到 H3 的证据。再乘上先验，归一化。这些都在对数尺度上算（避免数值溢出）。下面是完整的实现，不到 20 行：

```r
# coloc 的核心：每个 SNP 的近似贝叶斯因子（Wakefield），再汇总成五个假设的后验概率
log_abf <- function(beta, varbeta, sdY = 1) {
  W <- (0.15 * sdY)^2                                 # 先验：效应大小的标准差 = 0.15 个 sdY
  r <- W / (W + varbeta); z <- beta / sqrt(varbeta)
  0.5 * (log(1 - r) + r * z^2)
}
logsum  <- function(x) { m <- max(x); m + log(sum(exp(x - m))) }
logdiff <- function(x, y) { m <- max(x, y); m + log(exp(x - m) - exp(y - m)) }
my_coloc <- function(d1, d2, p1 = 1e-4, p2 = 1e-4, p12 = 1e-5) {
  l1 <- log_abf(d1$beta, d1$varbeta, d1$sdY); l2 <- log_abf(d2$beta, d2$varbeta, d2$sdY)
  lH <- c(0,                                                         # H0：都没有关联
          log(p1) + logsum(l1),                                      # H1：只有性状 1
          log(p2) + logsum(l2),                                      # H2：只有性状 2
          log(p1) + log(p2) + logdiff(logsum(l1) + logsum(l2), logsum(l1 + l2)),   # H3：各有因果变异，但不是同一个
          log(p12) + logsum(l1 + l2))                                # H4：共享同一个因果变异
  setNames(exp(lH - logsum(lH)), paste0("H", 0:4))
}
```

### 5.5 实战：三种情形

造一个区域：150 个 SNP，相邻 SNP 相关 0.95，向两侧衰减（LD 很强）。每个性状来自 4000 人的独立样本，所以是"两样本"设计。

```r
set.seed(7)
m <- 150; n <- 4000                                   # 一个区域 150 个 SNP；每个研究 4000 人
chol_R <- chol(0.95^abs(outer(1:m, 1:m, "-")))        # 相邻 SNP 相关 0.95，向两侧衰减（LD 很强）
f   <- runif(m, 0.15, 0.50)
snp <- sprintf("s%03d", 1:m)
sim_geno <- function(n) {                             # 造这个区域的基因型 0/1/2
  Z <- matrix(rnorm(n * m), n, m) %*% chol_R
  (Z > rep(qnorm((1 - f)^2), each = n)) + (Z > rep(qnorm(1 - f^2), each = n))
}
make_study <- function(causal, beta = 0.25) {         # 造一个研究：因果 SNP 的位置 + 逐 SNP 回归
  G <- sim_geno(n)
  y <- rnorm(n) + if (length(causal)) as.vector(G[, causal, drop = FALSE] %*% rep_len(beta, length(causal))) else 0
  y <- as.vector(scale(y))                            # 标准化，sdY = 1
  gc <- sweep(G, 2, colMeans(G)); sxx <- colSums(gc^2); sxy <- as.vector(crossprod(gc, y))
  b <- sxy / sxx; se <- sqrt((sum(y^2) - b * sxy) / (n - 2) / sxx)
  list(beta = b, varbeta = se^2, snp = snp, type = "quant", sdY = 1, N = n)
}
Gref <- sim_geno(2000); LD <- cor(Gref); dimnames(LD) <- list(snp, snp)   # LD 参考样本
```

三种情形：

- **H4（共享）：** 两个性状的因果 SNP 都在位置 60；
- **H3（不同）：** 性状 1 的因果 SNP 在 60，性状 2 的在 80（两者的 LD 中等）；
- **H1（只有性状 1）：** 性状 2 没有因果 SNP。


### 5.6 单一因果变异的假设会骗你

coloc 默认**每个性状在这个区域里最多一个因果变异**。如果一个性状有两个独立信号，会怎样？

造这样一个情形：性状 1 有两个因果 SNP：位置 60（强）和位置 100（弱）；性状 2 只有位置 100。也就是说，**真正共享的是性状 1 的"次要信号"**。

```r

# 也就是：真正共享的是性状 1 的“次要信号”
d_multi <- list(make_study(c(60, 100), beta = c(0.35, 0.12)), make_study(100))

```

```text

性状1   60 15.2
性状2  100 11.1
H0 H1 H2 H3 H4 
 0  0  0  1  0 
```

性状 1 的最强信号在 60（z = 15.2），性状 2 的在 100（z = 11.1）。coloc 看到两个性状的"主峰"不在同一处，判成 H3（因果变异不同，PP.H3 = 1）。**这是错的**：它们在位置 100 上确实共享，只是被性状 1 的强信号盖住了。

为什么 H4 没有赢？H4 的证据来自"同一个 SNP 上两个性状都强"，只能用位置 100。但性状 1 在位置 100 的证据（z = 6.5，log ABF = 18.9）远不如位置 60（z = 15.2，log ABF = 111.1），差了 92；而 H4 相对 H3 的 1000 倍先验优势，在对数尺度上只有 ln(1000) = 6.9。差距太大，先验补不回来。

### 5.7 SuSiE-coloc

SuSiE（Sum of Single Effects）是一种精细定位方法：把一个区域里的信号拆成若干个"单一效应"之和，每个单一效应对应一个**可信集**（一小撮 SNP，包含因果变异的概率不低于 95%）。SuSiE-coloc（Wallace 2021，PLoS Genet）先用 SuSiE 分别给两个性状找出可信集，再对**每一对可信集**做共定位。

它需要一个 LD 矩阵（来自与 GWAS 相同人群的参考样本）。下面用前面造的 LD 参考样本。

```r
library(susieR)
d1 <- d_multi[[1]]; d2 <- d_multi[[2]]; d1$LD <- LD; d2$LD <- LD
```

SuSiE-coloc 正确找到了被主信号盖住的共享变异。

### 5.8 实战要点

1. **等位基因要对齐。** 两个性状的汇总统计必须是同一批 SNP、同一个效应等位基因（见 MR 讲义第 5 章）。
2. **区域选择。** 通常取每个显著位点附近（如两侧 500 kb）的所有 SNP。两个性状的区域坐标版本要一致（GRCh37 或 GRCh38）。
3. **阈值。** 常用经验线是 PP.H4 不低于 0.8；也可以同时看 PP.H3 + PP.H4（有没有信号）和 PP.H4 ÷ PP.H3。PP.H0、PP.H1、PP.H2 高时，往往只是功效不足，不是"没有共定位"。
4. **先验敏感性。** 把 p12 在 1e-6 到 1e-4 之间变化，看结论是否稳定（`coloc` 包有 `sensitivity()` 函数）。
5. **二分类性状。** CHIP 这类病例对照性状，如果汇总统计来自 BOLT-LMM 线性混合模型，beta 是线性尺度，可以按连续性状处理，`sdY` 取 √(p(1−p))，p 是病例比例。具体做法以 `coloc` 文档为准。
6. **三个以上性状。** 报告要找"三表型共享位点"。可以两两做共定位再取交集；多性状共定位有专门的方法（如 HyPrColoc，Foley 等，Nat Commun 2021）。
7. **LD 必须匹配。** SuSiE-coloc 的 LD 矩阵与 GWAS 人群不匹配时，会找出假的可信集。

### 小结

- 共定位回答"同一个变异"的问题，输出 PP.H0 到 PP.H4。
- 核心是近似贝叶斯因子 + 五个假设的先验；手写不到 20 行，与 `coloc` 包完全一致。
- 单一因果变异的假设在多信号区域会骗你；SuSiE-coloc 按可信集配对，能找回被盖住的共享信号。

## 6. ★ 单细胞分析基础，以及"别把细胞当重复"

> 这一章带走什么：单细胞数据的标准分析流程；为什么单细胞研究的"样本"是供体而不是细胞；把细胞当重复会造成多严重的假阳性；17 个携带者 vs 7 个对照的数据能检出多大的差异。

### 6.1 数据长什么样

单细胞 RNA-seq 的原始结果是一张**计数矩阵**：行是细胞，列是基因，格子里是这个细胞里读到的这个基因的分子数。它很稀疏（大多数格子是 0），而且每个细胞的总读数（测序深度）差别很大。

### 6.2 标准流程

| 步骤 | 做什么 | 常用工具 |
|---|---|---|
| 质控 | 去掉低质量细胞、双细胞、线粒体比例过高的细胞 | Seurat（R）、Scanpy（Python） |
| 标准化 | 按每个细胞的总读数校正深度，再取 log1p | 同上 |
| 高变基因 | 选出变化最大的一批基因，降低噪声 | 同上 |
| 降维 | 主成分分析（PCA）；可视化用 UMAP | 同上 |
| 聚类 | 把相似的细胞分成群 | 同上 |
| 注释 | 用标记基因给每个群命名（T 细胞、巨噬细胞……） | 同上 |
| 差异分析 | 比较组间的基因表达；**在供体层面做** | edgeR、DESeq2、limma-voom |

### 6.3 实战 1：用基础 R 走一遍流程

造一个玩具数据：3 种细胞类型各 500 个，600 个基因，每种类型有 50 个标记基因表达更高，每个细胞的测序深度不同。

```r
set.seed(31)
ngene <- 600; per <- 500
type  <- rep(c("T细胞", "B细胞", "髓系"), each = per); ncell <- length(type)
base  <- rnorm(ngene, 0, 1.0)                             # 每个基因的基础表达量（对数尺度）
fc    <- matrix(0, ngene, 3)                              # 每种细胞类型各有 50 个标记基因表达更高
for (k in 1:3) fc[sample(ngene, 50), k] <- rnorm(50, 1.1, 0.3)
depth <- rlnorm(ncell, 0, 0.4)                            # 每个细胞的测序深度不同
lambda <- depth * exp(matrix(base, ncell, ngene, byrow = TRUE) + t(fc)[match(type, unique(type)), ])
counts <- matrix(rpois(length(lambda), lambda), ncell)    # 计数矩阵：行是细胞，列是基因

lib <- rowSums(counts)
X   <- log1p(counts / lib * 1e4)                          # 1. 按测序深度标准化，再取 log1p
hvg <- order(apply(X, 2, var), decreasing = TRUE)[1:200]  # 2. 选 200 个变化最大的基因
pcs <- prcomp(X[, hvg], scale. = TRUE)$x[, 1:10]          # 3. 主成分分析，取前 10 个
cl  <- kmeans(pcs, 3, nstart = 10)$cluster                # 4. 聚类
table(真实类型 = type, 聚类 = cl)
```

### 6.4 报告里的数据集分级

报告把单细胞数据集分成 A、B、C 三级：

- **A：可直接做组间比较。** 看的是**每组的供体数**，不是细胞数。例如 CNGB TrueBlood 有 17 例携带者 + 7 例对照；GSE159677 虽然只有 3 对配对样本，但配对设计很关键，也归 A；
- **B：可做状态发现与方向验证。** 样本少，不适合严格的组间检验；
- **C：参考用。**

### 6.5 最大的坑：伪重复

设想 CNGB 数据：17 例携带者 + 7 例对照，每人取 200 个细胞，共 4,800 个细胞。你想找"携带者 vs 对照"表达有差别的基因。

直觉做法：把 4,800 个细胞分成两组，每个基因做一次 t 检验。**这是错的。** 同一个供体的 200 个细胞共享这个供体自己的"基线"（遗传背景、年龄、批次、采样当天的状态……），它们不是 200 个独立样本，更像是对同一个人的 200 次重复测量。

模拟验证：1,000 个基因，其中只有前 50 个基因真的有组间差异，其余 950 个没有。供体之间有天然差异（SD 0.35）。

```r
set.seed(32)
n_case <- 17; n_ctrl <- 7; cells <- 200; ngene <- 1000      # 17 例携带者 + 7 例对照，每人取 200 个细胞
grp    <- rep(c("携带者", "对照"), c(n_case, n_ctrl))
donor  <- rep(seq_along(grp), each = cells); g_cell <- grp[donor]
base   <- rnorm(ngene, 0.3, 1)
true_fc <- c(rep(0.5, 50), rep(0, ngene - 50))              # 前 50 个基因有真实的组间差异；其余 950 个没有
donor_eff <- matrix(rnorm(length(grp) * ngene, 0, 0.35), length(grp), ngene)   # 供体之间的天然差异
logmu  <- matrix(base, length(donor), ngene, byrow = TRUE) + donor_eff[donor, ] +
          outer(as.integer(g_cell == "携带者"), true_fc)
depth  <- rlnorm(length(donor), 0, 0.3)
counts <- matrix(rpois(length(logmu), depth * exp(logmu)), length(donor))
X <- log1p(counts / rowSums(counts) * mean(rowSums(counts)))

welch_p <- function(M, is1) {                                # 对每一列做 Welch t 检验
  m1 <- colMeans(M[is1, , drop = FALSE]);  m0 <- colMeans(M[!is1, , drop = FALSE])
  v1 <- apply(M[is1, , drop = FALSE], 2, var) / sum(is1); v0 <- apply(M[!is1, , drop = FALSE], 2, var) / sum(!is1)
  t <- (m1 - m0) / sqrt(v1 + v0); df <- (v1 + v0)^2 / (v1^2 / (sum(is1) - 1) + v0^2 / (sum(!is1) - 1))
  2 * pt(-abs(t), df)
}
p_cell <- welch_p(X, g_cell == "携带者")                      # 做法 A：把每个细胞当一个独立样本
pb     <- rowsum(X, donor) / cells                           # 做法 B：先按供体求平均（伪批量），再比较 24 个供体
p_pb   <- welch_p(pb, grp == "携带者")

summ <- function(p) {
  disc <- p.adjust(p, "BH") < 0.05
  c(`无差异基因中 p<0.05 的比例` = mean(p[51:ngene] < 0.05), `真有差异的基因中 p<0.05 的比例` = mean(p[1:50] < 0.05),
    `FDR<5% 的发现数` = sum(disc), `其中假发现` = sum(disc[51:ngene]))
}
round(rbind(`细胞当重复` = summ(p_cell), `按供体汇总` = summ(p_pb)), 2)
```

```text
           无差异基因中 p<0.05 的比例 真有差异的基因中 p<0.05 的比例 FDR<5% 的发现数 其中假发现
细胞当重复                       0.67                           1.00             672        623
按供体汇总                       0.05                           0.88               8          1
```

| 做法 | 无差异的 950 个基因里，p<0.05 的比例 | FDR<5% 的发现数 | 其中假发现 |
|---|---|---|---|
| 细胞当重复 | 67% | 672 | 623（93%） |
| 按供体汇总 | 5% | 8 | 1 |

**把细胞当重复，三分之二的无关基因都"显著"，报出来的发现里 93% 是假的。** 按供体汇总后，假阳性率回到 5%，发现很少但可信。细胞当重复的"灵敏度 100%"是假象：它对一切都敏感。

### 6.6 怎么做对

三种常用做法：

1. **伪批量（pseudobulk）。** 把同一个供体、同一种细胞类型的原始计数加起来，得到每个供体一份"表达谱"，再用 edgeR、DESeq2 或 limma-voom 这类工具比较两组供体。可以方便地加入年龄、性别、批次等协变量。
2. **混合模型。** 保留细胞层面的数据，把供体设为随机效应（如 lme4、glmmTMB、NEBULA）。信息利用更充分，计算更重。
3. **供体层面的置换检验。** 打乱供体的组别标签，重新算统计量。

三种做法的共同点：**重复单位是供体**。报告结果时要写明每组的供体数。参考：Squair 等，Nat Commun 2021；Zimmerman 等，Nat Commun 2021。

### 6.7 17 vs 7 个供体，能检出多大的差异

样本量小，要先知道"功效够不够"。下面算 80% 功效、双侧检验时，最小可检出的标准化效应（单位：供体间的标准差）。

```r
# 17 例携带者 vs 7 例对照：80% 功效能检出多大的差异？（单位：供体间标准差）
power_unbal <- function(d, n1, n0, alpha = 0.05) {
  df <- n1 + n0 - 2; ncp <- d * sqrt(n1 * n0 / (n1 + n0)); tc <- qt(1 - alpha / 2, df)
  1 - pt(tc, df, ncp) + pt(-tc, df, ncp)
}
min_d <- function(n1, n0, alpha = 0.05) uniroot(function(d) power_unbal(d, n1, n0, alpha) - 0.8, c(0.1, 6))$root
data.frame(设计 = c("17 vs 7", "17 vs 17", "7 vs 7", "17 vs 7（每个基因 α=0.001）"),
           最小可检出效应 = round(c(min_d(17, 7), min_d(17, 17), min_d(7, 7), min_d(17, 7, 0.001)), 2))
```

```text
                         设计 最小可检出效应
1                     17 vs 7           1.32
2                    17 vs 17           0.99
3                      7 vs 7           1.63
4 17 vs 7（每个基因 α=0.001）           2.12
```

17 vs 7 的设计，最小可检出效应是 1.32 个供体间标准差。也就是说，组间差异要大于一个多标准差，才有 80% 的把握检出。如果要对每个基因做严格的多重检验（α = 0.001），门槛涨到 2.12。**所以这类数据适合发现"大效应"和"程序层面的整体方向"，不适合逐个基因地找小效应。** 报告里把 A 级数据用于"组间比较"、其余用于"方向验证"，正是这个道理。

### 小结

- 单细胞流程：标准化、高变基因、PCA、聚类、注释、差异分析。
- 重复单位是供体，不是细胞；把细胞当重复，假阳性率可以高达三分之二。
- 17 vs 7 的设计只能检出大效应（约 1.3 个供体间标准差以上）。

## 7. ★ 把 GWAS 信号映射到细胞：MAGMA、scDRS 与 scPagwas

> 这一章带走什么：怎么把"基因组上的关联信号"和"单细胞图谱里的表达"接起来；scDRS 为什么必须用"匹配对照"；用一个玩具例子看匹配和不匹配的差别。

### 7.1 要回答的问题

GWAS 告诉你：这个性状与基因组上很多位点有关。单细胞图谱告诉你：每个细胞表达哪些基因。把两者接起来，可以问：**这个性状的遗传风险，偏向哪一类细胞？**

对应报告第一阶段的第 4 步：把 AAC、CAC、eBMD 的 GWAS 信号映射到钙化斑块和骨髓单细胞图谱，看风险是否富集在髓系细胞上。

### 7.2 第一步：从 SNP 到基因（MAGMA）

GWAS 的单位是 SNP，单细胞的单位是基因，要先对齐。MAGMA（de Leeuw 等，PLoS Comput Biol 2015）做基因水平分析：把一个基因及其附近 SNP 的 p 值合并成一个**基因水平的 z 分数**，同时考虑 LD 和基因大小。z 越大，说明这个基因越可能与性状有关。

### 7.3 第二步：给每个细胞打"疾病分数"（scDRS）

scDRS（Zhang 等，Nat Genet 2022）的思路：

1. 取 GWAS 排名靠前的一批基因（论文默认约 1,000 个），用 MAGMA 的 z 分数作权重；
2. 每个细胞的"原始疾病分数"= 这些基因表达量的加权平均；
3. 但这个分数不能直接比。要生成很多组（论文默认约 1,000 组）**表达量与方差匹配**的随机对照基因集，同样算分数，作为"没有疾病信号时的期望"；
4. 用对照分数把疾病分数标准化，得到每个细胞的标准化分数和 p 值；
5. 在细胞类型层面汇总，如"某类细胞里高分细胞的比例"，并看类型内部的异质性。

以上是论文设计的概述，默认参数和细节以原文及软件文档为准。

### 7.4 为什么对照必须"匹配"

GWAS 筛出来的基因，往往本来表达量就偏高（高表达基因更容易被检出关联，也更常出现在功能基因里）。如果随机对照基因集是从**所有**基因里抽的，它们大部分是低表达基因，疾病基因集的分数永远比对照高，**所有细胞类型都会"显著"**。所以对照基因集必须在表达量上与疾病基因集匹配。

### 7.5 实战：玩具 scDRS

造一个玩具图谱：4 种细胞类型（T 细胞、B 细胞、髓系、基质）各 1,000 个细胞，2,000 个基因。设计：

- 疾病基因集：100 个基因，都来自表达量最高的前 400 个基因（模拟真实 GWAS 基因偏高表达）；
- 真信号：其中 60 个基因在髓系细胞里表达更高；
- 对照性状：另外 100 个同样高表达的基因，但没有任何细胞类型特异性。

```r
set.seed(41)
ngene <- 2000; per <- 1000; types <- c("T细胞", "B细胞", "髓系", "基质")
type  <- rep(types, each = per); ncell <- length(type)
mu_g  <- rnorm(ngene, -0.5, 1.4)                         # 每个基因的基础表达量（对数尺度），差别很大
fc    <- matrix(0, ngene, 4)                             # 每种细胞类型里 300 个基因有特异的上调或下调
for (k in 1:4) fc[sample(ngene, 300), k] <- rnorm(300, 0, 0.8)

hi  <- order(mu_g, decreasing = TRUE)[1:400]             # 表达量最高的 400 个基因
dis <- sample(hi, 100)                                   # 疾病基因集：100 个，都来自高表达基因（真实 GWAS 基因常如此）
sig <- sample(dis, 60); fc[sig, 3] <- fc[sig, 3] + 0.8   # 真信号：其中 60 个在髓系细胞里更高
dis_null <- sample(setdiff(hi, dis), 100)                # 对照性状：同样是 100 个高表达基因，但没有任何细胞类型特异性
w <- runif(100, 3, 8)                                    # 基因权重（真实分析里来自 MAGMA 基因水平 z 分数）

depth  <- rlnorm(ncell, 0, 0.3)
lambda <- depth * exp(matrix(mu_g, ncell, ngene, byrow = TRUE) + t(fc)[match(type, types), ])
counts <- matrix(rpois(length(lambda), lambda), ncell)
X <- log1p(counts / rowSums(counts) * 1e4)               # 标准化后的表达量
```

再写打分函数：把基因按平均表达量分成 20 档；"匹配对照"是为每个疾病基因配一个同档位的随机基因；"朴素对照"是从所有基因里随便抽。

```r
raw_score <- function(genes, wt) as.vector(X[, genes, drop = FALSE] %*% (wt / sum(wt)))   # 加权平均表达量

gene_mean <- colMeans(X)
bin <- cut(gene_mean, quantile(gene_mean, 0:20 / 20), include.lowest = TRUE, labels = FALSE)   # 按平均表达量分 20 档

make_ctrl <- function(genes, wt, matched, B = 300) {     # 造 B 组对照基因集
  pool <- setdiff(seq_len(ngene), genes)
  t(sapply(seq_len(B), function(i) {
    g <- if (matched) {                                  # 匹配对照：每个疾病基因配一个同一表达档位的随机基因
      sapply(genes, function(x) sample(pool[bin[pool] == bin[x]], 1))
    } else sample(pool, length(genes))                   # 朴素对照：从所有基因里随便抽
    raw_score(g, sample(wt))
  }))
}

score_trait <- function(genes, wt, matched) {
  s    <- raw_score(genes, wt)
  ctrl <- make_ctrl(genes, wt, matched)
  z    <- (s - colMeans(ctrl)) / apply(ctrl, 2, sd)      # 每个细胞：疾病分数相对对照分数的 z
  p    <- (1 + rowSums(t(ctrl) >= s)) / (nrow(ctrl) + 1) # 蒙特卡洛 p 值：对照分数不低于疾病分数的比例
  data.frame(mean_z = tapply(z, type, mean)[types], frac_sig = tapply(p < 0.05, type, mean)[types])
}
```

对两个性状（真信号、无关性状）各用两种对照打分：

```r
set.seed(42)
r_dis_m  <- score_trait(dis, w, TRUE);        r_dis_n  <- score_trait(dis, w, FALSE)        # 真信号：匹配对照 / 朴素对照

p_tab <- cbind(真信号 = r_dis_m$frac_sig, 无关性状 = r_null_m$frac_sig)

cat("每种细胞类型的平均 z 分数\n"); round(z_tab, 1)
```

读法：

- **匹配对照：** 真信号性状里，只有髓系细胞的平均 z 分数很高（5.8），而且 100% 的髓系细胞 p<0.05，其他三类都在 0.5 左右。无关性状里，髓系的 z 是 −0.9、没有显著细胞。方法有分辨力。
- **朴素对照：** 两个性状里，**所有**细胞类型的 z 分数都在 15 左右，所有细胞 p<0.05。这等于什么都没说。
- 提醒：无关性状里 B 细胞的 z = 1.2、33% 的细胞 p<0.05。这是随机抽的 100 个基因恰好偏向 B 细胞，属于偶然的小偏差。真实分析要在**细胞类型层面做置换检验**，并看效应大小，而不是只看显著细胞的比例。

**本玩具与真实 scDRS 的差别：** 没有对基因做标准化和协变量回归；对照基因集只有 300 组；只匹配了平均表达量，没有匹配方差；p 值逐细胞算，没有汇总各细胞的对照分数；也没有细胞类型层面的检验和异质性分析。

### 7.6 scPagwas

scPagwas（Ma 等，Cell Genomics 2023）是另一种把 GWAS 与单细胞接起来的方法，思路是在通路层面把 GWAS 信号与单细胞的通路活性联系起来。细节以原文为准，本讲义没有运行。报告写"scDRS 或 scPagwas"，建议两个都做，互相验证。

### 7.7 使用要点

1. **GWAS 的信号要够。** 信号太弱的 GWAS（如 TET2-CH，只有 2,041 例）很难给出稳定的"疾病基因集"。优先用大样本的表型（eBMD、CAC、AAC）。
2. **图谱里要有目标细胞类型。** 报告指出，破骨细胞专门的单细胞数据较少，骨这一侧是弱点。如果图谱里没有破骨样细胞，风险就不可能"富集"在它身上。
3. **富集不等于因果。** 它只说"风险基因在这类细胞里表达偏高"，不说这类细胞是原因。
4. **对应立项判据 2：** "至少一个钙化相关 GWAS 的风险富集在髓系细胞上"。要先在方案里写好什么算"富集"（细胞类型层面的 p 值阈值、校正方式）。

### 小结

- 先用 MAGMA 把 SNP 信号汇总到基因，再用 scDRS 给每个细胞打分。
- 对照基因集必须在表达量上匹配；朴素对照会让所有细胞类型都"显著"。
- 富集只说明风险偏向哪类细胞，不说明因果。

## 8. ★ 基因程序评分与跨组织比对

> 这一章带走什么：什么是"基因程序"和程序评分；基于排名的评分为什么更稳健；评分必须在供体层面比较；怎么判断两个组织里的程序是否重叠，以及一个会让你"假阳性"的共同基线陷阱。

### 8.1 报告里的程序

报告要在 CHIP 外周血单细胞数据里构建"破骨样巨噬细胞程序"评分，用 ACP5、CTSK、MMP9、NFATC1、OSM 这五个核心基因。它们各自的角色：

- **ACP5**：抗酒石酸酸性磷酸酶（TRAP），破骨细胞的经典标记；
- **CTSK**：组织蛋白酶 K，破骨细胞降解骨基质的主要蛋白酶；
- **MMP9**：基质金属蛋白酶 9，降解细胞外基质；
- **NFATC1**：破骨细胞分化的关键转录因子；
- **OSM**：oncostatin M，一种细胞因子（报告说 TET2 突变单核细胞通过它促进瓣膜间质细胞钙化）。

然后在钙化斑块和骨髓两套数据里分别评分，**比较程序重叠度**。

### 8.2 程序评分的几种做法

| 做法 | 思路 | 特点 |
|---|---|---|
| 平均表达减对照 | 程序基因的平均表达，减去表达量匹配的随机基因的平均（Seurat 的 AddModuleScore，思路来自 Tirosh 2016） | 简单；对深度、表达量水平敏感 |
| 基于排名（UCell） | 看程序基因在每个细胞里的表达排名（Andreatta 与 Carmona 2021） | 每个细胞独立计算，不受其他细胞影响；对批次和深度更稳健 |
| 基于排名的曲线下面积（AUCell） | 程序基因是否集中在细胞表达最高的那批基因里（Aibar 2017） | 同样基于排名 |

UCell 的公式：

```text
U = 1 − ( Σ r_i − n(n+1)/2 ) ÷ ( n × maxRank )
```

其中 n 是程序基因个数，r_i 是第 i 个程序基因在这个细胞里的表达排名（1 表示最高；排名超过 maxRank 的按 maxRank + 1 算）。n 个程序基因都排在最前面时 U = 1；都排在 maxRank 之外时 U ≈ 0。

### 8.3 实战：两个组织、两种情形

造玩具数据：每个组织 16 个供体（携带者和对照各 8 个），每个供体 150 个巨噬细胞，1,500 个基因。其中前 40 个基因是"破骨样程序"（含五个核心基因）。设计：

- 每个细胞有一定概率处于"破骨样"状态（携带者平均 30%，对照平均 12%，供体之间还有差异）；
- 破骨样细胞里，程序基因的表达升高；
- **骨髓**：程序 = 基因 1 到 40；
- **斑块，情形 S（共享）**：程序与骨髓相同；
- **斑块，情形 T（不同）**：程序是另外 40 个基因，不含五个核心基因。

```r
set.seed(51)
ngene <- 1500; nd <- 8; cells_per <- 150               # 每组 8 个供体，每个供体 150 个巨噬细胞
genes <- c("ACP5", "CTSK", "MMP9", "NFATC1", "OSM", sprintf("PG%02d", 1:35), sprintf("G%04d", 1:(ngene - 40)))
base  <- rnorm(ngene, 0.4, 1.2)                        # 基因的基础表达量（对数尺度）

sim_tissue <- function(program) {                      # program：这个组织里“破骨样程序”包含哪些基因（下标）
  group  <- rep(c("携带者", "对照"), each = nd)
  p_ocl  <- ifelse(group == "携带者", 0.30, 0.12) * exp(rnorm(2 * nd, 0, 0.2))   # 每个供体里破骨样细胞的比例
  donor  <- rep(seq_len(2 * nd), each = cells_per)
  ocl    <- rbinom(length(donor), 1, p_ocl[donor])     # 每个细胞是否处于破骨样状态
  d_eff  <- matrix(rnorm(2 * nd * ngene, 0, 0.15), 2 * nd, ngene)                 # 供体间的天然差异
  logmu  <- matrix(base, length(donor), ngene, byrow = TRUE) + d_eff[donor, ]
  logmu[, program] <- logmu[, program] + 1.5 * ocl     # 破骨样细胞里，程序基因表达升高
  counts <- matrix(rpois(length(logmu), exp(logmu)), length(donor))
  X <- log1p(counts / rowSums(counts) * 1e4); colnames(X) <- genes
  list(X = X, donor = donor, group = group, ocl = ocl)
}
bm     <- sim_tissue(1:40)                             # 骨髓：程序 = 基因 1–40（含 5 个核心基因）
pl_sh  <- sim_tissue(1:40)                             # 斑块（情形 S）：与骨髓共享同一套程序
pl_sp  <- sim_tissue(101:140)                          # 斑块（情形 T）：另一套完全不同的程序
```

**评分和比较。** 用一个 UCell 式的排名评分（教学简化版，细节如并列排名的处理可能与 UCell 软件包不同）给每个细胞打分，再在**供体层面**比较携带者和对照；同时也报告"把细胞当重复"的 p 值，看差别。

```r
# UCell 式的基于排名的评分（教学简化版）：核心基因在每个细胞里的表达排名越靠前，得分越高
ucell <- function(X, sig, maxRank = 300) {
  idx <- match(sig, colnames(X)); n <- length(idx)
  apply(X, 1, function(x) {
    r <- pmin(rank(-x, ties.method = "average")[idx], maxRank + 1)
    1 - (sum(r) - n * (n + 1) / 2) / (n * maxRank)
  })
}
core5 <- c("ACP5", "CTSK", "MMP9", "NFATC1", "OSM")
welch <- function(v, g) t.test(v[g == "携带者"], v[g == "对照"])$p.value

report <- function(tis) {
  sc <- ucell(tis$X, core5)
  d_score <- tapply(sc, tis$donor, mean)                       # 先按供体汇总
  c(`破骨样细胞比例` = mean(tis$ocl),
    `细胞当重复的p` = welch(sc, tis$group[tis$donor]),
    `按供体汇总的p` = welch(d_score, tis$group))
}
signif(rbind(骨髓 = report(bm), 斑块_共享程序 = report(pl_sh), 斑块_不同程序 = report(pl_sp)), 2)
```

```text
              破骨样细胞比例 细胞当重复的p 按供体汇总的p
骨髓                    0.19       2.7e-11       0.01100
斑块_共享程序           0.22       1.4e-28       0.00011
斑块_不同程序           0.21       1.1e-04       0.21000
```

读法：

- **骨髓和斑块（共享程序）：** 供体层面的 p 值分别为 0.011 和 0.00011，显著；
- **斑块（不同程序）：** 核心五基因不在这个组织的程序里，供体层面 p = 0.21，不显著，符合设计；
- 但把细胞当重复时，斑块（不同程序）的 p 值是 1.1e-4，**假阳性**。这又是第 6 章的伪重复。

### 8.4 跨组织比对：两个组织的程序是否重叠

做法：

1. 在每个组织里，定义"程序"= 破骨样细胞 vs 其余巨噬细胞的差异表达（每个基因的 log 倍数变化）。真实数据里要靠聚类和注释确定哪些是破骨样细胞，这里用真实标签；
2. 比较两个组织的程序：
   - 所有基因的 log 倍数变化的 Spearman 相关；
   - 各取上调最多的前 50 个基因，看重叠，用超几何检验；
3. 用置换检验给相关性一个 p 值。

**陷阱：** 两个组织共用同一批基因，基因的基线表达量有高有低。标准化（按总读数缩放）会让高表达基因的 log 倍数系统性地偏移，这个偏移在两个组织里是**共同的**，会造出一个假的相关。如果置换检验只是随机打乱基因，就看不出来。正确做法是**按表达量分箱后，只在同一档内打乱基因**，保留基线表达量带来的共同结构。

```r
# 程序比对：每个组织里，破骨样细胞 vs 其余细胞的 log 倍数变化（用真实标签；真实数据里要靠聚类和注释）
logfc <- function(tis) colMeans(tis$X[tis$ocl == 1, ]) - colMeans(tis$X[tis$ocl == 0, ])
fc_bm <- logfc(bm)
bin   <- cut(colMeans(bm$X), quantile(colMeans(bm$X), 0:20 / 20), include.lowest = TRUE, labels = FALSE)  # 按平均表达量分 20 档
shuffle_within_bins <- function(v) { out <- v; for (b in unique(bin)) { i <- which(bin == b); out[i] <- v[i][sample(length(i))] }; out }

compare <- function(fc2, nperm = 2000) {
  rho  <- cor(fc_bm, fc2, method = "spearman")
  top1 <- order(fc_bm, decreasing = TRUE)[1:50]; top2 <- order(fc2, decreasing = TRUE)[1:50]
  ov   <- length(intersect(top1, top2))                                      # 各取前 50 个上调基因，看重叠
  p_ov <- phyper(ov - 1, 50, ngene - 50, 50, lower.tail = FALSE)             # 超几何检验
  p1 <- (1 + sum(replicate(nperm, cor(fc_bm, sample(fc2), method = "spearman")) >= rho)) / (nperm + 1)           # 简单置换
  p2 <- (1 + sum(replicate(nperm, cor(fc_bm, shuffle_within_bins(fc2), method = "spearman")) >= rho)) / (nperm + 1)  # 分箱置换
  c(Spearman相关 = rho, 前50重叠 = ov, 重叠p = p_ov, 简单置换p = p1, 分箱置换p = p2)
}
signif(rbind(共享程序 = compare(logfc(pl_sh)), 不同程序 = compare(logfc(pl_sp))), 2)
```

```text
         Spearman相关 前50重叠   重叠p 简单置换p 分箱置换p
共享程序         0.35       40 1.2e-59     5e-04     0.001
不同程序         0.24        0 1.0e+00     5e-04     0.870
```

读法：

| 情形 | Spearman | 前 50 重叠 | 超几何 p | 简单置换 p | 分箱置换 p |
|---|---|---|---|---|---|
| 共享程序 | 0.35 | 40 | 1.2e-59 | 5e-04 | 0.001 |
| 不同程序 | 0.24 | 0 | 1.0 | 5e-04 | 0.87 |

- 共享程序：重叠 40 个基因，三种检验都显著；
- 不同程序：前 50 个基因**一个也没有重叠**，超几何检验不显著，分箱置换也不显著（p = 0.87）。但 Spearman 相关有 0.24，**简单置换 p 却是 5e-04（最小可能值）**，被共同的基线陷阱骗了。

所以报告里"比较程序重叠度"，**不要只报 Spearman 相关，要同时报前 N 个基因的重叠和分箱置换的 p 值**。

### 8.5 其他要注意的点

1. **不要直接比较不同数据集的原始分数。** 平台、深度、批次都不同。比较"方向"（携带者是否高于对照）和"排序"。
2. **程序基因在两个数据集里都要被检出。** 如果某个核心基因在斑块数据里几乎测不到，它就不应该进入评分。
3. **细胞注释的质量决定一切。** "破骨样细胞"是怎么在两个组织里定义的，要写清楚，最好用同一套标准。
4. **假说不成立也是结果。** 如果两个组织的程序不重叠（情形 T），这回答了问题：程序是组织特异的，不是共享的。报告提醒要把论文标题提前写成中性。

### 小结

- 程序评分用基于排名的方法更稳健；在供体层面比较，不要把细胞当重复。
- 跨组织比对要同时报相关、前 N 重叠，以及分箱置换的 p 值。
- 共同的基线表达会造出假的跨组织相关；简单置换看不出来。

## 9. ☆ 虚拟扰动：CellOracle、scTenifoldKnk、NicheNet 与 Geneformer

> 这一章带走什么：四种工具各自在做什么；为什么复杂模型必须和线性基线并排比较；"有没有方向正确的先验网络"为什么决定成败；怎么用已知答案回测。

### 9.1 要回答的问题

报告想检验的假说里有一个"可干预的节点"：抑制它，应该**同时**降低骨髓里的破骨样评分和斑块里的钙化评分。但谁来做这个实验？报告的第一步是**虚拟扰动**：用计算模型预测一个基因被敲除或抑制后，细胞状态会怎样变。

报告给出的工具分工：

- 转录因子：CellOracle；
- 非转录因子：scTenifoldKnk；
- 分泌因子：NicheNet 的配体活性；
- Geneformer：只做人类数据的推理，并与线性基线并排报告；
- 用已有答案做回测：TET2、MMP9、OSM、IL-20 都有已发表的敲除或中和实验。

### 9.2 四种工具各做什么

| 工具 | 输入 | 核心思路 | 擅长 | 局限 |
|---|---|---|---|---|
| CellOracle（Kamimoto 等，Nature 2023） | scRNA-seq，加上 scATAC-seq 或基序给出的"底图网络" | 先推断每种细胞类型自己的调控网络（转录因子到靶基因的系数），再把扰动沿网络一轮一轮传播，预测细胞状态变化 | 转录因子的敲除 | 依赖底图网络；线性假设；对间接调控和反馈有限 |
| scTenifoldKnk（Osorio 等，Patterns 2022） | 只需 scRNA-seq | 用单细胞数据构建基因网络，"敲除"某个基因就是把它发出的边设为 0，比较前后网络，找受影响的基因 | 没有转录因子注释的基因 | 网络本质是相关性网络，没有方向先验 |
| NicheNet（Browaeys 等，Nat Methods 2020） | 发送细胞、接收细胞的表达数据，加上"配体到靶基因"的先验知识 | 不预测敲除，而是回答"哪个配体最能解释接收细胞里观察到的基因变化"，输出配体活性排序 | 分泌因子、细胞间通讯 | 配体必须被发送细胞表达、受体必须被接收细胞表达；先验知识有偏 |
| Geneformer（Theodoris 等，Nature 2023） | 单细胞转录组 | 在约 3,000 万个人类单细胞转录组上预训练的 Transformer；把细胞变成按相对表达量排序的基因序列；"敲除"就是从序列里删掉这个基因，看细胞表征往哪里移动 | 无需自己建网络，可以一次测很多基因 | 黑箱；预测未必优于简单的线性基线 |

以上是概述，具体设计（回归方式、传播轮数、网络构建细节）以各自原文和文档为准。

### 9.3 实战 A：玩具基因调控网络和扰动传播

用一个"真相已知"的小网络演示原理。设计：

- 40 个基因，其中前 5 个是转录因子（TF）；
- TF1 调控 TF2（所以 TF2 不是"根"）；TF3 调控 TF5；
- 每个靶基因受 1 到 2 个 TF 直接调控；一部分靶基因还受其他靶基因调控（间接调控）；
- 真相：把某个基因敲到 0，其余基因的平均表达变化多少（由模型精确算出）。

```r
set.seed(61)
p <- 40; tf <- 1:5                                     # 40 个基因，其中前 5 个是转录因子（TF）
B <- matrix(0, p, p)                                   # B[j, k]：基因 k 对基因 j 的直接调控强度
B[2, 1] <- 0.9                                         # TF1 调控 TF2（TF2 不是“根”）
B[5, 3] <- 0.8                                         # TF3 调控 TF5
for (j in 6:p) {                                       # 每个靶基因受 1–2 个 TF 直接调控
  reg <- sample(tf, sample(1:2, 1))
  B[j, reg] <- sample(c(-1, 1), length(reg), TRUE) * runif(length(reg), 0.4, 0.9)
}
for (j in 21:p) B[j, sample(6:(j - 1), 1)] <- sample(c(-1, 1), 1) * runif(1, 0.3, 0.6)   # 靶基因之间的间接调控
mu <- c(rep(3, 5), rep(2, p - 5))                      # 每个基因的平均表达量
I_B <- diag(p) - B
cvec <- as.vector(I_B %*% mu)                          # 让平均表达量恰好等于 mu 的截距项
n <- 3000
X <- (matrix(cvec, n, p, byrow = TRUE) + matrix(rnorm(n * p), n, p)) %*% t(solve(I_B))   # x = (I-B)^-1 (c + e)
colnames(X) <- paste0("G", 1:p)

# 真相：把基因 k 敲除到 0（do 操作），其余基因的平均表达量变化多少
true_ko <- function(k) {
  Bk <- B; Bk[k, ] <- 0; ck <- cvec; ck[k] <- 0
  (solve(diag(p) - Bk) %*% ck)[, 1] - mu                # 敲除后的平均值 - 原来的平均值
}
```

三种预测方法：

- **线性基线：** 每个基因单独对被敲除的 TF 做回归，斜率乘以"敲到 0"的变化量；
- **传播（无先验）：** 任何 TF 都可以是任何基因的候选调控因子，用岭回归推断系数，再把扰动沿网络传播 3 轮（CellOracle 式思路的教学简化版，不是 CellOracle 本身）；
- **传播（有先验）：** 只允许"底图网络"里的边（相当于 scATAC-seq 给出的方向正确的候选边：真实的边都在，再混入 20% 的假候选边，但方向不会反）。

```r
# 做法 A（CellOracle 式思路的教学简化版）：先推断“调控因子 -> 基因”的系数，再把扰动沿网络传播 3 轮
ridge <- function(y, Z, lambda = 1) solve(crossprod(Z) + lambda * diag(ncol(Z)), crossprod(Z, y))
fit_grn <- function(cand) {                             # cand[j, k] = TRUE：允许基因 k 作为基因 j 的调控因子
  Bhat <- matrix(0, p, p)
  for (j in 1:p) if (any(cand[j, ]))
    Bhat[j, cand[j, ]] <- ridge(X[, j] - mean(X[, j]), scale(X[, cand[j, ], drop = FALSE], scale = FALSE))
  Bhat
}
cand_free <- matrix(FALSE, p, p); cand_free[, tf] <- TRUE; diag(cand_free) <- FALSE   # 无先验：任何 TF 都可能调控任何基因

cand_prior <- matrix(FALSE, p, p)                       # 有先验（相当于 scATAC-seq 给出的“底图网络”）：
cand_prior[, tf] <- (B != 0)[, tf]                      #   真实的 TF -> 基因 边都在
for (j in 1:p) for (k in tf) if (j != k && B[j, k] == 0 && B[k, j] == 0 && runif(1) < 0.2) cand_prior[j, k] <- TRUE   # 再混入 20% 的假候选边，但方向不会反

propagate <- function(Bhat, k, steps = 3) {
  delta <- numeric(p); delta[k] <- -mean(X[, k]); total <- delta
  for (s in seq_len(steps)) { delta <- as.vector(Bhat %*% delta); delta[k] <- 0; total <- total + delta }
  total
}
# 做法 B（线性基线）：每个基因单独对 TF k 做回归，斜率 × (0 - 平均表达量)
baseline <- function(k) sapply(1:p, function(j) cov(X[, j], X[, k]) / var(X[, k])) * (0 - mean(X[, k]))

auc <- function(score, truth) {                         # 用打分把“真正受影响的基因”排到前面的能力
  r <- rank(score); n1 <- sum(truth); n0 <- sum(!truth)
  (sum(r[truth]) - n1 * (n1 + 1) / 2) / (n1 * n0)
}
B_free <- fit_grn(cand_free); B_prior <- fit_grn(cand_prior)
evaluate <- function(k) {
  tr <- true_ko(k)[-k]; affected <- abs(tr) > 0.2       # 真相里变化超过 0.2 的基因
  pred <- list(线性基线 = baseline(k)[-k], 传播_无先验 = propagate(B_free, k)[-k], 传播_有先验 = propagate(B_prior, k)[-k])
  list(n = sum(affected), cor = sapply(pred, function(v) cor(tr, v)), auc = sapply(pred, function(v) auc(abs(v), affected)))
}
e1 <- evaluate(1); e2 <- evaluate(2)
cat("真相里受影响的基因数：TF1 =", e1$n, "；TF2 =", e2$n, "\n")
cat("\n预测与真相的相关系数\n");  round(rbind(`TF1（上游没有调控因子）` = e1$cor, `TF2（被 TF1 调控）` = e2$cor), 2)
cat("\n把受影响基因排到前面的能力（AUC）\n"); round(rbind(`TF1（上游没有调控因子）` = e1$auc, `TF2（被 TF1 调控）` = e2$auc), 2)
```

```text

预测与真相的相关系数
                        线性基线 传播_无先验 传播_有先验
TF1（上游没有调控因子）     1.00        1.00        0.99
TF2（被 TF1 调控）          0.72        0.73        0.97

```

读法：

1. **对没有上游调控因子的 TF1，线性基线已经几乎完美**（相关 1.00）。复杂模型没有用武之地。这就是为什么必须和线性基线并排比：它经常已经够好。
2. **对被 TF1 调控的 TF2，线性基线和无先验传播都只有 0.72 和 0.73。** 原因：TF1 的靶基因和 TF2 都相关（因为 TF2 本身受 TF1 驱动），两种方法都把这些基因误当成 TF2 的靶基因。调试时我还看到，无先验的回归会推断出"TF2 调控 TF1"这条反向边，于是扰动传到了 TF1 的靶基因上。
3. **有了方向正确的先验网络，相关升到 0.97，AUC 升到 0.88。** 这就是 CellOracle 要借助 scATAC-seq 给出"底图网络"的原因：它告诉模型哪些转录因子可能结合哪些基因，方向由结合位点固定。
4. 即使有先验，AUC 也只有 0.88：靶基因之间的间接调控没有被建模，仍有遗漏。

### 9.4 实战 B：NicheNet 的思路

NicheNet 不预测"敲除后会怎样"，而是反过来：**接收细胞里观察到了一批差异表达基因，哪个配体最能解释它们？**

玩具设计：30 个配体、300 个靶基因；先验知识是一个"配体到靶基因的调控潜力"矩阵；真正起作用的是配体 7，接收细胞里差异表达的基因是配体 7 的靶基因的 70%，再混入 15 个无关的噪声基因。每个配体的"活性"取它的先验潜力向量与"是否差异表达"之间的 Pearson 相关（NicheNet 默认用来给配体排序的度量）。

```r
set.seed(62)
n_lig <- 30; n_tar <- 300
P <- matrix(0, n_tar, n_lig)                            # 先验知识：配体 -> 靶基因的“调控潜力”
for (l in 1:n_lig) { tg <- sample(n_tar, 25); P[tg, l] <- runif(25, 0.2, 1) }
colnames(P) <- paste0("配体", 1:n_lig)
true_l <- 7                                             # 真正在起作用的配体
tg7 <- which(P[, true_l] > 0)
de <- integer(n_tar)                                    # 受体细胞里观察到的差异表达基因
de[sample(tg7, round(0.7 * length(tg7)))] <- 1L         # 配体 7 的靶基因里有 70% 被检出
de[sample(which(de == 0), 15)] <- 1L                    # 再混入 15 个无关的噪声基因
activity <- apply(P, 2, function(v) cor(v, de))         # NicheNet 的配体活性：先验潜力与差异基因的 Pearson 相关
round(sort(activity, decreasing = TRUE)[1:5], 3)
```

```text
 配体7 配体26  配体3 配体16 配体23 
 0.538  0.091  0.049  0.043  0.034 
```

配体 7 的活性是 0.538，排第一，第二名只有 0.091。

真实 NicheNet 的使用要点：

1. 先验模型整合了配体到受体、信号通路、基因调控三类数据库；
2. 配体必须在发送细胞里表达，受体必须在接收细胞里表达，否则"活性"没有意义；
3. 用于报告：发送细胞是 CHIP 突变单核细胞，接收细胞是瓣膜间质细胞，看 OSM 是否排在前面。报告说 OSM 的作用已有发表，这正好是一个"已知答案回测"。

### 9.5 实战 C：Geneformer 吃进去的是什么

Geneformer 的输入不是数字矩阵，而是**每个细胞一条按相对表达量排序的基因序列**。"相对"是指每个基因除以它在整个训练语料库里的典型表达水平，这样管家基因（GAPDH、ACTB）被压到末尾，细胞特异的基因排到前面。

```r
# Geneformer 的输入：把每个细胞变成“按相对表达量排序的基因序列”
cell   <- c(GAPDH = 120, ACTB = 90, MMP9 = 30, IL1B = 15, ACP5 = 8, CTSK = 5, TET2 = 2, OSM = 0)
ref_md <- c(GAPDH = 100, ACTB = 80, MMP9 = 5, IL1B = 4, ACP5 = 1, CTSK = 1, TET2 = 1, OSM = 1)   # 假想的全语料库中位数
rel    <- cell / ref_md                                 # 除以该基因在全语料库里的典型水平，压低“管家基因”
tokens <- names(sort(rel[rel > 0], decreasing = TRUE))
tokens
tokens_ko <- setdiff(tokens, "ACP5")                    # “计算机里敲除 ACP5”：把它从序列里删掉
rbind(原始 = match(c("MMP9", "CTSK", "TET2"), tokens), 删除ACP5后 = match(c("MMP9", "CTSK", "TET2"), tokens_ko))
```

```text
[1] "ACP5"  "MMP9"  "CTSK"  "IL1B"  "TET2"  "GAPDH" "ACTB" 
           [,1] [,2] [,3]
原始          2    3    5
```

序列里 ACP5 排第一，管家基因排在最后。"计算机里敲除 ACP5"就是把它从序列里删掉：其余基因的顺位整体上移（MMP9 从第 2 变第 1，CTSK 从第 3 变第 2，TET2 从第 5 变第 4）。Geneformer 再把删前和删后的细胞送进模型，看细胞的表征向"疾病"或"健康"状态移动了多少。

### 9.6 怎么回测，怎么对照

报告说要"用已知答案做回测"。回测的做法：

1. **选已有定论的扰动。** 如 TET2 敲除、MMP9 抑制、OSM 中和、IL-20 中和；
2. **定义指标。** 常用的有三个：
   - 方向一致率：预测的评分变化方向与已发表结果是否一致；
   - 排序能力：已知的下游基因在预测排序里的 AUC（见上面的玩具）；
   - 与线性基线的差值：复杂模型比基线好多少；
3. **并排报告基线。** Ahlmann-Eltze 等（Nat Methods 2025）发现，当时的深度学习扰动预测并没有跑赢简单的线性基线；报告引用的 Nat Methods 2025 一篇也得出了相同的结论。所以任何复杂模型的结果都必须同时给出基线；
4. **随机对照。** 随机选同样数量的基因做"虚拟敲除"，看评分变化的分布，给真实候选节点一个经验 p 值。

### 9.7 "双向判定"的逻辑和陷阱

报告的判定是：候选节点在髓系细胞里被抑制后，应当**同时**降低骨髓里的破骨评分和斑块里的钙化评分。

要注意：

1. **两个组织各用各的网络。** 调控网络是细胞类型特异的，不能把骨髓的网络直接套在斑块上。
2. **避免循环论证。** 如果评分用到的基因里包含候选节点自己（如 MMP9 既是候选节点又是评分基因），敲除它评分必然下降。评分基因集要排除候选节点。
3. **效应要大于噪声。** 对照随机节点的分布，别只看符号。
4. **报告两侧的效应量，不只是方向。** "同时降低"要有量化的标准。

### 小结

- CellOracle 借助底图网络、scTenifoldKnk 靠相关性网络、NicheNet 排序配体、Geneformer 靠预训练模型。
- 线性基线经常已经够好；复杂模型必须并排报告基线。
- 方向正确的先验网络是 CellOracle 类方法成败的关键。
- 用已知答案回测，并用随机节点做对照。

### 10.2 造一个玩具队列

10 万人，携带率约 3.3%（由报告里"跟骨 BMD 人群约 9,000 名携带者、27.9 万人"估出）。设计：

- CHIP 携带概率随年龄上升；
- 携带者中：DNMT3A 55%、TET2 18%、ASXL1 7%、其他 20%（常见的大致构成，仅为设定）；
- VAF 服从对数正态，使大克隆（VAF 不低于 0.1）约占 1/3（报告引用的 CHIP GWAS 里大克隆病例约占四成）；
- 骨密度（单位：标准差）随年龄下降、女性更低；CHIP 的真实效应设为：小克隆 DNMT3A −0.03、TET2 −0.08、ASXL1 −0.08、其他 0；大克隆在此基础上再减 0.12、0.18、0.20、0.05。**这些全是设定，不是真实效应大小。**

```r
group <- ifelse(chip == 0, "无CHIP", paste0(gene, ifelse(large == 1, "-大克隆", "-小克隆")))
group <- relevel(factor(group), ref = "无CHIP")
```

- 小亚组的估计会偏离真值：ASXL1 小克隆估计 −0.131（真值 −0.08），TET2 小克隆 −0.018（真值 −0.08），都落在一个 SE 的范围内。

**两个常见的误判：**

1. "一个亚组显著、另一个不显著，所以两者有差别"是错的。两个亚组的差别要用**交互项或对比检验**直接检验（Gelman 与 Stern，Am Stat 2006）。
2. 8 个亚组就是 8 次检验，要做多重检验校正（FDR 或 Bonferroni），并事先写好哪些是主要亚组。

### 10.6 骨折：Cox 比例风险模型

骨折是"时间到事件"的结局，用 Cox 模型。设定：骨折风险随年龄上升、女性更高、骨密度越低越高；大克隆另有一个直接效应。随访 10 年。

```r

t_ev <- rexp(N, 0.004 * exp(lin))                                                    # 事件时间（年）
```

### 10.7 共病分析：观察/期望比

报告要问："CHIP 携带者中'低骨密度 + 心血管事件'的联合发生率，是否高于两个单独风险的乘积？"

**为什么看乘积。** 如果两件事互相独立，同时发生的概率就等于各自概率的乘积。同时出现的次数比这个"期望"多，说明两件事在这批人里**结伴出现**。

**怎么算。** 观察/期望比 = 观察到的同时发生人数 ÷ 期望人数。期望 = 每个分层里 人数 × P(低骨密度) × P(心血管事件)，再加总。

**为什么要分层。** 年龄会让两件事天然结伴出现（越老越容易两者都有）。所以要在**年龄 × 性别**的分层里算，把年龄的作用拿掉。

**怎么读。** 只看携带者的比值是否大于 1 不够，还要和**非携带者**比。因为吸烟、肾功能、衰弱等共同原因，在没有 CHIP 的人群里也会让两件事结伴出现。

玩具模拟：两个世界，边际风险完全相同，区别只在**携带者内部的依赖结构**：

- 共享同一套程序：携带者体内有一个"程序强度"，同时推高低骨密度和心血管事件的风险；
- 各自独立：两件事各自有独立的"强度"，边际风险一样。

```r
# 共病：低骨密度和心血管事件是否“扎堆”出现在携带者身上？
sim_comorb <- function(shared) {
  u1 <- rnorm(N); u2 <- if (shared) u1 else rnorm(N)     # 携带者体内的“程序强度”：共享同一个 / 各自独立
  low <- rbinom(N, 1, plogis(-1.1 + 0.05 * (age - 55) + 0.5 * female + 0.3 * smoke + chip * (0.35 + 0.8 * u1)))
  cvd <- rbinom(N, 1, plogis(-2.8 + 0.07 * (age - 55) + 0.3 * (1 - female) + 0.5 * smoke + chip * (0.25 + 0.8 * u2)))
  data.frame(age, female, chip, low, cvd)
}
oe <- function(d) {                                       # 在“年龄 x 性别”分层里：观察到的同时出现 vs 各自风险相乘的期望
  st <- interaction(cut(d$age, seq(40, 70, 5), include.lowest = TRUE), d$female)
  O <- sum(d$low & d$cvd)
  E <- sum(sapply(split(d, st), function(s) nrow(s) * mean(s$low) * mean(s$cvd)))
  c(观察 = O, 期望 = E, 比值 = O / E)
}
boot_ci <- function(d, B = 300) quantile(replicate(B, oe(d[sample(nrow(d), replace = TRUE), ])[3]), c(0.025, 0.975))
summarize <- function(d) {
  car <- oe(d[d$chip == 1, ]); non <- oe(d[d$chip == 0, ]); ci <- boot_ci(d[d$chip == 1, ])
  c(携带者_观察 = car[[1]], 携带者_期望 = round(car[[2]], 1), 携带者_比值 = round(car[[3]], 2),
    比值_下限 = round(ci[[1]], 2), 比值_上限 = round(ci[[2]], 2), 非携带者_比值 = round(non[[3]], 2))
}
set.seed(72)
rbind(`共享同一套程序` = summarize(sim_comorb(TRUE)), `各自独立` = summarize(sim_comorb(FALSE)))
```

```text
共享同一套程序         336       274.4        1.22      1.15      1.29          1.03
各自独立               298       297.5        1.00      0.93      1.07          0.99
```

读法：共享世界里，携带者的 O/E 是 1.22，明显大于 1，而非携带者只有 1.03；独立世界里携带者的 O/E 是 1.00。两个世界里携带者的边际风险一样，但 O/E 能把它们区分开。

**但 O/E > 1 不能证明"同一套破骨样程序"。** 任何让两件事结伴的共同原因都会造成 O/E > 1（炎症、肾功能、衰弱、药物……）。要加强这条证据，可以：

1. 与非携带者比较（做法如上）；
2. 看剂量反应：大克隆的 O/E 是否高于小克隆；
3. 尽可能调整更多的共同原因；
4. 更严格地，用多状态模型或多项逻辑回归，联合建模"都没有、只有骨、只有血管、两者都有"四种结局。

### 小结

- 不调整年龄，CHIP 对骨密度的效应会被放大近 6 倍。
- 分层要比较"交互"，不是比较"谁显著"；亚组多了要做多重检验。
- 跟骨 BMD 的样本基本够，DXA 里 ASXL1 只能检出大效应。

读法：

- MMP9：小分子和抗体都有"Advanced Clinical"（进入后期临床）的证据；
- CTSK：小分子有后期临床证据；
- IL20：抗体有后期临床证据；
- ACP5、OSM：没有可成药性的证据；
- NFATC1、TET2：只有早期线索（"高质量配体"、"带配体的结构"）。

**这些标签只表示"可成药性证据的成熟程度"，不表示"有效"或"安全"。** 一个基因在后期临床里有药，不代表对骨和血管同时有益，更要看同时抑制两侧的假说。

报告还提到 drug2cell：把药物与靶点的关系映射到单细胞表达数据上，看一种药的靶点在哪些细胞里表达，用来判断药物可能作用于哪类细胞。本讲义没有运行这个工具，以原文为准。

### 11.5 影像 AAC 评分

腹主动脉钙化（AAC）是报告里"唯一的短板"：UK Biobank 里没有现成的 AAC 评分，要在 5 万张侧位脊柱 DXA 影像上自建。

**评分标准。** 常用的是 Kauppila 的 AAC-24：看腰椎 L1 到 L4 四个节段的腹主动脉前壁和后壁，每个位置按钙化长度打 0 到 3 分（0 无；1 小于 1/3；2 在 1/3 到 2/3 之间；3 大于 2/3），共 8 项，满分 24 分。

**自动评分模型怎么评价。** 模型从影像预测 AAC-24，要和人工评分比较，常看三个指标：

- Spearman 相关：排序是否一致；
- 二次加权 kappa：考虑"差几分"的一致性；
- 临床分组的一致率：如 0 分、1 到 5 分、6 分以上（示例分组）。

下面用模拟数据演示这三个指标怎么算：

```r
# Kauppila 的 AAC-24：腰椎 L1–L4 四个节段，每段的前壁、后壁各打 0–3 分（钙化长度：0 无；1 小于 1/3；2 在 1/3 到 2/3 之间；3 大于 2/3），共 8 项，满分 24
aac24 <- function(scores) { stopifnot(length(scores) == 8, all(scores %in% 0:3)); sum(scores) }
aac24(c(0, 0, 1, 0, 2, 1, 3, 2))

# 评估一个自动评分模型：和人工评分比较
set.seed(81)
n <- 500
manual <- pmin(24, rpois(n, 3) * (runif(n) < 0.6))                 # 人工评分（模拟）：很多人是 0 分
model  <- pmin(24, pmax(0, round(manual + rnorm(n, 0, 1.5))))      # 模型评分 = 人工评分 + 误差（模拟）
wkappa <- function(a, b, K = 25) {                                 # 二次加权 kappa（0–24 分共 25 档）
  W <- outer(0:(K - 1), 0:(K - 1), function(i, j) (i - j)^2 / (K - 1)^2)
  O <- table(factor(a, 0:(K - 1)), factor(b, 0:(K - 1))) / length(a)
  E <- outer(rowSums(O), colSums(O))
  1 - sum(W * O) / sum(W * E)
}
cat_of <- function(x) cut(x, c(-1, 0, 5, 24), labels = c("0分", "1–5分", "6分以上"))   # 常见的临床分组（示例）
c(`Spearman 相关` = cor(manual, model, method = "spearman"), `二次加权kappa` = wkappa(manual, model),
  `分组一致率` = mean(cat_of(manual) == cat_of(model)))
table(人工 = cat_of(manual), 模型 = cat_of(model))
```

```text
[1] 9
Spearman 相关 二次加权kappa    分组一致率 
    0.8072636     0.8029155     0.7200000 
         模型
人工    0分 1–5分 6分以上
  0分     129    78       0
  1–5分    24   209      31
  6分以上   0     7      22
```

读法：这个模拟模型的 Spearman 相关 0.81，二次加权 kappa 0.80，三个分组的一致率 72%。混淆表显示"0 分"里有 78 人被模型判成"1 到 5 分"。**排序和加权 kappa 都不错的模型，在分组边界处仍然会有不少误分**，所以用于分组分析前，要在边界附近单独评估，并且报告人工评分者之间的一致性作为上限参考。

### 小结

- 用 GWAS Catalog 的 API 核对编号和出处，下载时先看文件头、尺度和基因组版本。
- 检索量可以量化"没人做过"，但命中条数必须人工读；只能说没找到。
- Open Targets 的可成药性只说明证据成熟程度，不说明疗效。
- AAC 评分模型要同时看相关、加权 kappa 和分组一致率。

## 12. ★ 把它们串起来：三阶段流水线与"三取二"立项规则

> 这一章带走什么：各步骤怎么衔接；"三条满足两条就立项"的规则在统计上意味着什么；每条判据里隐含的多重检验；"没有信号"和"功效不足"怎么区分。

### 12.1 流水线

```text
公开 GWAS 汇总统计 --+--> 遗传相关 (LDSC, HDL) --> 局部相关 (LAVA, SUPERGNOVA) --> 共定位 (coloc, SuSiE-coloc)
                     |
                     +--> MAGMA 基因分数 --> scDRS / scPagwas --+
                                                                |
单细胞数据 --> 质控与注释 --> 程序评分 --> 跨组织比对 ---------+--> 第 6 周 Go/No-Go (三取二)
                                                                |
UK Biobank Tier 1 --> 个体级分层分析、共病分析 ----------------+--> 第 9 个月判定
```

每一步的输入、输出和最常见的坑：

| 步骤 | 输入 | 输出 | 最常见的坑 |
|---|---|---|---|
| LDSC、HDL | 两份汇总统计 + LD 分数 | h²、rg、截距 | 有效样本量太小；尺度；人群不匹配 |
| LAVA、SUPERGNOVA | 同上 + 区块划分 | 每个区块的局部 rg | 局部遗传度不显著；多重检验 |
| coloc、SuSiE-coloc | 一个区域的两份汇总统计 + LD | PP.H0 到 PP.H4 | 等位基因没对齐；多信号；LD 不匹配 |
| MAGMA、scDRS | 汇总统计 + 单细胞图谱 | 每个细胞或细胞类型的疾病分数 | 对照不匹配；图谱里没有目标细胞 |
| 程序评分与比对 | 单细胞表达 + 基因集 | 每个供体的程序分数；跨组织重叠 | 把细胞当重复；共同基线造成的假相关 |
| 虚拟扰动 | 单细胞表达 + 先验网络 | 预测的评分变化 | 不比线性基线；无方向先验 |
| 个体级分析 | UKB 表型 + CHIP 字段 | 分层效应、HR、O/E | 年龄混杂；多重检验；共同原因 |

### 12.2 "三取二"的统计性质

规则：三条判据里满足两条就立项。假设三条判据互相独立，每条在"没有真实关系"时偶然满足的概率是 α，在"真实关系存在"时满足的概率（功效）是 π。

```r
# “三条满足两条就立项”：假设三条判据互相独立，每条在“没有真实关系”时偶然满足的概率是 alpha，
# 在“真实关系存在”时满足的概率（功效）是 pw
p_atleast2 <- function(p) {                            # p：三条判据各自满足的概率（可以各不相同）
  z <- expand.grid(rep(list(0:1), 3))
  sum(apply(z, 1, function(r) if (sum(r) >= 2) prod(ifelse(r == 1, p, 1 - p)) else 0))
}
alpha <- c(0.25, 0.10, 0.05, 0.01); pw <- c(0.5, 0.7, 0.9)
false_go <- sapply(alpha, function(a) p_atleast2(rep(a, 3)))       # 没有真实关系时，误判“立项”的概率
true_go  <- sapply(pw, function(w) p_atleast2(rep(w, 3)))          # 关系真实存在时，正确“立项”的概率
data.frame(每条判据的假阳性率 = alpha, 误判立项的概率 = signif(false_go, 2))
data.frame(每条判据的功效 = pw, 正确立项的概率 = round(true_go, 3))
```

```text
  每条判据的假阳性率 误判立项的概率
1               0.25         0.1600
2               0.10         0.0280
3               0.05         0.0072
4               0.01         0.0003
  每条判据的功效 正确立项的概率
1            0.5          0.500
2            0.7          0.784
3            0.9          0.972
```

| 每条判据的假阳性率 α | 没有真实关系时误判"立项"的概率 |
|---|---|
| 0.25 | 0.16 |
| 0.10 | 0.028 |
| 0.05 | 0.0072 |
| 0.01 | 0.0003 |

| 每条判据的功效 π | 关系真实存在时正确"立项"的概率 |
|---|---|
| 0.5 | 0.500 |
| 0.7 | 0.784 |
| 0.9 | 0.972 |

读法：

- "三取二"比"单条通过"严格得多：即使每条判据的假阳性率高达 25%，整体误判立项也只有 16%；每条降到 5%，只有 0.7%。
- 但它同时降低了"正确立项"的概率：每条判据的功效只有 0.5 时，正确立项的概率只有 0.5。**功效是这一层的主要风险。** CHIP 的有效样本量只有几万甚至几千（第 3 章），每条判据的功效很可能不高。

### 12.3 判据 1 里隐含的多重检验

判据 1 是"CHIP（或其任一亚型）与 eBMD、AAC、CAC 中至少两个表型存在显著的局部遗传相关或共定位信号"。这里面有大量检验：4 个 CHIP 表型 × 3 个结局表型共 12 对，每对要在约 2,500 个基因组区块里找局部相关。

```r
# 判据 1 的多重检验：4 个 CHIP 表型 x 3 个结局表型 = 12 对；每对要在约 2,500 个基因组区域里找局部相关
n_reg <- 2495
q_raw  <- 1 - (1 - 0.05)^n_reg                       # 每个区域 p<0.05，不校正：几乎一定“找到”
q_bonf <- 1 - (1 - 0.05 / n_reg)^n_reg               # 区域间 Bonferroni 校正后：每对约 5%
per_outcome <- 1 - (1 - q_bonf)^4                    # 一个结局表型，4 个 CHIP 表型里至少 1 个“找到”
c(`不校正：每对偶然找到的概率` = q_raw, `校正后：每对` = q_bonf, `校正后：某个结局表型至少配上 1 个 CHIP 表型` = per_outcome,
  `判据1（至少两个结局表型）偶然满足的概率` = p_atleast2(rep(per_outcome, 3)))
```

```text
                 不校正：每对偶然找到的概率                                校正后：每对 
                                 1.00000000                                  0.04877105 
校正后：某个结局表型至少配上 1 个 CHIP 表型     判据1（至少两个结局表型）偶然满足的概率 
                                 0.18127089                                  0.08666460 
```

| 量 | 数值 |
|---|---|
| 不校正：每对在 2,495 个区块里至少"找到"一个的概率 | 约 100% |
| 区块间 Bonferroni 校正后：每对 | 4.9% |
| 校正后：某个结局表型至少配上 1 个 CHIP 表型 | 18% |
| 判据 1（至少两个结局表型）偶然满足的概率 | 8.7% |

读法：

- **不校正，几乎一定"找到"**，所以必须校正。
- 即使校正了每一对，由于有 4 个 CHIP 表型，"某个结局至少配上一个"的偶然概率涨到 18%；要求"至少两个结局"后，判据 1 整体偶然满足的概率仍有 8.7%。（这里假设 4 个 CHIP 表型互相独立；实际上它们高度相关，有效个数更少，这个数会偏高。）
- 所以方案里要写清：校正的范围（区块之间、表型对之间）、显著的阈值，以及"至少两个结局"是否要在同一个 CHIP 亚型上。

把三条判据放在一起看一个示意性的组合：判据 1 取上面的 8.7%；判据 2 假设每次检验 5%；判据 3 只要求"两个组织的方向相同"，偶然满足的概率是 25%（两个方向各有一半可能）。

```r
# 一个示意性的组合：判据 1 用上面校正后的数；判据 2 假设每次检验 5%；
# 判据 3 只要求“两个组织的方向相同”，偶然满足的概率是 25%；如果改成“两个组织各自单侧 p<0.05”，则是 0.05 × 0.05
round(c(`原方案（判据3只看方向）` = p_atleast2(c(per_outcome, 0.05, 0.25)),
        `判据3要求各自显著`       = p_atleast2(c(per_outcome, 0.05, 0.05 * 0.05))), 3)
```

```text
原方案（判据3只看方向）       判据3要求各自显著 
                  0.062                   0.010 
```

原方案的整体误判立项概率是 6.2%。**判据 3 是最松的一条**：只看方向，一半一半。如果改成要求两个组织各自的程序评分都单侧显著（p<0.05），整体误判降到 1.0%。（这些都是示意性的假设，具体数值取决于你如何定义每条判据。）

### 12.4 "没有信号"的两种含义

三条全部不满足，报告的建议是不花 UK Biobank 的钱。要注意：**"没有信号"可能是假说不成立，也可能只是功效不足。**

怎么区分：

1. 看每条判据的**区间和效应上限**，而不是只看"显著与否"。区间很窄且覆盖 0，是对"大效应"的否定；区间很宽，说明功效不足；
2. 把 CHIP 的有效样本量写进方案（第 3 章），评估能检出多大的遗传相关；
3. 对"有可能因为功效不足而漏掉"的判据，事先写好"如果这一条不通过，如何补救"（如换更大的多祖源 GWAS）。

### 12.5 计算能证明什么

报告自己说得很清楚：**没有任何公开数据集同时具备"人骨组织或骨髓 + CHIP 基因型"。** 所以纯计算路径只能做到"程序层面的跨组织比对"。遗传学证据说明"共享遗传基础"，单细胞证据说明"程序重叠"，队列证据说明"结局结伴出现"，这三者合起来支持假说，但不能证明"CHIP 通过这套程序同时导致骨丢失和血管钙化"。要做到因果，小鼠骨髓移植实验不可省。

### 小结

- 流水线分三层：遗传学、单细胞、队列，各自有不同的坑。
- "三取二"能压低假阳性，但会放大对功效的依赖。
- 判据里隐含的多重检验要事先写清楚；没有信号要区分"假说错"和"功效不足"。

## 13. ★ 常见错误

| 技术 | 错误 | 后果 | 怎么避免 |
|---|---|---|---|
| LDSC、HDL | 忽略有效样本量和尺度 | 遗传度不可比、标准误大 | 用有效样本量；二分类性状换算尺度 |
| LDSC、HDL | 只看全局 rg | 正负抵消被漏掉 | 加局部方法 |
| LDSC、HDL | 用不匹配的人群的 LD 分数 | 偏倚 | 人群一致 |
| 局部 rg | 不检验局部遗传度就估计 rg | rg 不稳定 | 先过滤 |
| 局部 rg | 不校正区块数 | 假阳性 | Bonferroni 或 FDR |
| coloc | 等位基因没对齐、基因组版本不一致 | 结果无意义 | 先协调 |
| coloc | 多信号区域仍用单变量 coloc | 误判 H3（本章例子里 PP.H3 = 1） | 用 SuSiE-coloc |
| coloc | SuSiE 的 LD 矩阵与人群不匹配 | 假的可信集 | 同人群 LD |
| coloc | 把低 PP.H4 当成"没有共定位" | 误读功效不足 | 同时看 PP.H0、PP.H1、PP.H2 |
| 单细胞 | 把细胞当重复 | 假阳性（本章例子里 67%） | 供体层面分析 |
| 单细胞 | 直接比较不同数据集的原始分数 | 批次、平台造成的差异 | 比较方向和排序 |
| scDRS | 用朴素的随机对照 | 所有细胞类型都"显著" | 表达量匹配的对照 |
| scDRS | 图谱里没有目标细胞类型 | 漏掉真正的靶细胞 | 先确认图谱覆盖 |
| 程序比对 | 只报 Spearman，用简单置换 | 共同基线造成假相关 | 前 N 个基因重叠 + 分箱置换 |
| 程序评分 | 评分基因包含被扰动的候选节点 | 循环论证 | 评分基因集排除候选节点 |
| 虚拟扰动 | 不与线性基线并排 | 高估复杂模型 | 同时报告基线 |
| 虚拟扰动 | 没有方向先验的网络 | 把方向弄反 | 底图网络 |
| 队列 | 不调整年龄 | 效应放大近 6 倍 | 调整年龄和性别等 |
| 队列 | 一个亚组显著、一个不显著就说有差别 | 误判 | 交互项或对比检验 |
| 共病 | O/E > 1 就当成共享程序的证据 | 共同原因也能造成 | 与非携带者比较、看剂量反应 |
| Go/No-Go | 事后定阈值 | 假阳性 | 事先写进方案 |
| 数据 | 把出处写错 | 引用错误 | 用 API 核对编号和 PMID |

## 14. ★ 自测题

先自己答，再看后面的答案。

1. VAF = 0.10 的杂合突变，大约有多少比例的细胞带这个突变？
2. 为什么外显子测序对小克隆不敏感？
3. LDSC 的截距和斜率分别代表什么？
4. 为什么 LDSC 估计的遗传相关对样本重叠稳健？
5. 病例 2,041、对照 173,918，有效样本量大约是多少？这意味着什么？
6. 全局 rg 约等于 0，能不能说两个性状没有共享？
7. 局部遗传相关方法为什么要先检验局部遗传度？
8. coloc 里 PP.H3 很高，一定是"两个性状因果变异不同"吗？
9. SuSiE-coloc 比 coloc 多做了什么？
10. 比较携带者和对照的单细胞表达，统计的重复单位是什么？为什么？
11. scDRS 为什么要用匹配的对照基因集？
12. 跨组织比对时，为什么简单置换会给出假阳性？
13. 虚拟扰动为什么要并排报告线性基线？
14. 共病分析的 O/E 比为什么要在年龄 × 性别的分层里算，并和非携带者比？
15. "三取二"规则为什么要事先定好每条判据的阈值？

### 参考答案

1. 约 20%。带突变的细胞比例约等于 2 × VAF。
2. 小克隆的 VAF 低，在有限的测序深度下，支持突变的读段数太少，达不到检出阈值。所以数据里的小克隆是被"截尾"的，"非携带者"里混着看不见的小克隆。
3. 斜率 = N h² ÷ M，给出遗传度；截距 = 1 + N a，反映人群分层等混杂，没有混杂时约等于 1。
4. 样本重叠只改变跨性状回归的截距（ρ N_s ÷ √(N1 N2)），不改变斜率；rg 由斜率和两个遗传度算出。
5. 4 ÷ (1/2,041 + 1/173,918) ≈ 8,069。相当于一个只有约 8,000 人的均衡样本，LDSC 的功效会很低，遗传度和遗传相关的估计都不稳。
6. 不能。正负相关的区域可以互相抵消，使全局 rg 接近 0。要用局部方法逐区块检验。
7. 没有局部遗传信号时，局部 rg 的分母接近 0，估计极不稳定。先检验局部遗传度，只在两个性状都有信号的区块里估计 rg。
8. 不一定。区域里有多个独立信号、而真正共享的是较弱的次要信号时，单一因果变异的 coloc 也会给出高的 PP.H3（本章 5.6 的例子）。要用 SuSiE-coloc 按可信集配对。
9. 先用 SuSiE 把每个性状的信号拆成若干可信集，再对每一对可信集做共定位，从而允许一个区域里有多个因果变异。需要匹配的 LD 矩阵。
10. 供体（人）。同一个供体的细胞共享这个供体自己的基线，不是独立样本。把细胞当重复，假阳性会大量出现（本章 6.5 的例子里 67%）。
11. 疾病基因集往往表达量偏高。与随机基因比，所有细胞类型的分数都会偏高，没有分辨力。匹配表达量的对照才能反映"这个基因集在某类细胞里是否额外偏高"。
12. 两个组织共用同一批基因，基线表达量带来的、被标准化放大的系统性偏移在两边是共同的，造出假的相关。简单置换把基因随机打乱，破坏了这种结构，所以看不出来。应在同一表达量分档内置换。
13. 线性基线经常已经够好（如根转录因子的情形），复杂模型只有明显优于基线才有价值；没有基线，就无法判断复杂模型有没有真正学到东西。
14. 年龄会让两件事天然结伴出现，分层把它拿掉；吸烟、肾功能等共同原因在非携带者里也会让 O/E 偏离 1，所以要和非携带者比，看携带者是否额外结伴。
15. 事后定阈值会让假阳性不可控；而且判据 1 里有大量隐含的多重检验，不事先写清楚校正范围，立项判断就失去统计意义。

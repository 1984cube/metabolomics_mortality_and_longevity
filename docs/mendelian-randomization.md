## 1. 它在估计哪一个数

孟德尔随机化（Mendelian randomization, MR）把生殖细胞里的遗传变异当作工具变量，用来估计暴露对结局的因果效应。

观察性关联回答的是：暴露 X 高的人，结局 Y 是不是也高。因果问题是：在一个写明的人群里，把 X 提高一个单位，Y 平均改变多少。两者的差别来自混杂和反向因果。混杂因素同时推动 X 和 Y，回归系数里就混着混杂因素的作用。疾病本身也会改变体重、血脂和很多代谢物，于是在已经患病的人里测到的 X，有一部分是 Y 的后果。

随机对照试验把干预分配出去，从而切断混杂与干预的联系。吸烟、终身的低密度脂蛋白水平、血浆代谢物浓度、教育年限，都不能这样分配。MR 用的是另一套已经发生过的分配。

单个工具变量的估计是 Wald 比值：

```text
θ = β(G→Y) / β(G→X)
```

分子是这个遗传变异在结局上的关联，分母是它在暴露上的关联。一个等位基因让 LDL 升高 0.2 mmol/L，同时让冠心病的 log-odds 升高 0.04，那么每 1 mmol/L 对应的 log-odds 是 0.04 / 0.2 = 0.2。

这个比值等于全体平均因果效应，需要下面几件事同时成立：

- 变异真的推动暴露（相关性）
- 变异与暴露–结局关系的混杂独立（独立性）
- 变异只通过暴露影响结局（排他性）
- 因果效应在人与人之间相同（同质性）

同质性不成立时，比值仍然可以是一个加权平均，权重是“这个工具把每个人的暴露推动了多少”。它不再自动等于把全体受试者按同样幅度改变暴露时的平均效应。

## 2. 随机化发生在什么时候

随机化发生在减数分裂。给定父母在一个位点上的基因型，子女得到两个等位基因中的哪一个是随机的。这是分离律，随机化的单位是家系内部的传递。

用一群没有血缘关系的人做 MR，是把这套家系内随机性外推到整个人群。外推还要求：人群分层、选型交配，以及父母基因型经由家庭环境对子女的影响，都没有在基因型和结局之间留下通路。同胞差异、三联体里传递与未传递等位基因的比较，把父母基因型消去，因此比普通的全基因组关联研究（GWAS）摘要统计更接近“孟德尔随机化”这几个字的原意。

Katan 在 1986 年用载脂蛋白 E 把这个设计说清楚了。当时的观察是低胆固醇与癌症相关，但临床前期的癌症本身就会把胆固醇拉低。APOE 基因型改变胆固醇，癌症改变不了已经形成的基因型。如果低胆固醇会致癌，那么降低胆固醇的 APOE 等位基因应当带来更高的癌症风险。基因型在这里是胆固醇的工具。它不是回归里多放进去的一个协变量。

后来的形式化把这件事写成工具变量。Davey Smith 与 Ebrahim 在 2003 年把这个设计介绍进流行病学。Didelez 与 Sheehan 在 2007 年写明了它和工具变量识别条件的对应关系。

## 3. 结构方程和识别公式

线性、同质效应的结构方程是：

```text
X = α0 + α G + δ U + ν
Y = β0 + τ X + γ U + ε
```

符号的含义：

| 符号 | 含义 |
|---|---|
| X | 暴露，例如 BMI、LDL、某一个代谢物 |
| Y | 结局，例如疾病、死亡 |
| G | 遗传工具，一个变异或一组变异 |
| U | 混杂，常常测不到 |
| τ | X 对 Y 的因果效应，这是目标参数 |
| α | G 对 X 的第一阶段效应 |
| ν, ε | 各自的剩余变异 |

若 G 与 (U, ν, ε) 独立，α ≠ 0，并且 Y 的方程里没有 G 的直接项，则：

```text
Cov(G, X) = α Var(G)
Cov(G, Y) = τ α Var(G)
τ = Cov(G, Y) / Cov(G, X)
```

样本里用两个回归系数的比：

```text
θ̂ = β̂(G→Y) / β̂(G→X)
```

若排他性失败，G 还有一个不经过 X 的直接效应 π，则：

```text
θ = τ + π / α
```

偏倚等于直接效应除以第一阶段效应。π 固定时，工具越强，α 越大，这条旁路把比值带偏的程度越小。

若直接效应和工具强度成比例，π = κ α，则：

```text
θ = τ + κ
```

κ 不会因为工具变强而消失。数据里每一点遗传关联都像是“通过 X 发生的因果”。这就是相关水平多效。再大的 GWAS、再小的标准误，都不会把它消掉。换估计量也未必消得掉。能对付它的是设计：使用不走那条共享通路的工具，通常是因果基因附近的顺式变异，并用共定位确认疾病信号和暴露信号是同一个变异。

多个工具、效应因人而异时，Wald 比值和它的加权平均识别的是按第一阶段效应加权的平均，权重大的是被这个基因型推得更远的人。不同 SNP 的“被推动者”不是同一群人。

## 4. 因果图

标准图里有四样东西。

```text
        G                  U
        |                 / \
        v               v   v
        X  -----------> Y
```

- 实线 G → X → Y 是要估计的因果通路。
- U → X 和 U → Y 是混杂。独立性说的是：没有 U → G。基因型不是被混杂分配的。
- 反向因果可以写成 Y → X。只要没有 Y → G，工具仍然只携带 X → Y 这个方向的信息。疾病可以把代谢物测低，但疾病改变不了生殖细胞基因型。

水平多效再加上一条绕开暴露的路：

```text
        G ----------------------+
        |                       |
        v                       v
        X  ------------------>  Y
        ^                       ^
        |                       |
        +---------- U ----------+
```

这条 G → Y 的弯路一旦存在，Wald 比值就等于 τ + π / α，不再是暴露本身的效应。

垂直多效是另一条路，应当留在总效应里：

```text
G → X → 中介 → Y
```

LDL 受体的变异先改变 LDL，再改变动脉粥样硬化，再改变冠心病。中介是 X 发挥作用的方式。把中介通路上的变异从工具里剔除，估计的就不再是 X 的总效应。

读图时固定三句话：

1. G → X → Y 是目标通路。
2. U 可以指向 X 和 Y，不可以指向 G。
3. G 直接指向 Y，排他性就失败了。Y 指向 X 可以存在，只要 Y 不指向 G。

## 5. 三条假设，以及第四个决定参数的条件

| 假设 | 内容 | 数据能做什么 | 最常见的失败方式 |
|---|---|---|---|
| 相关性 | Cov(G, X) ≠ 0，工具真的推动暴露 | 能检验。单个 SNP 的 F = (βX / SEX)²。多个工具看平均 F，或遗传得分的 R² | 把显著性阈值放宽；暴露 GWAS 太小；多变量模型里条件 F 塌掉 |
| 独立性 | G 与 X–Y 的混杂独立 | 不能直接检验 | 人群分层、选型交配、遗传养育、进入队列的选择 |
| 排他性 | G 影响 Y 的唯一路径是 X | 不能证实。敏感性分析只是在检查结果对某些失败方式敏不敏感 | 水平多效；工具 SNP 与邻近的另一个因果基因连锁 |
| 同质性，或单调性 | 效应对每个人相同；二分类暴露时没有被工具往反方向推的人 | 通常作为假设写下来，而不是作为一个检验 | 效应修饰；不同位点对应不同的局部人群 |

F > 10 来自弱工具文献。单个内生变量时，两阶段最小二乘相对于普通最小二乘的偏倚，大约被压到普通最小二乘偏倚的十分之一附近。它是经验界，不是生物学定律。平均 F 刚刚超过 10、SNP 又很多时，整套工具仍然可以偏弱。

相关性失败时，估计会不稳，偏倚方向见第 10 节。独立性和排他性失败时，p 值仍然可以很小。精度高只说明加权平均离开了 0，不说明加权平均等于 τ。

## 6. 垂直多效和水平多效

垂直多效的路径是 G → X → 下游中介 → Y。问题如果是 X 的总效应，这段路径要保留。CRP 若只是 LDL 升高之后的伴随现象，LDL 工具同时关联 CRP，并不破坏“LDL 对冠心病”的排他性。

水平多效的路径是同一个变异另外作用到结局。APOE 既改变脂蛋白，也通过淀粉样蛋白通路影响阿尔茨海默病。用 APOE 做“LDL 对阿尔茨海默病”的工具，排他性不成立。用它做 LDL 对冠心病，生物学上合理得多，仍然经常被单独拿掉做敏感性分析，因为这个位点的效应和多效都特别强。

水平多效再分成两种，处理它们的方法不同。

| 类型 | InSIDE | 对 IVW 的含义 | Egger 还能不能把 τ 分离出来 |
|---|---|---|---|
| 不相关水平多效：各 SNP 的直接效应与 βX 无关 | 成立 | 直接效应均值为 0 时，点估计仍对着 τ，多余变异变成异质性。均值不为 0 时，点估计偏移 | 截距接住非零均值，斜率仍可以对着 τ |
| 相关水平多效：直接效应与 βX 成比例 | 不成立 | 点估计对着 τ 加上那条共享通路的效应 | 斜率同样被带走。截距可以仍是 0 |

InSIDE 的全称是 Instrument Strength Independent of Direct Effect：跨 SNP 看，直接效应与该 SNP 对暴露的效应相互独立。

CRP 把两种工具的差别示范得很清楚。观察性数据里 CRP 与冠心病强烈相关。CRP 基因附近、改变 CRP 蛋白本身的顺式变异，并不带来冠心病风险的升高。基因组里另外很多与 CRP 相关的位点，上游是肥胖和炎症；用那些位点做工具，等于把肥胖的效应算进“CRP 的效应”。顺式工具回答“这个分子本身怎么样”。全基因组工具回答“所有把这个测量值推高的生物学混在一起怎么样”。

## 7. 相关多效为什么看起来像因果

把第 3 节的公式再写一次，因为后面每种稳健方法都绕着它转。

直接效应是一个与工具强度无关的常数时：

```text
βY = τ βX + π
θSNP = βY / βX = τ + π / βX
```

βX 小的 SNP，比值会被 π / βX 甩得很远。漏斗图因此不对称。Egger 回归允许一条不穿过原点的直线，用截距接住 π，用斜率估计 τ。这要求两件事：π 的均值与 βX 独立；βX 的测量误差小到不会把斜率稀释掉。后一条叫 NOME（NO Measurement Error）。工具弱时 NOME 失败，Egger 斜率偏向 0。

直接效应与 βX 成比例时：

```text
βY = τ βX + κ βX = (τ + κ) βX
```

截距是 0，斜率是 τ + κ。IVW、中位数、Egger 看到的是同一条过原点的线。谁更稳健都没有用，因为无效工具和有效工具长得一样。

这种结构会出现在：为 CRP 挑选的位点大多也关联 BMI，而 BMI 既推动 CRP，也推动疾病。位点越“像”CRP 的好工具，越可能同时是 BMI 的工具。CAUSE 试图用全基因组摘要把“共享因素”和“通过暴露的因果效应”拆开。更硬的设计是换工具：只用 CRP 基因自身附近、不通过 BMI 而改变 CRP 的变异，再要求疾病信号与 CRP 信号共定位到同一个变异。

所以“做了 Egger、截距不显著”不是排他性成立的证据。截距检验功效低。第 12 节的数字例子里，截距约 −0.005，标准误约 0.089，看起来安静，斜率的标准误却有 1.79，区间没有信息。

## 8. 论文里的那句话对应哪个参数

“X 导致 Y”没有说明效应发生在谁身上、以什么尺度、持续多久、是总效应还是直接效应。下表里的参数，MR 不会自动全部给出。

| 想说的参数 | 估计靠近它的条件 | 写结论时要用的句子 |
|---|---|---|
| 全体平均处理效应 | 效应同质，或工具加权平均恰好等于总体平均 | 效应因人而异时，写成“这些工具所推动的暴露差” |
| 局部平均处理效应 | 二分类暴露，加上单调性。多个 SNP 时是各自局部效应再加权 | 不同位点推动的不是同一群人 |
| 终身暴露差 | 变异从基因表达起就起作用，发育补偿没有把扰动完全抵消 | 不写成“服药两年会使风险变成这个比值” |
| 二分类暴露本身 | 几乎从不直接成立 | 吸烟起始、疾病诊断：工具推动的是易感性，不是“发生一次事件” |
| 比值比 | 结局 GWAS 使用 logistic 模型。疾病常见时比值比不可直接压缩成风险比 | 常见病的 MR 比值比不与试验的风险比并排比较 |
| 直接效应 | 多变量 MR 纳入了要阻断的中介，而且条件工具够强 | 两步法的乘积是间接效应 |
| 可搬到另一人群的临床效应 | 基因–环境交互不强，祖源、年龄、病例定义相近 | 欧洲志愿者队列的估计不自动适用于其他祖源或老年患者 |

终身暴露差和短期治疗不是同一个数。遗传变异从基因表达开始就起作用。LDL 是用来校准直觉的对照：终身低大约 1 mmol/L，冠心病相对风险的下降，大于他汀试验里同样降 1 mmol/L、随访数年看到的下降。数量级上，前者在文献里常被引在相对风险降低一半左右，后者大约五分之一到四分之一。两边可以同时正确，因为累积暴露的时间不同。

发育补偿会让两边离得更远。机体若在发育过程中把遗传扰动抵消，遗传估计会小于成年后干预的效应。LDL 与他汀试验的方向和量级能够对上，说明这条通路上的补偿不强。换一条通路时，不能默认同样能对上。

二分类暴露要改写句子。吸烟起始、疾病有无、糖尿病有无，GWAS 推动的是潜在连续易感性。吸烟起始的位点里混着冒险和冲动相关的变异，排他性从生物学上就需要单独辩护。把结果写成“戒烟会使风险变成这个数”，换了参数。

暴露 GWAS 的协变量也是参数的一部分。调整过中介，βX 已经是另一条参数。调整过对撞因子，βX 里会打开新的通路。这种扭曲发生在做 MR 之前。换 IVW 或中位数修不回来。

工具必须来自与结局 GWAS 相同的祖源。连锁结构和等位基因频率不同，同一个位点的 βX 不能直接借用。

## 9. 单样本、两样本、三样本

### 单样本

G、X、Y 来自同一批人。估计用两阶段最小二乘。

1. 第一阶段：用 G 预测 X，得到预测值 X̂。
2. 第二阶段：把 Y 回归到 X̂ 上。

单个工具时，这和 Wald 比值是同一个数。第二阶段的标准误不能用普通回归的公式，因为 X̂ 自己也是估计出来的。工具变量程序会把这件事算进去。

弱工具在单样本里把估计拉向含混杂的普通回归。第一阶段没拟合好时，预测值里还残留着 U。F 越大，这股拉力越小。许多弱 SNP 放在一起时，偏倚还随着工具个数增加。有限信息最大似然（LIML）在弱工具下的有限样本表现通常好于两阶段最小二乘。

在同一个样本里发现显著 SNP，再用同一批人的 βX 做比值，|βX| 会被赢家诅咒抬高，比值缩小，偏向无效。

### 两样本

暴露 GWAS 提供 βX 和 SEX，另一项结局 GWAS 提供 βY 和 SEY。两边都可以用最大的公开数据，暴露和结局不必在同一队列里测量。这是现在的默认设计。MR-Base / TwoSampleMR 一类流程做的就是这件事。

两样本要满足：

- 祖源匹配
- 效应等位基因对齐，回文 SNP 能判断链向
- 单位一致：标准差、原始单位、对数、分位数转换，分母差一个常数，临床解释就变了
- 样本重叠被测量或被界定
- 年龄和性别结构差得太大时，写明效应可能不可搬运

没有样本重叠时，弱工具的典型方向是朝向 0，也就是朝向无效值。有重叠时，重叠比例会把估计拉向观察性关联。英国生物银行同时出现在暴露和结局的摘要统计里，就是这种设计。Mounier 与 Kutalik 的 MRlap 针对的是样本重叠、弱工具和赢家诅咒这三项可以写出解析式的偏差。

比值的抽样分布是歪的。βX 的区间碰到 0 时，比值可以任意大，期望甚至可能不存在。工具强时，把 βX 当作已知的一阶标准误是：

```text
SE(θ) ≈ SEY / |βX|
```

独立样本、把 βX 的不确定性也算上：

```text
Var(βY / βX) ≈ SEY² / βX² + βY² · SEX² / βX⁴
```

F 很大时第二项很小。F 很小的时候，对称的 Wald 区间会误导，Fieller 区间或对弱工具建模的方法更合适。

### 三样本

三个角色分开：

1. 发现工具的 GWAS
2. 估计 βX 的 GWAS
3. 估计 βY 的 GWAS

发现和估计 βX 若是同一样本，刚好擦过 5×10⁻⁸ 的位点，|βX| 偏大，比值偏小。暴露 GWAS 已经大到估计很稳时，这股衰减会小一些。小样本代谢物 GWAS 里，它是主要偏差之一。

## 10. 偏倚方向

讨论里要写偏去哪一侧。“有偏”本身不够用。

| 情形 | 点估计通常偏向 | 相应的处理 |
|---|---|---|
| 单样本，工具弱 | 含混杂的观察性关联 | 加强工具，或在个体数据里用 LIML。不拿弱工具两阶段最小二乘的小 p 值下结论 |
| 两样本，无重叠，工具弱 | 0，即无效值 | 偏保守，仍报告平均 F。很弱时比值的期望可能不等于参数 |
| 两样本，样本重叠，工具弱 | 观察性关联 | 做重叠校正，或更换不全是同一批人的结局 GWAS |
| 在估计 βX 的同一样本里挑选显著 SNP | 0。\|βX\| 被抬高，比值缩小 | 三样本，或对赢家诅咒做校正 |
| MR-Egger，且 βX 有测量误差 | 0。斜率被稀释 | 先看 I²GX。低于约 0.9 时不解释 Egger 斜率 |
| 人群分层，或“谁参加研究”这个对撞因子 | 可正可负，取决于分层如何与结局相关 | 限制祖源；社会性状改做家系内设计 |
| 水平多效的均值不为 0 | IVW 偏离 τ，符号与多效均值相同 | 中位数、众数、离群点模型、CAUSE；能用顺式工具就用顺式工具 |
| 垂直多效 | 这不是偏倚。估计的是总效应 | 只有问题是直接效应时才调整中介，并改用多变量 MR |
| 终身遗传暴露差对比短期干预 | 这不是统计偏倚，是两个参数 | 结论里写明时间尺度 |

垂直多效那一行要留在表里，避免把“估计里包含了中介”当成方法学失败。

## 11. 从单个 Wald 比值到 IVW

两样本手里没有每个人的 G、X、Y，只有每个近似独立的 SNP：

- βXj，SEX,j：暴露 GWAS
- βYj，SEY,j：结局 GWAS

第 j 个 SNP：

```text
θj = βYj / βXj
```

把 βX 当作已知时，比值的方差约为 SEYj² / βXj²。逆方差权重是：

```text
wj = βXj² / SEYj²
```

逆方差加权（inverse-variance weighted, IVW）估计是：

```text
θIVW = Σ wj θj / Σ wj
      = Σ (βXj · βYj / SEYj²) / Σ (βXj² / SEYj²)
```

它等价于 βY 对 βX 的加权回归，权重是 1/SEY²，截距固定为 0。Burgess、Butterworth 与 Thompson 在 2013 年给出了汇总数据上的这个估计。

固定效应假设每个 SNP 估计同一个 τ。异质性存在时，固定效应标准误偏小。乘性随机效应把残差方差写成 φ · SE²。φ 用 Q / (J − 1) 估计。Q 大于自由度时，标准误乘上 √φ。点估计基本留在原地。随机效应改变的是区间宽度。方向性多效已经把点估计带离 τ 的那一部分，还在原来的地方。

异质性：

```text
Q = Σ wj (θj − θIVW)²
```

固定效应成立且工具有效时，Q 近似服从自由度为 J − 1 的卡方分布。

```text
I² = (Q − df) / Q
```

当 Q 小于自由度时，I² 记为 0。Q 大的来源可以是水平多效、不同位点的真实效应不同、人群或连锁结构不同，也可以是等位基因协调错误。一个很显著的 IVW 配上很大的 Q，说明的是“这组 SNP 的加权平均离开了 0”。

SNP 要互相独立。同一段连锁被算多次，标准误会偏小。常用聚类是 r² < 0.001、窗口 10 Mb，参考面板与 GWAS 祖源一致。这是偏保守的默认值。若保留相关 SNP，就要把连锁不平衡矩阵放进广义最小二乘或似然，不能沿用独立 SNP 的方差公式。

## 12. 四个 SNP 的手算例子

下面的数字是构造的，用来看估计量的差别，不是任何 GWAS 的结果。每个工具的 F 都设为 100，暴露这一侧量得很准，不确定性主要在结局。

| SNP | βX | βY | SEY | 比值 θ | IVW 权重 w |
|---|---:|---:|---:|---:|---:|
| 1 | 0.05 | 0.020 | 0.004 | 0.40 | 156.25 |
| 2 | 0.04 | 0.012 | 0.005 | 0.30 | 64 |
| 3 | 0.06 | 0.021 | 0.006 | 0.35 | 100 |
| 4 | 0.05 | 0.050 | 0.004 | 1.00 | 156.25 |

权重验算：

```text
w1 = 0.05² / 0.004² = 0.0025 / 0.000016 = 156.25
w2 = 0.04² / 0.005² = 0.0016 / 0.000025 = 64
w3 = 0.06² / 0.006² = 0.0036 / 0.000036 = 100
w4 = 0.05² / 0.004² = 156.25
```

SNP4 是离群比值，它和 SNP1 的权重大小相同。离群点的危害取决于权重，不取决于它在表里看起来“极端”这一件事本身。

IVW：

```text
分子 = 156.25×0.40 + 64×0.30 + 100×0.35 + 156.25×1.00
     = 62.5 + 19.2 + 35 + 156.25
     = 272.95

分母 = 156.25 + 64 + 100 + 156.25
     = 476.5

θIVW = 272.95 / 476.5 = 0.573
```

固定效应标准误：

```text
SE = 1 / √476.5 ≈ 0.046
```

四个 SNP 对 Q 的贡献，用 0.573 作为合并值：

```text
SNP1: 156.25 × (0.40 − 0.573)² ≈ 4.68
SNP2: 64     × (0.30 − 0.573)² ≈ 4.77
SNP3: 100    × (0.35 − 0.573)² ≈ 4.97
SNP4: 156.25 × (1.00 − 0.573)² ≈ 28.5
Q ≈ 42.9
```

自由度 3。I² ≈ (42.9 − 3) / 42.9 ≈ 93%。卡方检验会强烈拒绝“四个 SNP 估计同一个数”。

乘性随机效应把标准误放大：

```text
√(Q / df) = √(42.9 / 3) ≈ 3.78
SE ≈ 0.046 × 3.78 ≈ 0.17
```

95% 区间大约是 0.573 ± 1.96 × 0.17，即大约 0.23 到 0.91。区间仍然不包括 0。点估计 0.57 没有回到有效工具所在的位置。随机效应只加宽区间。

去掉 SNP4：

```text
分子 = 62.5 + 19.2 + 35 = 116.7
分母 = 320.25
θ = 116.7 / 320.25 = 0.364
```

一个与有效工具等权的离群点，把合并估计从 0.36 拉到 0.57。

加权中位数把比值从小到大排，累计权重跨过总权重的一半即停止。

```text
总权重的一半 = 476.5 / 2 = 238.25
0.30 的累计权重 = 64
0.35 的累计权重 = 164
0.40 的累计权重 = 320.25
```

累计权重跨过 238 发生在比值 0.40 上。加权中位数是 0.40。它要求至少一半权重来自有效工具。这里 SNP1 到 SNP3 的权重合计 320，超过一半，所以中位数留在 0.30–0.40 这一簇。

Egger 回归：

```text
βY = α0 + θ βX
```

权重仍是 1/SEY²。这四个点的 βX 挤在 0.04 到 0.06，斜率和截距几乎分不开。乘性随机效应下：

| 量 | 数值 |
|---|---|
| Egger 斜率 | 约 0.67 |
| 斜率的标准误 | 约 1.79 |
| 截距 | 约 −0.005 |
| 截距的标准误 | 约 0.089 |

截距“不显著”，同时斜率的区间宽到没有信息。Egger 需要 βX 拉开，也需要 I²GX 高。I²GX 衡量的是观察到的 βX 差异里，有多少不是估计误差。工具强度都差不多时，不解释 Egger 斜率。

这个例子的读法可以固定成四句：

1. 主分析若预先指定为乘性随机效应 IVW，点估计是 0.57，区间大约 0.23 到 0.91。
2. Q 和 I² 说明四个工具并不在估计同一个数。
3. 加权中位数是 0.40，结论对那个比值为 1 的 SNP 敏感。
4. Egger 在这里没有分辨能力。截距不显著不是排他性成立。

从 IVW、中位数、Egger 里挑选唯一显著的那个来写结论，是另一层赢家诅咒。

## 13. 每种估计量额外假定了什么

主分析事先定为乘性随机效应 IVW。其余方法用来回答“结论是否靠某一个位点、是否靠排他性的某种失败方式”。

| 方法 | 无效工具可以有多少 | 额外假设 | 适合的情况 | 保护不到的情况 |
|---|---|---|---|---|
| 固定效应 IVW | 不能有 | 所有 SNP 估计同一个 τ | Q 很小、位点生物学干净 | 异质性大时标准误过小 |
| 随机效应 IVW | 不能有；只放宽方差 | 多效均值为 0 时点估计仍对着 τ | 常规主分析 | 方向性多效仍移动点估计 |
| 加权中位数 | 权重不到一半 | 至少一半权重来自有效工具 | 有少数离群位点 | 无效工具刚好过半，或成片相关、长得不像离群点 |
| 加权众数 | 可以是大多数 | 有效工具形成最高的峰（ZEMPA） | 无效位点很多，但分成另一堆 | 峰分不开时区间极宽，也受平滑带宽影响 |
| MR-Egger | 可以全部带有可加的直接效应 | InSIDE，以及 βX 近似无测量误差 | I²GX 高于约 0.9，工具多，βX 有分散 | 弱工具把斜率稀释向 0；相关多效被吸进斜率 |
| MR-PRESSO | 离群点是少数 | 多数工具有效，无效工具长得像离群点 | 一两个明显离群位点 | 全体一起偏、谁也不像离群点 |
| 污染混合模型 | 允许一部分 SNP 来自污染分布 | 有效 SNP 集中在 τ，无效 SNP 来自更散的分布 | SNP 较多、想同时估计无效比例 | 模型设错时的解释 |
| RAPS | 允许零散的特异多效 | 用轮廓似然处理 βX 的误差，并用稳健损失 | 工具多、单个偏弱 | 相关多效 |
| CAUSE | 一部分位点经共享因素相关 | 因果模型与共享因素模型可以用全基因组摘要比较 | 怀疑相关多效，而且有全基因组摘要 | 只有十几个显著 SNP 时两个模型分不开 |
| 多变量 MR | 视第二暴露是否把旁路挡住 | 工具只通过模型里列入的暴露起作用 | 中介、脂蛋白互相调整 | 条件 F 很弱时偏倚加重 |
| 顺式 / 药物靶点 | 该窗口内要干净 | 共定位支持同一个因果变异 | 蛋白、受体、药靶、单一代谢酶 | 仍是终身扰动，不是几个疗程的药物 |
| 家系内 MR | 家系内重新要求排他性 | 同胞差异消去父母基因型 | 教育、吸烟、BMI 等社会性状 | 有效样本量小得多 |

几点实现上的对应关系：

- 加权中位数：把比值排序，取累计权重达到 50% 的位置。区间常用自助法。Bowden 等人，Genetic Epidemiology，2016。
- 加权众数：在比值的加权分布上找最高峰。零模态多效假设（ZEMPA）说最高峰由有效工具形成。Hartwig、Davey Smith 与 Bowden，International Journal of Epidemiology，2017。
- MR-Egger：分析前把等位基因方向调成所有 βX 为正，截距才是平均直接效应。Bowden、Davey Smith 与 Burgess，International Journal of Epidemiology，2015。I²GX 低时可以用 SIMEX：人为再给 βX 加噪声，观察斜率如何被稀释，再外推回零测量误差。
- MR-PRESSO 分三步：整体残差平方和是否大于“没有多效”的模拟分布；逐个 SNP 看去掉它之后残差是否明显下降；比较去掉离群点前后估计差了多少。Verbanck 等人，Nature Genetics，2018。
- RAPS：Zhao 等人，Annals of Applied Statistics，2020。稳健损失常用 Huber 或 Tukey，另有一个过离散参数。
- CAUSE：Morrison 等人，Nature Genetics，2020。它使用的是整张 GWAS 里经过筛选和剪枝的变异，不只是全基因组显著的工具列表。

方法之间方向一致，说明结果对加权方式不敏感。方向分裂时，写成“估计对水平多效的处理方式敏感”，并指出是哪一个位点或哪一条共享通路在起作用。

## 14. 多变量、中介、双向和非线性

### 多变量 MR

多个暴露一起放进第二阶段：

```text
βYj = θ1 βX1j + θ2 βX2j + εj
```

权重 1/SEY²，默认没有截距。θ1 是按住 X2 之后 X1 的直接效应。脂蛋白是典型场景：高密度脂蛋白胆固醇的单变量 MR 常常还带着载脂蛋白 B，或富含甘油三酯的颗粒。把 apoB 放进模型后，HDL 胆固醇的表观效应会明显收缩。与临床事件对齐的是含 apoB 的颗粒时，这个收缩是估计目标变了，不是方法把结果“做没了”。

工具强度用条件 F，不是原来的边际 F。一组 LDL 工具若与 apoB 的遗传关联成比例，条件在 apoB 上之后，LDL 几乎没有剩下的独立变异，条件 F 会掉到 1 附近。数据没有能力把两者分开。这时报告“不可分的一簇”，不解释那个多变量系数。Sanderson 等人在 2019 年比较了单样本和两样本汇总数据里的多变量 MR。条件 F 的检验和校正见 Sanderson、Spiller 与 Bowden 随后的工作。

多变量 Egger 可以再加一个截距，它继承 Egger 的 InSIDE 和 NOME，功效更低。

### 两步中介

间接效应近似于两个 MR 系数的乘积：

```text
间接效应 ≈ θ(X→M) × θ(M→Y)
```

标准误用 δ 方法。第一步用 X 的工具。第二步必须用 M 自己的工具，而且这些工具不能主要经由 X 起作用。否则 X → Y 的其他通路会从 M 的工具里漏进来。

代谢物研究里这是常态。BMI 的位点因为 BMI 推动代谢物，也会出现在代谢物 GWAS 里。用这些位点做“代谢物 → 死亡”，估计的是 BMI 和代谢物搅在一起的作用。处理有两条：多变量 MR 里同时放入 BMI；或者只用代谢物生物合成基因附近的顺式变异。

两步法的乘积是间接效应。直接效应来自多变量模型里暴露在按住中介之后的系数，或者用来自总效应减去间接效应的差值，两种写法的假设并不完全相同。

### 双向 MR

用两套不同的工具，分别做 X → Y 和 Y → X。两边都正，可能是真正的双向作用，也可能是两边都有多效，或存在共享遗传混杂。

癌症诊断后的体重下降是要认真做反向分析的情形：疾病的工具预测体重，和体重的工具预测疾病，不是同一句话。成人 BMI 的工具预测一个在儿童期就已经完成的结局时，更像是工具在更早的年龄起作用，或存在水平多效，而不是成人 BMI 的反向因果。

### Steiger 过滤

比较每个 SNP 对暴露解释的方差和对结局解释的方差。对结局解释得更多的 SNP，更像结局的工具，或带有更强的直接效应，从暴露工具里拿掉。Hemani、Tilling 与 Davey Smith，PLoS Genetics，2017。

暴露测得很差时，真实的暴露工具也会显得“解释不了暴露”。死亡是测量可靠、但单个 SNP 解释方差很小的结局；代谢物浓度往往测得很准。两边的可靠性差得很多时，Steiger 容易把代谢物一律判成上游。过滤可以做敏感性分析，主分析是否采用要预先写明。

### 非线性 MR

问题是效应是否随暴露水平变化。例如极低的维生素 D 与正常范围是不是一回事，BMI 与死亡是不是 U 型。

不能按观察到的 X 分层再做 MR。X 是 G 和 U 的共同后代，按 X 分层会打开 G 与 U 之间的联系。可用的做法是按残差分层：残差是 X 去掉遗传预测之后剩下的部分，层的划分不由工具决定，再在每一层里估计局部因果效应。即便如此，仍要求工具效应在各层相近，而且分层没有引入新的选择。功效比线性 MR 差一个数量级。Staley 与 Burgess，Genetic Epidemiology，2017，给出了工具变量下非线性暴露–结局关系的半参数估计。维生素 D、酒精、BMI 与死亡的曲线争论，卡在这个设计上。再跑一次线性 IVW 回答不了曲线的形状。

## 15. 工具变量怎么选

预先写下来的内容：

- 显著性阈值，常规是 5×10⁻⁸
- 连锁阈值和窗口，常规是 r² < 0.001、10 Mb
- 参考面板及其祖源
- 是否允许代理 SNP，常用 r² > 0.8
- 回文 SNP 的规则
- 是否做任何生物学排除，例如某个疾病分析里预先排除 APOE 区域

回文碱基对是 A/T 和 C/G。效应等位基因频率靠近 50% 时，无法从频率判断两条链是否对齐，应当删除。频率是 0.1 对 0.9 时，可以用频率把效应等位基因转过来。等位基因翻转会使整个符号反过来。这是最便宜、也最致命的数据处理错误。

从发现到分析结束，报告每一关的个数：起始 SNP 数，聚类后剩余数，结局 GWAS 缺失数，用了多少代理，因回文删除多少，协调后最终进入 IVW 的个数。

把阈值放宽到 5×10⁻⁶ 或 1×10⁻⁵，会同时放进弱工具和假工具。只在暴露 GWAS 功效不足、并且主分析改用对弱工具稳健的方法时才这样做，同时报告原阈值和放宽阈值的差别。

看到结果之后，按“是否关联吸烟、BMI、教育”反复剔除 SNP，直到 p 值好看，是研究者自由度。这里还有一个目标问题。位点若处在垂直多效的中介上，剔除它改变的是估计目标。位点若是水平多效，剔除可以让工具更接近排他性。两种剔除要在动手之前分开写。预先登记的生物学排除可以做。

### 顺式工具和全基因组工具

顺式窗口取基因上下游一百 kb 到一 Mb，具体宽度预先定。窗口里的变异适合蛋白、受体、药物靶点和有明确酶的代谢物。窗口里若还有第二个基因，连锁会把邻居的效应算进来，所以顺式 MR 要配共定位。

反式位点功效更高，排他性差得多。反式蛋白数量性状位点经常反映上游调控或血细胞组成，不适合当作“这个蛋白分子”的工具。代谢物也一样：FADS、GCKR、LPL、APOE 是许多代谢物的共享区域，全基因组显著位点的集合常常是“这一簇通路”的工具。

### 药物靶点

暴露可以是靶点下游的生物标志。教科书里反复出现的区域包括 HMGCR、PCSK9、NPC1L1、LDLR、APOB，用 LDL 的变化当刻度。估计的是这些靶点活性的终身差异。表型组扫描用同一组顺式工具去看感染、肝酶、糖尿病等，看的是靶点方向上的效益和危害是否一起出现。

IL-6 受体的遗传变异与受体阻断方向一致：这条通路的活性下降时，冠心病风险下降，感染相关表型增加。这和后来的受体阻断药物是同一方向的证据。它仍是终身遗传扰动，不是临床试验的缩写。

## 16. 诊断图和检验在看什么

三张图回答三个不同的问题。

**散点图。** 横轴 βX，纵轴 βY。过原点的直线是 IVW。带截距的直线是 Egger。一个点把直线拽离其余点的方向时，留一法应当能对上那个 SNP。做 Egger 之前，等位基因要调成 βX 全部为正，否则截距没有“平均直接效应”的含义。

**漏斗图。** 横轴是单个 SNP 的比值，纵轴是这个比值的精度。不对称与元分析里的小研究效应同一形状。方向性多效下，弱工具的比值被 π / βX 甩出去，漏斗会歪。弱工具本身也可以把漏斗弄歪。它是提示，不是检验的替代品。

**森林图。** 每个 SNP 的比值，加上合并估计。APOE、HLA、ABO、FTO 这类区域应当能在图上被指认。留一法若显示删掉一个区域后估计穿过 0，这个区域就是结论的支点，讨论里要有它的生物学，而不是只写“结果稳健”。

常用数字：

| 量 | 在问什么 | 怎么读 |
|---|---|---|
| 平均 F、R² | 相关性够不够 | 平均 F < 10，或 Egger 的 I²GX 低，先停在工具强度 |
| Q 和 I² | SNP 是否在估计同一个数 | I² 很高时报告随机效应区间，并看中位数或众数有没有离开 IVW |
| Egger 截距 | 可加的直接效应均值是不是 0 | 功效低。不显著仍然与不小的方向性多效相容。相关多效可以让截距保持为 0 |
| PRESSO 整体检验 | 残差是否大于没有多效的零分布 | 显著只说明模型太干净了。删掉谁、估计变了多少，要看后面两步 |
| 留一法 | 是否由一个位点主导 | 主导位点要有名字和生物学，不能只出现在附录图里 |

阳性对照用来检查流程：LDL 相关工具对冠心病、BMI 相关工具对 2 型糖尿病，应当给出文献中的方向。对照失败时，先查效应等位基因、单位和样本重叠，再解释新的暴露。

阴性对照选一个该暴露不可能再影响的早期性状。成年才出现的暴露若在遗传上仍与成年身高关联，工具在更早的年龄已经起效，或存在水平多效。

## 17. 独立性还会怎么失败

排他性讨论得很多。独立性失败同样会给出很显著的估计。

**人群分层。** 等位基因频率随祖源变化，祖源又与环境和结局相关。GWAS 里的主成分去掉的是那一次 GWAS 所调整的粗分层。摘要统计 MR 继承残留的部分。限制在遗传上同质的祖源里做，是设计的一部分，不是可选的敏感性分析。

**选型交配。** 教育、身高、BMI 在配偶之间相关，会使不同位点之间出现长程连锁。遗传相关和 MR 估计都会被抬高。跨性状的选型交配还会制造看起来像因果方向的遗传相关。

**遗传养育。** 父母的基因型通过家庭环境改变子女表型。子女自己的等位基因并没有全部经由自身的暴露起作用。Kong 等人在 2018 年用父母未传递的等位基因展示了这条路径。教育、吸烟起始、一部分 BMI 的人群 MR，会把家庭环境算进“本人暴露的因果效应”。

**家系内设计。** 同胞基因型之差与父母基因型独立，王朝效应、家庭内共享的分层，以及选型交配的一部分家庭间成分，会被差分掉。Brumpton 等人在 2020 年说明了这一点。家系内估计若明显小于人群估计，优先怀疑人群分析的独立性。代价是有效样本量小，区间宽。

**进入队列。** 参与研究与教育、BMI、吸烟和疾病有关，参与本身也有遗传基础。以“进入了某一生物银行”为条件，等于条件在一个对撞因子上，基因型与结局之间会打开一条只在样本内存在的通路。社会性状，以及与参与强相关的代谢表型，要把这件事写进偏差来源。

**生存。** 活到能采血、能完成随访的人，已经在早死因素上被选择过。影响早死的基因型在老年样本里变少。高龄结局、长寿、晚发疾病都会受到这层条件化的影响。APOE 与寿命的关系强到足以带动一大片晚发表型。

这些路径的共同点是：基因型仍然可以和结局相关，但相关不是“本人的暴露被随机推动之后的后果”。

## 18. 共定位、SMR 和相邻方法

MR 问效应有多大。共定位问这一小段基因组里，暴露和结局是不是同一个因果变异。

coloc（Giambartolomei 等人，PLoS Genetics，2014）把一个区域的证据分成五种后验：

| 假设 | 含义 |
|---|---|
| H0 | 两边都没有关联 |
| H1 | 只有性状 1 有关联 |
| H2 | 只有性状 2 有关联 |
| H3 | 两边都有关联，因果变异不同 |
| H4 | 共享同一个因果变异 |

药物靶点、蛋白、单一代谢酶要的是 H4。两个基因靠得很近、连锁在一起时，MR 的 Wald 比值可以显著，共定位却支持 H3。那是邻居基因的效应。

SMR（Zhu 等人，Nature Genetics，2016）用最强的表达数量性状位点做一次 Wald 比值，把基因表达和疾病接起来。HEIDI 再看这个区域内其他 SNP 的信号是否一致。HEIDI 拒绝时，更像两个变异连锁，而不是一个变异同时影响表达和疾病。只报告 SMR 的 p 值，没有 HEIDI 或 coloc 的共享证据，不断言“就是这个基因”。

相邻方法回答的是邻题，不是同一个参数。

| 方法 | 它回答的问题 | 它不回答的问题 |
|---|---|---|
| 两阶段最小二乘、LIML | 个体数据里的工具变量估计 | 不会自动满足排他性和独立性 |
| LD 分数回归的遗传相关 rg | 全基因组遗传结构有多像 | 没有方向，因果和多效都在里面 |
| 潜在因果变量模型 | 遗传相关是否更像从一边流向另一边 | 不是一个写明剂量的暴露干预 |
| 转录组关联、PrediXcan | 遗传预测的表达量与疾病是否关联 | 连锁和多效仍在 |
| SMR + HEIDI、coloc | 这个座位是不是同一个因果变异 | 不给出可搬运的临床剂量效应 |
| 随机对照试验 | 特定人群、特定疗程、特定方案的干预效应 | 不等于终身遗传暴露差 |
| 观察性多变量回归 | 在已测量协变量下的条件关联 | 未测量混杂和反向因果仍在 |

遗传相关显著，只说明两性状的遗传结构有重叠。它可以来自因果、水平多效、人群结构或选型交配。把它写成 MR 的结果，换了方法。

## 19. 功效、多重检验和报告

标准化的连续暴露和连续结局、工具不弱、样本不重叠时，因果效应的标准误大约是：

```text
SE(θ) ≈ 1 / √(N结局 × R²暴露)
```

θ 的单位是“结局的 1 个标准差 / 暴露的 1 个标准差”。这是用来判断数量级的近似，不是软件里那个精确的标准误。

两个数：

- 工具解释暴露方差的 2%，结局样本 10 万：SE ≈ 1 / √2000 ≈ 0.022。每标准差 0.05 的效应有机会被分辨出来。
- 工具只解释 0.2%，结局样本 1 万：SE ≈ 1 / √20 ≈ 0.22。只有很大的效应才出得了窄区间。

瓶颈几乎总是结局样本量和工具对暴露的 R²，不是暴露 GWAS 的 p 值有多小。二分类结局还要再乘上病例比例带来的信息损失。病例少的疾病，总样本量不能代替病例数。

区间很窄并且覆盖 0，才是对“较大效应”的否定。区间同时盖住重要的获益和重要的危害，结论是精度不够。

一个暴露对几百个结局，或几百个代谢物对一个结局，假设检验的次数就是那个乘积。预先指定的单一假说用常规显著性。表型组扫描用错误发现率，并把高度相关的结局当成一簇，而不是一串独立复制。三十个脂质性状同时显著，常常是一次生物学事件。

报告按 STROBE-MR（Skrivankova 等人，JAMA，2021；配套说明见 BMJ，2021）。最低限度包括：

- 因果句子和估计目标：人群、单位、总效应还是直接效应、终身还是想外推到短期干预
- 两个 GWAS 的人群、祖源、样本量、重叠
- SNP 从多少到多少，聚类、代理、回文各删多少
- R² 与平均 F；多变量模型还要条件 F
- 预先指定的主分析
- Q、I²、Egger 截距、留一法
- 散点、漏斗、森林图
- 哪一条假设最可疑
- 祖源和年龄限制

措辞用：在上述假设下，估计与这一因果效应一致。

实施时的操作清单，Burgess 等人发表在 Wellcome Open Research，2019。给临床读者的读法，Davies、Holmes 与 Davey Smith 发表在 BMJ，2018。

## 20. 用已有结果校准大小

这些例子用来固定“估计目标”和“证据强弱”，不是一份结果汇编。

**PCSK9。** 功能缺失变异降低 LDL，并降低冠心病（Cohen 等人，New England Journal of Medicine，2006）。结局试验出现在这种遗传证据之后。这是药物靶点 MR 最常被引用的历史对照。估计的是终身低 LDL，用 PCSK9 活性的遗传差异当干预。

**HDL 胆固醇。** 观察性关联很强。用遗传工具把 HDL 与其他脂蛋白分开之后，HDL 胆固醇本身并不呈现观察性数据所暗示的那种保护（Voight 等人，Lancet，2012）。CETP 抑制剂后来降低了冠心病事件，同时降低的是含 apoB 的脂蛋白。多变量框架下，与事件对齐的是 apoB。

**CRP。** CRP 基因座位上、推动 CRP 蛋白本身的顺式变异，并不带来冠心病风险的升高。全基因组的 CRP 工具则会混入上游的肥胖和炎症。同一个测量值，两套工具，两个参数。

**IL-6 受体。** 与受体阻断方向一致的遗传变异，对应较低的冠心病风险，同时也对应感染相关表型的增加（Lancet，2012 年的孟德尔随机化合作分析）。效益和危害都在靶点上。

**酒精。** 观察性曲线常呈 J 型。以乙醇脱氢酶等位点为工具的分析，不支持“少量饮酒保护心血管”这一段（Holmes 等人，BMJ，2014；中国人群中 Millwood 等人，Lancet，2019）。饮酒位点仍可能混着消费模式和人群结构。

**教育与一部分行为性状。** 人群 MR 容易混入遗传养育和选型交配。看到这类估计，先找有没有同胞分析。

读新论文时，用这些例子问自己：作者的工具更像 PCSK9 那种顺式靶点，还是更像全基因组的 CRP 工具；作者写的是终身暴露差，还是一个短期治疗；作者排除 APOE 或某一个位点，是预先规定的，还是看到结果之后做的。

## 21. 代谢物、模块、评分、死亡和长寿

本节对应该仓库里的四类分析。样本是 13,512 人的前瞻性随访。四类分析分别是：单个代谢物与死亡、长寿的代谢组范围关联；基于已知集合的代谢物集富集；WGCNA 模块；预测全因死亡的弹性网络评分。

### 13,512 人放在设计的哪一步

这个样本量适合发现观察性信号。它不适合在内部发现遗传工具，再在内部检验死亡。能稳定超过 5×10⁻⁸ 的代谢物位点很少，赢家诅咒会很大。单样本或高度重叠的两样本里，弱工具会把估计拉向队列里那个已经含混杂的关联。

工具应来自独立的、更大的代谢组 GWAS。早期核磁共振代谢组大约两万多人，例如 Kettunen 等人那一代；早期质谱 GWAS 更小；英国生物银行的核磁共振代谢组到了十万人以上。结局用独立的死亡或寿命 GWAS。暴露数据若和结局 GWAS 大量重叠，方向的解释要带上第 10 节的重叠偏倚。

### 一个代谢物的总效应和直接效应

代谢物位点高度共享。FADS、GCKR、LPL、APOE 会同时推动几十个代谢物。一百个代谢物各自显著，可能是同一簇脂蛋白或同一段脂肪酸去饱和通路被重复计数。

单变量 MR 估计的是“这个测量值所代表的遗传通路”的总效应。句子若要写成“就是这一个峰，把其他相关代谢物按住以后仍然有效”，那是直接效应：使用多变量 MR，并报告条件 F。条件 F 很低时，这些代谢物在遗传上不可分，结论停在“这一簇”。

比值型代谢物，例如两种脂肪酸之比，有时会在 FADS 上得到很强的顺式工具。生物学上它可能更接近酶的活性。估计目标也就变成了这个比值，不再是其中某一个绝对浓度。

平台之间不能直接搬运单位。核磁共振的绝对浓度、质谱的相对定量、GWAS 里的标准差，Wald 比值的分母差一个常数，临床解释就要重标。先把 βX 和 βY 写成同一套单位，再谈效应大小。

### 模块

WGCNA 模块是数据驱动的协同变化。对模块的因果问题，是成员代谢物各自的 MR 是否方向一致、是否由少数共享位点主导。模块特征向量本身没有现成的 GWAS，就不能当作已经有工具的暴露。若先在 13,512 人里用死亡来解释模块，再把模块叫作原因，估计目标又回到了观察性关联。

### 预测评分

弹性网络评分的权重是为了预测死亡而估计的。再把这个评分当作暴露，用遗传预测去关联死亡，预测目标已经写进权重，多效是构造出来的。评分可以生成假说：看高权重代谢物各自的工具指向哪里。评分整体不是一个暴露。

遗传预测的代谢物评分与死亡相关，更接近“预测表达量与性状相关”那一类分析。它仍然携带评分里每一个成分的水平多效。

### 死亡和长寿特有的选择

活到采血并完成长期随访的人，早期致死因素已经作用过。寿命 GWAS 对 APOE 极其敏感。代谢物若主要通过脂蛋白通路与死亡关联，APOE 区域要预先规定保留或排除，并报告留一法。长寿表型若定义在存活到高龄的人身上，估计还条件在生存上，和全因死亡的率或风险不是同一个参数。

### 和这个仓库里四步分析的衔接

| 已有分析 | 它已经回答的 | 若要接 MR，暴露必须改写成 |
|---|---|---|
| 单个代谢物与死亡、长寿 | 这个测量值是否与结局一起变化 | 一个有外部工具的代谢物；写明总效应还是按住相关代谢物后的直接效应 |
| 代谢物集富集 | 已知集合是否整体关联 | 集合若对应一条有顺式基因的通路，工具取那条通路；否则先拆回成员 |
| WGCNA 模块 | 数据驱动的协同模块是否关联 | 成员各自的 MR，以及共享位点是否主导。特征向量本身不做工具变量 |
| 弹性网络死亡评分 | 一组权重的预测能力 | 高权重代谢物的单独假说。评分整体不作为暴露 |

阳性对照可以放在同一条流程里。已知脂蛋白工具对冠心病、BMI 工具对糖尿病，应当给出文献中的方向。这些对照失败时，先查效应等位基因和单位。

## 22. 预先固定的分析顺序

主分析事先指定为乘性随机效应 IVW。其余方法不参与“挑选一个显著结果”。

| 步 | 做什么 | 这一步过不去时停在哪里 |
|---:|---|---|
| 1 | 用一句话写因果问题：人群、暴露单位、总效应还是直接效应 | 问题其实是易感性、短期治疗或其他祖源时，改写句子，不沿用默认的终身总效应 |
| 2 | 画因果图。标出中介、对撞、已知的水平多效。对照暴露 GWAS 的协变量 | GWAS 调整过中介或对撞因子时，βX 已经不是目标参数 |
| 3 | 选祖源匹配的暴露 GWAS 和结局 GWAS，写明样本重叠 | 重叠大且工具不强时，先做重叠校正 |
| 4 | p < 5×10⁻⁸；r² < 0.001、10 Mb 聚类；协调效应等位基因；无法判断链向的回文 SNP 删除 | 报告每一步删除的个数。等位基因翻转会使符号整个反过来 |
| 5 | 计算 R² 与平均 F | 平均 F < 10 时，不做以 Egger 为主的分析 |
| 6 | 主分析：乘性随机效应 IVW，报告 Q、I²、SNP 数 | Q 很大时同时准备好中位数或众数，不把随机效应写成“已经处理了多效” |
| 7 | 加权中位数、加权众数、留一法；离群点方法；Egger 仅在 I²GX 足够高时解释斜率 | 方法之间方向相反时，结论写成对假设敏感 |
| 8 | 旁路若是某个已测量性状，做多变量 MR，报告条件 F | 条件 F 接近 1 时，不解释直接效应系数 |
| 9 | Steiger 方向性。反向因果说得通时做反向 MR | 暴露测量误差大时，Steiger 会把真工具误判成结局工具 |
| 10 | 蛋白、基因表达、单一代谢酶：加共定位或 HEIDI | 只有 SMR 的 p 值、没有共享因果变异的证据时，不断言是这个基因 |
| 11 | 教育、吸烟、饮食、部分 BMI：寻找家系内证据 | 人群估计与家系内估计不一致时，优先怀疑人群分析的独立性 |
| 12 | 按 STROBE-MR 报告效应、区间、诊断图，并写明最可疑的假设 | 措辞停在“在所列假设下与因果效应一致” |

三张图和 F、Q、截距放在主文或主附录。

## 23. 读一篇 MR 论文时按什么顺序看

1. 第一段或方法第一句：暴露、结局、单位、总效应还是直接效应。这句话含糊时，后面的比值比没有着落。
2. 工具来自哪里：全基因组显著位点，还是一个基因窗口。是不是 APOE、HLA、ABO、FTO 或代谢物的 FADS 在主导。
3. 平均 F、SNP 个数、样本是否重叠。F 低而 p 值很小，先想弱工具和重叠。
4. 主分析是不是预先指定的 IVW。Egger、中位数、PRESSO 是敏感性分析还是被挑出来的那个。
5. Q 和留一法。删掉一个区域后结论是否还在。
6. 因果图里最可能失败的是排他性还是独立性。社会性状优先看有没有家系内结果。蛋白和代谢酶优先看有没有共定位。
7. 讨论是否把终身遗传暴露差写成了短期治疗效应，是否把二分类易感性写成了“发生一次事件”。

## 25. 符号

| 符号 | 含义 |
|---|---|
| G | 遗传工具 |
| X | 暴露 |
| Y | 结局 |
| U | 混杂 |
| M | 中介 |
| τ | 因果效应 |
| α | 工具对暴露的效应 |
| π | 工具对结局的直接效应 |
| κ | 直接效应与 α 成比例时的比例系数，θ = τ + κ |
| βX, βY | GWAS 回归系数 |
| SEX, SEY | 对应的标准误 |
| θj | 第 j 个 SNP 的 Wald 比值，βYj / βXj |
| wj | IVW 权重，βXj² / SEYj² |
| F | 工具强度。(βX / SEX)²，或遗传得分的联合 F |
| R² | 工具解释的暴露方差比例 |
| Q | Cochran 异质性统计量 |
| I² | 异质性占方差的比例 |
| I²GX | βX 的变异里不是测量误差的比例，用来判断 Egger 的 NOME |
| InSIDE | 直接效应与工具强度独立 |
| NOME | Egger 把 βX 当作没有测量误差 |
| ZEMPA | 零模态多效：有效工具形成比值分布的最高峰 |
| IVW | 逆方差加权 |
| MVMR | 多变量 MR |
| 2SLS | 两阶段最小二乘 |
| LIML | 有限信息最大似然 |

一句话收束：Wald 比值 θ = β(G→Y) / β(G→X) 是 MR 的全部算术核心。相关性保证分母不是 0，独立性保证基因型不是混杂分配的，排他性保证分子里只有经过暴露的那一部分。三条里任何一条失败，后面的加权、中位数和 Egger 都是在一个已经改变了含义的数上做文章。

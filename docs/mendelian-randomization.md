## 先记住这三句话

1. 想知道"X 会不会导致 Y"，但直接比较会被混杂因素和反向因果搞乱。
2. 于是找一个"出生时就抽签决定、只通过 X 起作用"的基因变异，把它当作"天然的随机分组"。
3. 用"变异对 Y 的作用 ÷ 变异对 X 的作用"得到 X 对 Y 的因果效应。有多个变异时，把各自的结果加权平均。

## 0. 术语速查（先扫一眼，看不懂再回来查）

| 术语 | 一句话解释 |
|---|---|
| 暴露（X） | 你想研究的"原因"，如 LDL、BMI、某个代谢物 |
| 结局（Y） | 你想研究的"结果"，如冠心病、死亡 |
| 混杂（U） | 同时影响 X 和 Y 的因素，如生活方式、收入 |
| 因果效应 | 把 X 改变一个单位，Y 平均会变多少 |
| SNP | 基因组上的一个"字母位点"，不同人在这里的字母可能不同 |
| 等位基因 | 同一个位点上的不同字母，如 A 和 G |
| 效应等位基因 | GWAS 用来计量的那个字母，beta 说的是"多一个它"的作用 |
| 基因型（0、1、2） | 一个人带了几个效应等位基因 |
| GWAS | 全基因组关联研究：对每个 SNP 各做一次回归，看它与某性状是否相关 |
| 摘要统计 | GWAS 公开的结果表，每个 SNP 一行（beta、SE、p 等），不含个人数据 |
| beta | 每多一个效应等位基因，性状变化多少（二分类性状里是 log OR） |
| SE | beta 的标准误，越小说明估计越准 |
| p 值 | 关联不是偶然的证据强度。全基因组显著线是 5×10⁻⁸ |
| EAF | 效应等位基因在人群中的频率，0 到 1 |
| 连锁不平衡（LD） | 相邻 SNP 常一起遗传，看起来像"同一个信号" |
| 聚类（clumping） | 在同一片连锁区域只保留最强的那个 SNP |
| 工具变量 | 满足三条假设、用来充当"随机分组"的 SNP |
| 多效性 | 一个 SNP 影响多个性状 |
| 水平多效性 | SNP 绕开 X 去影响 Y，也就是"走后门" |
| F 统计量 | 衡量 SNP 够不够"硬"，经验标准是大于 10 |
| Wald 比值 | 单个 SNP 的因果估计，by ÷ bx |
| IVW | 逆方差加权：把多个 SNP 的比值按可信度加权平均 |
| Q、I² | 衡量各 SNP 的估计彼此是否一致 |
| 协调（harmonise） | 把两份 GWAS 的效应等位基因对齐 |
| 回文 SNP | 等位基因是 A/T 或 C/G 的 SNP，容易分不清链的方向 |
| OR | 比值比。OR = e 的 beta 次方 |

## 1. ★ 孟德尔随机化想解决什么问题

> 这一章带走什么：为什么直接比较会错；基因变异为什么能当"天然的随机分组"；MR 能回答和不能回答什么。

### 1.1 直接比较会错：两个陷阱

**陷阱一：混杂。** 调查发现"每天喝很多咖啡的人肺癌更多"。但喝咖啡多的人里吸烟的人也多，吸烟才是肺癌的原因。吸烟同时推高了"喝咖啡"和"肺癌"，这叫混杂。你可以把吸烟测出来再调整，但很多混杂因素根本测不到：饮食习惯、收入、心理压力、早年经历。

**陷阱二：反向因果。** 调查发现"体重偏低的老人更容易死亡"。不一定是瘦导致死亡，也可能是重病先让人消瘦，再导致死亡。箭头反了。

两种问题的共同后果是：回归系数里混着"真正的因果效应"和"别的东西"，分不开。

### 1.2 最干净的办法：随机分组

随机对照试验的核心是抽签分组。抽签之后，两组人在年龄、生活方式、收入这些方面平均来说是一样的，只有"吃不吃这个药"不同，结局的差别就可以归给药。

但很多问题没法做这种试验：不能让一部分人一辈子血脂偏高、另一部分一辈子血脂偏低，也不能随机让人吸烟。

### 1.3 大自然已经抽过一次签

孟德尔遗传定律说：父母把两份基因拷贝中的哪一份传给孩子，是随机的，像抛硬币，而且在受孕时就定下来了。

假设基因组上某个位置有 A 和 G 两种字母，并且已知"A 会让 LDL 胆固醇略微升高"。那么：

- 带 A 的人，一辈子 LDL 平均略高一点；
- 带 G 的人，一辈子 LDL 平均略低一点。

谁带 A、谁带 G 是受孕时抽签决定的，和生活方式、收入、饮食无关，也不会被后来得的病改变。所以"带 A 的人"和"带 G 的人"，除了 LDL 略有差别，其他方面平均上是可比的。如果前者的冠心病更多，就说明 LDL 的差别很可能真的导致了冠心病。

这就是孟德尔随机化：用基因变异当作"天然的随机分组"。

### 1.4 和随机对照试验对照着看

| | 随机对照试验 | 孟德尔随机化 |
|---|---|---|
| 谁来抽签 | 研究者 | 受孕时自然抽签 |
| 分成哪两组 | 药物组与安慰剂组 | 带 A 的人与带 G 的人 |
| 两组的差别 | 药物剂量 | 终身略高或略低的暴露水平 |
| 能不能盲法 | 需要设计 | 天然盲法，人不知道自己的基因型 |
| 主要风险 | 失访、不遵医嘱 | 基因还有别的作用（多效性）、人群结构 |

### 1.5 一个经典故事

1986 年，Katan 注意到胆固醇低的人癌症更多。是低胆固醇致癌，还是早期癌症本身让胆固醇下降（反向因果）？他提出：载脂蛋白 E（APOE）基因的不同类型会让胆固醇高低不同，而癌症改变不了一个人出生时的基因型。如果低胆固醇真会致癌，那么天生带"低胆固醇类型"的人，癌症应该更多。这是 MR 思想最早的清晰表述之一。后来这个思路被系统化并命名（Davey Smith 与 Ebrahim，2003）。

### 1.6 MR 能回答什么，不能回答什么

- 能回答：假设成立时，终身略高或略低的某种暴露，是否改变结局风险，以及大概改变多少。
- 不能直接回答：
  - 某种药吃两年的效果，因为基因变异的作用是终身的；
  - 暴露"从有到无"的效果，例如"戒烟"，因为基因推动的是"倾向"，不是"事件"；
  - 一个祖源人群的结果能否直接用于另一个祖源人群。

### 小结

- 直接比较会被混杂和反向因果搞乱。
- 基因变异是受孕时抽签分配的，可以当作天然的随机分组。
- MR 回答的是"终身暴露差"的因果效应，不是短期干预的效果。

## 2. ★ 三条必须成立的假设

> 这一章带走什么：用"够硬、公平、不走后门"记住三条假设；知道每一条怎么被破坏；知道哪条能用数据检验，哪条不能。

### 2.1 先看图

字母含义：G 是基因变异（工具），X 是暴露（如 LDL），Y 是结局（如冠心病），U 是混杂（你看不见的因素）。箭头表示"影响"。

理想的世界：

```text
G ---> X ---> Y
       ^      ^
       |      |
       +-- U -+
```

读法：

- G 影响 X，X 影响 Y。这条链是我们想估计的。
- U 同时影响 X 和 Y，这是混杂。
- 没有 U 指向 G 的箭头：基因不受生活方式影响。
- 没有 G 直接指向 Y 的箭头：基因不走后门。

### 2.2 三条假设

**① 够硬（相关性）。** 基因变异真的能推动 X。如果它对 X 几乎没影响，后面"除以它对 X 的作用"就是在除以一个接近 0 的数，结果极不稳定。

- 能不能检验：能。看 p 值（小于 5×10⁻⁸）和 F 统计量（大于 10）。
- 怎么被破坏：用了不够显著的 SNP；暴露 GWAS 样本太小。

**② 公平（独立性）。** 基因变异与混杂因素 U 无关。就像抽签应该公平，不能偏向某一类人。

- 能不能检验：不能直接检验。
- 怎么被破坏：人群分层（不同祖源的人，等位基因频率不同，生活方式也不同）；选型交配；家庭环境（父母基因通过养育影响孩子）。
- 对策：只用同一祖源；校正祖源主成分；必要时做家系内 MR。

**③ 不走后门（排他性）。** 基因变异只通过 X 影响 Y。

- 能不能检验：不能证明。只能做敏感性分析，看结论对"有没有后门"敏不敏感。
- 怎么被破坏：水平多效性（一个变异同时影响好几个性状）；工具 SNP 与邻近的另一个因果基因连锁。
- 例子：APOE 同时影响脂蛋白和阿尔茨海默病的另一些通路。拿它当"LDL 对阿尔茨海默病"的工具，就走了后门。

记忆：够硬、公平、不走后门，对应相关性、独立性、排他性。

### 2.3 后门有两种

**后门（水平多效性）：** 基因绕开 X，直接影响 Y。

```text
  +-------------+
  |             v
  G ---> X ---> Y
         ^      ^
         |      |
         +-- U -+
```

**顺路（垂直多效性）：** 基因影响 X，X 再影响中介 M，M 再影响 Y。

```text
G ---> X ---> M ---> Y
```

这条路不是后门。M 是 X 发挥作用的方式，X 对 Y 的总效应本来就包含它。例如 LDL 受体的变异先改变 LDL，再改变动脉粥样硬化，再改变冠心病，这是正常的因果链。

### 2.4 一种更隐蔽的后门

如果后门的大小和 SNP 对 X 的推动强度成比例，所有 SNP 会一起偏。这种情形叫相关多效性，第 3.5 节讲原理，第 7 章（情形 C）让你亲眼看到。

### 2.5 还有一个隐含的条件

如果每个人的因果效应不一样，MR 估计的是被基因"推动得更远"的那些人的加权平均效应。初学时知道这一点就够了。

### 小结

| 假设 | 记法 | 能用数据检验吗 |
|---|---|---|
| 相关性 | 够硬 | 能（p、F） |
| 独立性 | 公平 | 不能直接检验 |
| 排他性 | 不走后门 | 不能证明，只能做敏感性分析 |

## 3. ★ 核心算术：一个 SNP 怎么算出因果效应

> 这一章带走什么：一个 SNP 的因果估计，就是它对结局的作用除以它对暴露的作用；为什么这样除就能避开混杂；有"后门"时会错多少。

这一章是整份讲义最关键、也最容易看不懂的地方，所以写法是：先讲故事，再代数字，最后才写公式。

### 3.1 先认识四个数

继续用 LDL 与冠心病的例子。手边有一个 SNP，它的 A 等位基因会让 LDL 升高。这件事涉及四个数：

| 记号 | 白话意思 | 从哪里来 | 本章例子 |
|---|---|---|---|
| bx | 每多一个 A，LDL 升高多少 | 暴露 GWAS 的 beta | 0.2 |
| by | 每多一个 A，冠心病的 log-odds 升高多少 | 结局 GWAS 的 beta | 0.1 |
| τ | LDL 每升高 1 个单位，冠心病的 log-odds 升高多少 | 这是想求的，没法直接观察 | 未知 |
| π | A 绕开 LDL，直接对冠心病的作用，即后门 | 看不见 | 先假设为 0 |

前两个是 GWAS 直接给你的，后两个是想知道或看不见的。τ 读作"套"，π 读作"派"。

### 3.2 因果链上做乘法

A 影响冠心病只有一条路：A 到 LDL，再到冠心病。

```text
A --(bx)--> LDL --(τ)--> 冠心病
```

沿着链走：A 让 LDL 升高 bx；LDL 每升高 1 个单位，冠心病的 log-odds 升高 τ；所以 A 最终让冠心病的 log-odds 升高 bx × τ。GWAS 直接测到的 by 就是这个"最终效果"：

```text
by = bx × τ
```

把它倒过来：

```text
τ = by ÷ bx
```

代入数字：by = 0.1，bx = 0.2，所以 τ = 0.1 ÷ 0.2 = 0.5。意思是 LDL 每升高 1 个单位，冠心病的 log-odds 升高 0.5，也就是 OR = e^0.5 = 1.65。

这就是整个 MR 最核心的一步：用"基因对结局的作用"除以"基因对暴露的作用"。这个比值叫 Wald 比值。

### 3.3 为什么这样除，混杂就被绕开了

直接比较"LDL 高的人"和"LDL 低的人"，两群人在生活方式上也不一样（U），冠心病的差别里混着 U 的作用。

但 by 比较的是"带 A 的人"和"带 G 的人"。谁带 A 是受孕时抽签决定的，和生活方式无关，两群人在 U 上平均是一样的，所以 by 里没有 U 的成分。bx 同理。两个"干净"的数相除，结果也是干净的。

### 3.4 有"后门"会怎样

假设 A 除了通过 LDL，还有另一条路直接让冠心病的 log-odds 升高 π = 0.03（比如影响了炎症）。那么 GWAS 测到的 by 变成：

```text
by = bx × τ + π = 0.2 × 0.5 + 0.03 = 0.13
```

你并不知道有后门，照样去除：0.13 ÷ 0.2 = 0.65，比真值 0.5 多了 0.15。

```text
估计值 = τ + π ÷ bx = 0.5 + 0.03 ÷ 0.2 = 0.65
```

两条读法：

- 后门 π 越大，错得越多。
- bx 越大（SNP 越"硬"），同样大小的后门造成的错误越小。这是"够硬"的价值。

### 3.5 一种更隐蔽的后门

如果后门的大小跟着 bx 同比例变化，比如 π = 0.2 × bx，那么：

```text
π ÷ bx = 0.2
```

不论 SNP 多"硬"，每个 SNP 都偏高同样的 0.2。各个 SNP 的估计彼此一致，从数据上看不出任何异常，却整体错了。这叫相关多效性，是 MR 里最难处理的问题。

### 3.6 比值也有不确定性

bx、by 都是估计值，各有标准误。比值的标准误近似是：

```text
SE(by ÷ bx) ≈ SE(by) ÷ bx
```

读法：bx 越大、by 测得越准，这个 SNP 的比值越可信。第 4 章据此给每个 SNP 分配权重。

### 3.7 完整走一遍：rs_demo01

第 8 章实战里的 rs_demo01：bx = 0.200（LDL，单位 SD），by = 0.074（冠心病，log OR），SE(by) = 0.012。

```text
比值   = 0.074 ÷ 0.200 = 0.37
SE     = 0.012 ÷ 0.200 = 0.06
95% CI = 0.37 ± 1.96 × 0.06 = 0.25 到 0.49
OR     = e^0.37 = 1.45，95% CI 1.29 到 1.63
```

读法：只看这一个 SNP，LDL 每升高 1 SD，冠心病的 OR 约 1.45。

### 小结

- 一个 SNP 的因果估计 = by ÷ bx。
- 它避开了混杂，因为 by 和 bx 都来自"抽签分组"的比较。
- 前提是没有后门。有后门，估计值 = τ + π ÷ bx。
- 严格推导见附录 A。

## 4. ★ 多个 SNP 怎么合并（IVW）

> 这一章带走什么：为什么要用很多个 SNP；"逆方差加权"到底在加权什么；Q 和 I² 怎么看。

### 4.1 为什么要很多个 SNP

只用一个 SNP，估计的噪声大，也没法知道它有没有"后门"。如果用几十个互相独立的 SNP，每个都算出一个比值：

- 它们都在估计同一个 τ，应该彼此接近，合并起来可以减少噪声；
- 如果某个 SNP 的比值明显偏离其他，它就是"可疑的 SNP"。

### 4.2 加权平均：谁更可信谁说了算

各 SNP 的可信度不同：bx 大、SE(by) 小的 SNP，比值更准。权重取：

```text
权重 = bx² ÷ SE(by)²
```

它是比值方差（SE(by)² ÷ bx²）的倒数，所以叫"逆方差加权"。

小例子：3 个 SNP。

| SNP | bx | by | SE(by) | 比值 | 权重 | 权重×比值 |
|---|---:|---:|---:|---:|---:|---:|
| A | 0.20 | 0.100 | 0.010 | 0.50 | 400 | 200 |
| B | 0.10 | 0.050 | 0.010 | 0.50 | 100 | 50 |
| C | 0.05 | 0.040 | 0.010 | 0.80 | 25 | 20 |
| 合计 | | | | | 525 | 270 |

权重怎么来的，以 A 为例：0.20² ÷ 0.010² = 0.04 ÷ 0.0001 = 400。

合并结果：

```text
IVW = 270 ÷ 525 = 0.514
SE  = 1 ÷ √525 = 0.044
```

注意 C 的比值是 0.80，偏离较远，但它的权重只有 25 ÷ 525 = 5%，所以几乎没有拉动结果。

### 4.3 公式（就这两行）

```text
IVW = （各 SNP 的 权重×比值 之和） ÷ （各 SNP 的 权重 之和）
SE  = 1 ÷ √（各 SNP 的 权重 之和）
```

### 4.4 各 SNP 一致吗：Q 和 I²

如果所有 SNP 估计的是同一个 τ，各个比值围绕 IVW 的散开程度就只来自随机误差。Q 把这种"偏离"加总：

```text
Q = 各 SNP 的 权重 × （比值 − IVW）² 之和
```

3 个 SNP 的例子：

```text
Q = 400×(0.50−0.514)² + 100×(0.50−0.514)² + 25×(0.80−0.514)²
  = 0.08 + 0.02 + 2.04
  = 2.14
```

比较标准是自由度 df = SNP 个数 − 1 = 2。如果各 SNP 一致，Q 通常和 df 差不多。这里 Q = 2.14，接近 df = 2，p = 0.34，没有异质性的证据。

I² = (Q − df) ÷ Q，意思是"各 SNP 之间的差异中，有多大比例不是随机误差"。Q 不大于 df 时记为 0。

| 看到的 | 含义 | 怎么做 |
|---|---|---|
| Q 约等于 df | 一致 | 固定效应 IVW 即可 |
| Q 远大于 df（p 很小） | 不一致：可能有后门、离群 SNP，或等位基因没对齐 | 先检查数据；用随机效应；做第 6 章的敏感性分析 |

随机效应的做法：Q 大于 df 时，把标准误乘以 √(Q ÷ df)，区间变宽，点估计不变。随机效应只是承认"有不一致"，并没有把后门的影响去掉。

### 4.5 画成图

横轴 bx，纵轴 by，每个 SNP 一个点。如果每个 SNP 估计同一个 τ，点应该落在一条过原点、斜率为 τ 的直线上。IVW 的估计就是这条加权直线的斜率，偏离直线的点就是可疑 SNP。第 8 章会画这张图。

### 小结

- IVW 是各 SNP 比值的加权平均，权重 = bx² ÷ SE(by)²。
- Q 衡量各 SNP 是否一致，和自由度 df 比。
- 随机效应只加宽区间，不会纠正后门造成的偏差。

## 5. ★ GWAS 摘要统计入门

> 这一章带走什么：GWAS 是什么、一份摘要统计长什么样、beta、SE、p、EAF 各是什么意思，以及为什么要做"显著性筛选、聚类、F 检查、等位基因对齐"这四件事。

### 5.1 GWAS 是什么

GWAS（全基因组关联研究）的做法很朴素：

1. 招募很多人（几万到几十万）。
2. 测每个人基因组上几百万个 SNP，同时记录某个性状（例如 LDL 水平，或者有没有冠心病）。
3. 对每个 SNP 单独做一次回归：

```text
性状 ~ 效应等位基因个数（0、1、2） + 年龄 + 性别 + 祖源主成分 ……
```

几百万个 SNP 就做几百万次回归，每个 SNP 得到一行结果：beta、SE、p 等。这张"每个 SNP 一行"的表就是摘要统计（summary statistics）。真实研究还会用混合模型处理亲缘关系，但概念上就是"每个 SNP 一次回归"。第 7 章你会亲手做一个迷你版。

### 5.2 一行摘要统计长什么样

| 列 | 含义 | 例 |
|---|---|---|
| SNP | 位点编号 | rs_demo01 |
| effect allele（ea） | 效应等位基因，beta 说的是"多一个它"的作用 | G |
| other allele（oa） | 另一个字母 | A |
| EAF | 效应等位基因的频率 | 0.30 |
| beta | 每多一个效应等位基因，性状变化多少 | 0.200 |
| SE | beta 的标准误 | 0.010 |
| p | p 值 | 5.5e-89 |

### 5.3 beta 的单位决定了结果怎么读

- 连续性状（LDL、BMI）：beta 的单位就是性状的单位。很多 GWAS 先把性状标准化，beta 的单位是标准差（SD）。beta = 0.20 的意思是：每多一个效应等位基因，LDL 平均高 0.20 SD。
- 二分类性状（有没有冠心病）：用 logistic 回归，beta 是 log OR。beta = 0.074 的意思是：OR = e^0.074 = 1.077，每多一个效应等位基因，患病的 odds 高约 7.7%。
- MR 估计值的单位是"by 的单位 ÷ bx 的单位"。暴露是 SD、结局是 log OR 时，τ 的含义是"暴露每升高 1 SD，结局的 log OR 升高 τ"，OR = e^τ。

### 5.4 筛选工具变量的三件事

1. **显著：p 小于 5×10⁻⁸。** 人类基因组约有 100 万个相互独立的常见变异位置，0.05 ÷ 1,000,000 = 5×10⁻⁸，这是对多重检验的校正。
2. **独立：聚类。** 相邻 SNP 常常一起遗传，叫连锁不平衡（LD），相关程度用 r² 表示。同一片连锁区域里只留最强的一个，否则同一个信号被重复计算。TwoSampleMR 的默认是 r² 小于 0.001、窗口 10,000 kb。
3. **够硬：F = (beta ÷ SE)² 要大于 10。** 例：beta = 0.05、SE = 0.007，F = (0.05 ÷ 0.007)² = 51。F 小于 10 叫弱工具：两样本且样本不重叠时，估计会偏向 0。

### 5.5 两样本设计

两样本 MR 需要两份 GWAS：

- 暴露 GWAS，给出 bx 和 SE(bx)；
- 结局 GWAS，给出 by 和 SE(by)。

两份来自不同的人群，最好不重叠。优点是都可以用公开的大规模摘要统计，不需要个人数据。要求：祖源相同；样本基本不重叠；单位清楚。

常用的公开数据来源：OpenGWAS（https://opengwas.io）、GWAS Catalog（https://www.ebi.ac.uk/gwas）、FinnGen、Pan-UK Biobank，以及各疾病联盟的网站（血脂的 GLGC、BMI 的 GIANT、冠心病的 CARDIoGRAMplusC4D 等）。

### 5.6 最容易出错的一步：对齐等位基因

两份 GWAS 可能把同一个 SNP 的"效应等位基因"设成不同的字母。例：

| | 效应等位基因 | 另一个等位基因 | beta |
|---|---|---|---:|
| 暴露 GWAS | T | C | 0.080 |
| 结局 GWAS | C | T | −0.041 |

暴露表里的 beta 说的是"多一个 T"，结局表里的 beta 说的是"多一个 C"。必须统一成同一个字母。多一个 C 等于少一个 T，所以把结局的 beta 变号：−0.041 变成 +0.041。如果忘了，这个 SNP 的比值会从 +0.51 变成 −0.51。这正是第 8 章的 rs_demo04。

**回文 SNP。** 等位基因是 A/T 或 C/G 的 SNP。DNA 双链是互补的：一份 GWAS 在这条链上写 A/T，另一份在另一条链上写 T/A，光看字母分不清到底是"同一方向"还是"链不同"。办法是看 EAF：频率远离 0.5（例如 0.10 对 0.90）就能判断；频率接近 0.5（例如 0.47）就判断不了，通常直接删除。TwoSampleMR 默认这样处理。

**方向统一。** 做 MR-Egger 之前，要把所有 SNP 的方向统一成"bx 为正"，也就是效应等位基因都是让暴露升高的那个。IVW 不受这一步影响，Egger 受影响。第 8 章会演示。

### 小结

- GWAS 摘要统计就是"每个 SNP 一次回归"的结果表。
- 筛 SNP 的四件事：p 小于 5×10⁻⁸、聚类、F 大于 10、对齐等位基因。
- 对齐等位基因出错，符号会反，是最常见的数据错误。

## 6. ★ 有"后门"怎么办：异质性与敏感性分析

> 这一章带走什么：数据没法证明"没有后门"，但能检查"有没有迹象"；每种方法在押注什么；怎么避免挑结果。

### 6.1 一个事实

排他性（不走后门）无法被数据证明。能做的是换几种不同的假设重算一遍，看结论是否一致。这叫敏感性分析。

### 6.2 工具箱

| 方法 | 通俗比喻 | 它押注什么 | 它能抓住什么 |
|---|---|---|---|
| Q 和 I² | 看各 SNP 投票是否一致 | 无，只是检查 | 离群 SNP、普遍的不一致 |
| 留一法 | 每次请走一个 SNP，看结论变不变 | 无，只是检查 | 结论是否靠某一个 SNP |
| 加权中位数 | 按权重排队，取中间那个 | 至少一半的权重来自没有后门的 SNP | 少数离群或有后门的 SNP |
| 加权众数 | 看比值最集中的那座"山峰" | 最集中的一堆是没有后门的 SNP | 一部分 SNP 有后门，但好 SNP 彼此接近 |
| MR-Egger | 允许直线不过原点，截距是"平均后门" | 后门大小与 SNP 强度无关（InSIDE），且 SNP 强度差异足够大 | 方向一致的平均后门 |
| MR-PRESSO | 自动找出离群 SNP 并剔除重算 | 离群的是少数 | 个别明显离群的 SNP |
| Steiger 方向检验 | 检查箭头方向：SNP 解释 X 的方差是否大于解释 Y 的 | 两个性状都测得比较准 | SNP 其实是 Y 的工具 |
| 多变量 MR | 把可能的第二条路也放进模型 | 第二条路的性状有可用的 GWAS | 经已知中介或相关性状的后门 |
| 顺式 MR 加共定位 | 只用目标基因附近的 SNP，再确认信号来自同一个变异 | 该区域内没有别的因果基因 | 全基因组工具里广泛存在的后门 |

### 6.3 三个例子帮你记

- **加权中位数。** 第 8 章的 8 个 SNP 比值排队是 0.300、0.314、0.333、0.370、0.458、0.512、0.600、0.867，权重不同。按权重取中间，落在 0.37 附近。即使最右边的 0.867 变成 5，中位数也不会动。
- **Egger。** 把点画在 bx 对 by 的平面上。IVW 强制直线过原点，Egger 允许直线不过原点。截距明显不是 0，说明所有 SNP 平均有一个固定的偏移，也就是方向一致的后门。
- **留一法。** 从 8 个 SNP 里每次去掉 1 个，重算 IVW，看 8 个结果是否都差不多。去掉某个 SNP 后结果大变，说明结论依赖于它。

### 6.4 一个必须记住的警告

这些方法检查的都是"不一致"。如果后门对所有 SNP 都按比例存在（3.5 节），所有方法会一致地给出同一个错误答案。方法一致不等于正确，只能说"对被检查的这些失败方式不敏感"。

### 6.5 事先定好主分析

主分析在看结果之前就写好，通常是随机效应 IVW。其余方法是敏感性分析，用来回答"结论会不会因为某种后门而改变"。不要在四种方法里挑那个显著的写。

### 小结

- 数据证明不了"没有后门"，只能检查"有没有迹象"。
- 不同方法押注不同的假设，结果一致才更可信。
- 一致也不等于对：按比例的后门，所有方法一起错。

## 7. ★ 实战 0：自己造一个知道真相的世界，亲手跑迷你 GWAS

> 这一章带走什么：GWAS 就是每个 SNP 做一次回归；普通回归怎么被混杂带偏；MR 怎么找回真相；"后门"如何影响结果。全程只用基础 R，几秒钟跑完。

### 7.1 想法

真实研究里你永远不知道真相是多少，所以没法检验方法对不对。模拟的好处是真相是我们自己设的。

| 项目 | 设定 |
|---|---|
| 暴露 X | LDL，已标准化，单位 SD |
| 结局 Y | "冠心病风险得分"，连续变量，为了简单 |
| 真相 τ | LDL 每升高 1 SD，风险得分升高 0.30 |
| 混杂 U | 同时推高 LDL 和风险得分（各 0.8 的力度），分析时假装看不见 |
| 工具 | 20 个互相独立的 SNP，各自让 LDL 升高 0.06 到 0.16 SD |
| 样本 1 | 10 万人，用来做"暴露 GWAS" |
| 样本 2 | 另外 10 万人，用来做"结局 GWAS"，两样本设计，不重叠 |

### 7.2 代码

```r
set.seed(2026)

# ---------- 第 1 步：造一个“我知道真相”的世界 ----------
J     <- 20                        # 20 个 SNP
N1    <- 100000                    # 样本 1：用来做“暴露 GWAS”（测 LDL）
N2    <- 100000                    # 样本 2：另一批人，用来做“结局 GWAS”（测风险得分）
tau   <- 0.30                      # 真相：LDL 每升高 1 SD，风险得分升高 0.30
maf   <- runif(J, 0.15, 0.50)      # 每个 SNP 的等位基因频率
alpha <- runif(J, 0.06, 0.16)      # 每个 SNP 推动 LDL 的幅度（SD）

make_people <- function(n, back_door = rep(0, J)) {
  G <- sapply(maf, function(f) rbinom(n, 2, f))                    # 基因型 0/1/2
  U <- rnorm(n)                                                    # 看不见的混杂
  X <- as.vector(G %*% alpha) + 0.8 * U + rnorm(n)                 # LDL
  Y <- tau * X + 0.8 * U + as.vector(G %*% back_door) + rnorm(n)   # 风险得分
  list(G = G, X = X, Y = Y)
}

# ---------- 第 2 步：迷你 GWAS = 对每个 SNP 做一次回归 ----------
mini_gwas <- function(G, trait) {
  t(sapply(seq_len(ncol(G)), function(j) {
    s <- summary(lm(trait ~ G[, j]))$coefficients
    c(beta = s[2, 1], se = s[2, 2])
  }))
}

# ---------- 第 3 步：两样本 MR（IVW 和加权中位数） ----------
run_mr <- function(gx, gy) {
  bx <- gx[, "beta"]; sex <- gx[, "se"]; by <- gy[, "beta"]; sey <- gy[, "se"]
  ratio <- by / bx
  w     <- bx^2 / sey^2
  b_ivw <- sum(w * ratio) / sum(w)
  Q     <- sum(w * (ratio - b_ivw)^2)
  se    <- sqrt(1 / sum(w)) * sqrt(max(1, Q / (length(bx) - 1)))
  v2    <- sey^2 / bx^2 + by^2 * sex^2 / bx^4
  o <- order(ratio); r <- ratio[o]; ww <- (1 / v2)[o] / sum(1 / v2)
  s <- cumsum(ww) - 0.5 * ww; k <- max(which(s < 0.5))
  med <- r[k] + (r[k + 1] - r[k]) * (0.5 - s[k]) / (s[k + 1] - s[k])
  c(IVW = b_ivw, SE = se, Median = med, Q = Q)
}

# ---------- 第 4 步：样本 1 做暴露 GWAS ----------
s1     <- make_people(N1)
gwas_x <- mini_gwas(s1$G, s1$X)
data.frame(SNP = 1:J, beta = round(gwas_x[, "beta"], 3), se = round(gwas_x[, "se"], 3),
           p = signif(2 * pnorm(-abs(gwas_x[, "beta"] / gwas_x[, "se"])), 2))[1:4, ]
mean((gwas_x[, "beta"] / gwas_x[, "se"])^2)      # 平均 F

# ---------- 第 5 步：三个世界，各做一次结局 GWAS ----------
sA <- make_people(N2)                                        # A：没有后门
sB <- make_people(N2, c(rep(0.06, 6), rep(0, J - 6)))        # B：6 个 SNP 有后门，大小与强度无关
sC <- make_people(N2, 0.2 * alpha)                           # C：后门大小 = 0.2 倍的强度

coef(lm(sA$Y ~ sA$X))[2]                                     # 普通回归：样本 2 里直接 Y ~ X

res <- rbind(A = run_mr(gwas_x, mini_gwas(sA$G, sA$Y)),
             B = run_mr(gwas_x, mini_gwas(sB$G, sB$Y)),
             C = run_mr(gwas_x, mini_gwas(sC$G, sC$Y)))
round(res, 3)
```

### 7.3 结果与读法

迷你 GWAS 的输出（前 4 个 SNP）：

```text
  SNP  beta    se       p
1   1 0.091 0.006 6.8e-53
2   2 0.095 0.006 1.6e-53
3   3 0.085 0.007 1.3e-30
4   4 0.065 0.007 1.2e-21
[1] 224.273
```

这四行就是一份"摘要统计"最核心的样子：每个 SNP 一行，有 beta、SE、p。真实 GWAS 只是行数多得多，有几百万行。最后一行是 20 个 SNP 的平均 F，远大于 10。

直接做普通回归（在样本 2 里把 Y 回归到 X 上）：

```text
     sA$X 
0.6710483 
```

真相是 0.30，普通回归给出 0.67，偏高一倍多。原因是看不见的 U 同时推高了 LDL 和风险得分。

三个世界的 MR 结果：

```text
    IVW    SE Median       Q
A 0.291 0.019  0.275  23.310
B 0.441 0.066  0.284 286.133
C 0.494 0.024  0.472  38.339
```

| 世界 | 设定 | IVW | 加权中位数 | Q（df = 19） | 真相 |
|---|---|---:|---:|---:|---:|
| A | 没有后门 | 0.291 | 0.275 | 23.3 | 0.30 |
| B | 6 个 SNP 有后门，大小与强度无关 | 0.441 | 0.284 | 286.1 | 0.30 |
| C | 每个 SNP 的后门 = 0.2 倍强度 | 0.494 | 0.472 | 38.3 | 0.30 |

- **A：MR 找回了真相。** IVW = 0.291，95% 区间约 0.25 到 0.33，包含 0.30；普通回归是 0.67。MR 的价值就在这里：它绕开了看不见的 U。
- **B：IVW 被拉高到 0.441。** 后门是正的，把估计往上推。Q = 286 远大于 df = 19，明显报警。加权中位数 0.284 几乎没受影响，因为 6 个有后门的 SNP 只占总权重的约四分之一，不到一半。这就是"少数服从多数"。
- **C：所有方法一致地错。** IVW = 0.494，加权中位数 = 0.472，都偏离真相 0.30，大约高出 0.2，正好是后门比例系数。Q = 38.3，比 B 小得多。我换了几个随机种子重复，C 的 Q 多数落在 10 到 30 的正常范围里（这里的 38.3 是偏高的一次）。所以：方法一致、Q 不吓人，结论仍然可能是错的。

### 7.4 带走的三条

1. GWAS 摘要统计就是"每个 SNP 一次回归"的输出。
2. 混杂能让普通回归错得很多；MR 在假设成立时能纠正。
3. 少数 SNP 有后门时，中位数能救；所有 SNP 都有"按比例的后门"时谁也救不了，要靠设计：换工具、顺式 MR、共定位。

### 7.5 自己改改看

下面每一条我都实际改了参数跑过：

- 把 `tau` 改成 0。普通回归仍然给出约 0.37（纯粹来自混杂），IVW 约等于 0。
- 把 N2 改成 5000。IVW 的 SE 从约 0.02 变成约 0.08。
- 把 B 世界的后门改成正负各半：`c(rep(0.06, 3), rep(-0.06, 3), rep(0, J - 6))`。IVW 的偏差基本消失，但 Q 和 SE 变得很大。平衡的水平多效性不造成偏倚，只增加噪声。
- 把 C 世界的 `0.2 * alpha` 改成 `0.5 * alpha`。IVW 和中位数都变成约 0.83，也就是 τ 加上 0.5。

## 8. ★ 实战 1（主例题）：从两份 GWAS 摘要统计到 MR 结论

> 这一章带走什么：照着真实研究的流程，亲手做一遍两样本 MR：选工具、对齐等位基因、算 IVW、查异质性、做敏感性分析、写结果。数据是为教学构造的，不来自任何真实研究，所以每一步都有标准答案。

### 8.1 任务

估计 LDL 胆固醇每升高 1 SD 对冠心病的因果效应（OR），并判断结果是否可靠。

已知条件：

1. 暴露 GWAS（LDL）有 12 个候选 SNP，beta 的单位是 SD。
2. 结局 GWAS（冠心病）有 11 个 SNP，beta 的单位是 log OR。
3. 两份 GWAS 来自同一祖源，样本不重叠。
4. rs_demo10 与 rs_demo01 在同一片连锁区域（r² = 0.70）。

### 8.2 你拿到的两份表

下面的代码把两份表读进 R。先别看后面的答案，自己读一遍表。


5. 不能。理由有三：① Egger 检验功效低；② 它只检测"方向一致的平均后门"，而这里的问题是一个离群 SNP，不是系统性偏移；③ 它对第 3.5 节那种按比例的后门没有保护。这里真正有用的工具是 Q 的分解、留一法和中位数。
6. 如果不翻转，rs_demo04 的比值变成 −0.51，IVW 变成 0.406，SE 变成 0.124，Q 从 32 暴涨到 91。一个对齐错误就能让 Q 涨到近三倍。看到 Q 很大，先检查对齐。
7. 放进来后 IVW = 0.482，几乎不变（rs_demo09 的 F 只有 21，比值 0.33，权重只有 9）。但这样做不对：阈值要在看结果之前定好，不能因为"放进来也没事"就改阈值。
8. 示范写法见第 11 章。

## 11. ★ 怎么读结果、怎么写结果、常见错误

> 这一章带走什么：看到一组结果，怎么判断下一步；一段规范的结果怎么写；最常见的 12 个错误。

### 11.1 读结果的对照表

| 你看到的 | 通常意味着 | 下一步 |
|---|---|---|
| 各方法方向一致，Q 不大，留一法稳定 | 比较理想 | 报告，并写明仍无法证明排他性 |
| Q 很大，但中位数、众数与 IVW 接近 | 有异质性，但结论不靠离群点 | 用随机效应区间，报告敏感性结果 |
| IVW 显著，中位数不显著 | 可能靠少数强 SNP 或后门 | 看留一法、森林图，查那个 SNP 的生物学 |
| 去掉某个 SNP 后估计大变 | 结论靠这个 SNP | 解释这个 SNP（如 APOE 区域），分别报告 |
| Egger 截距明显偏离 0 | 方向一致的后门的迹象 | 以 Egger、中位数、众数为重点，谨慎表述 |
| 所有方法一致显著，但你怀疑有共同的后门 | 相关多效性的可能 | 顺式 MR、共定位、多变量 MR |
| IVW 不显著 | 不能证明"没有因果" | 看置信区间和功效，不要写"没有关系" |

### 11.2 示范：把第 8 章的结果写成一段话

> 以 LDL 为暴露、冠心病为结局做两样本 MR。经 p 小于 5×10⁻⁸、r² 聚类和等位基因协调，8 个独立 SNP 入选，平均 F = 161，合计解释约 4.5% 的 LDL 方差。随机效应 IVW 显示 LDL 每升高 1 SD，冠心病风险升高（OR 1.62，95% CI 1.40 到 1.87，p = 5.3×10⁻¹¹）。Cochran Q 提示显著异质性（Q = 32.3，df = 7，p = 3.6×10⁻⁵），其中 71% 来自 rs_demo07。加权中位数（OR 1.50）、MR-Egger（OR 1.70，截距 −0.005，p = 0.79）和加权众数（OR 1.46）方向一致。去掉 rs_demo07 后，IVW 为 OR 1.49（95% CI 1.38 到 1.60），异质性消失（Q = 4.2，p = 0.66）。结论：在 MR 假设成立的前提下，数据支持 LDL 升高增加冠心病风险，效应大小的合理范围是 OR 1.5 到 1.6，且对 rs_demo07 敏感。局限：排他性无法被证明；估计反映的是终身暴露差，不能直接外推为短期降脂治疗的效果。

### 11.3 常见 12 个错误

| 错误 | 后果 | 怎么避免 |
|---|---|---|
| 忘记对齐等位基因 | 符号错，Q 暴涨（第 8 章：32 变 91） | 用 harmonise；对照 EAF |
| 用了弱工具（F 小于 10） | 估计偏，区间不可靠 | 报告平均 F，去掉弱 SNP |
| 没聚类，相关 SNP 都放进来 | 标准误偏小 | r² 小于 0.001 |
| 暴露与结局样本大量重叠 | 估计偏向普通回归 | 选不重叠的数据，或做重叠校正 |
| 只报一种方法，或挑显著的方法 | 假阳性 | 事先指定主分析 |
| 把 Egger 截距不显著当成没有多效性 | 误判 | 它功效低，只检测方向一致的后门 |
| 只看 IVW 的 p 值，不看 Q 和留一法 | 被离群 SNP 带偏 | 全套诊断都要看 |
| 暴露 GWAS 调整过 BMI 等中介或对撞因子 | 工具的含义变了 | 看原始 GWAS 的协变量 |
| 混用不同祖源的 GWAS | 频率和连锁结构不同 | 同祖源 |
| 把二分类暴露当连续暴露解释 | 解释错 | 写成"易感性" |
| 把 MR 效应当成"吃药两年"的效果 | 估计目标不同 | 写"终身暴露差" |
| 写"证明了因果" | 过度表述 | 写"在所列假设下与因果效应一致" |

### 小结

- 先看 Q 和留一法，再看其他方法。
- 方法之间不一致时，写成"证据不稳"，并指出是哪个 SNP 或哪条通路在起作用。
- 措辞要克制："在所列假设下，估计与因果效应一致"。

## 12. ☆ 进阶话题

> 这一章带走什么：偏倚往哪个方向偏；独立性怎么失败；更多设计（多变量、中介、双向、非线性、顺式、共定位）；功效；报告规范；几个经典案例。

### 12.1 偏倚往哪个方向偏

写讨论时要写出"偏去哪一侧"，只说"有偏"不够用。

| 情形 | 点估计通常偏向 | 处理 |
|---|---|---|
| 单样本，工具弱 | 含混杂的普通回归 | 加强工具；个体数据里用 LIML |
| 两样本，无重叠，工具弱 | 0，也就是无效值 | 偏保守，仍要报告平均 F |
| 两样本，样本重叠，工具弱 | 普通回归 | 选不重叠的数据；重叠校正（如 MRlap） |
| 在估计 bx 的同一样本里挑选显著 SNP | 0（bx 被高估，比值缩小，叫赢家诅咒） | 三样本：发现、估计 bx、估计 by 各用独立样本 |
| MR-Egger 且 bx 有测量误差 | 0（斜率被稀释） | 先看 I²GX，低于约 0.9 不解释斜率 |
| 人群分层、参与者选择 | 可正可负 | 限制祖源；社会性状改做家系内设计 |
| 水平多效性且均值不为 0 | IVW 偏向多效性均值的方向 | 中位数、众数、顺式工具 |
| 垂直多效性 | 不是偏倚，估计的是总效应 | 只有问题是直接效应时才调整中介 |

### 12.2 独立性怎么失败

- **人群分层。** 等位基因频率随祖源变化，祖源又与环境和结局相关。主成分只能去掉一部分。限制在遗传上同质的祖源里做，是设计的一部分。
- **选型交配。** 教育、身高、BMI 在配偶之间相关，会让不同位点之间出现长程连锁，遗传相关和 MR 估计都会被抬高。
- **遗传养育。** 父母的基因型通过家庭环境改变子女表型。子女自己的等位基因并没有全部经由自身的暴露起作用（Kong 等，Science 2018）。教育、吸烟起始等社会性状的人群 MR 特别容易受影响。
- **家系内设计。** 同胞之间基因型的差异是随机的，用同胞差异做 MR，可以去掉上面这几种偏倚（Brumpton 等，Nat Commun 2020）。家系内估计若明显小于人群估计，优先怀疑人群分析的独立性。代价是有效样本量小，区间宽。
- **选择进入队列和生存。** 参与研究、活到老年本身与基因型有关。以此为条件会在基因型和结局之间打开一条只在样本内存在的通路。高龄结局、长寿的 MR 要特别注意。

### 12.3 更多设计

- **多变量 MR。** 同时放进多个暴露，估计各自的直接效应（第 10 章）。要报告条件 F。
- **两步中介。** 间接效应约等于两个 MR 系数的乘积：X 对 M 的 MR，乘上 M 对 Y 的 MR。M 的工具不能主要经由 X 起作用。
- **双向 MR。** 分别用 X 的工具和 Y 的工具做 X 对 Y、Y 对 X 两个方向。两边都显著，可能是真的双向，也可能是共同的多效性。
- **Steiger 方向检验。** 比较每个 SNP 对 X 和对 Y 解释的方差。解释 Y 更多的 SNP 更像 Y 的工具，要拿掉。测量误差大时会误判。
- **非线性 MR。** 问的是效应是否随暴露水平改变。不能按观察到的 X 分层再做 MR，因为 X 是基因和混杂的共同结果，按它分层会制造偏倚。可用的做法是按"去掉遗传预测之后的残差"分层。功效比线性 MR 低得多。
- **顺式 MR、药物靶点 MR。** 只用目标基因附近的变异（如 HMGCR、PCSK9）。适合蛋白、受体、药靶，排他性更干净，但仍是终身扰动。
- **共定位（coloc）、SMR 与 HEIDI。** MR 问效应多大，共定位问这一小段基因组里，暴露和结局是不是同一个因果变异。两个基因靠得很近、连锁在一起时，MR 可以显著，共定位却支持"两个不同的因果变异"，那就是邻居基因的效应。

### 12.4 终身效应与药物效应：LDL 的例子

遗传上 LDL 终身每低 1 mmol/L，冠心病风险约降低一半（Ference 等，JACC 2012）。他汀试验里每降 1 mmol/L，风险约降 20% 多（CTT，Lancet 2010）。两个数字都对，因为一个是终身暴露差，一个是中年之后几年的干预。MR 估计的是前者。

### 12.5 功效：粗略估算

```text
SE(τ) ≈ 1 ÷ √（结局样本量 × 工具解释的暴露方差 R²）
```

条件：暴露和结局都标准化，样本不重叠。这只是用来判断数量级的近似。

- R² = 2%，结局样本 10 万：SE ≈ 1 ÷ √2000 = 0.022。每个 SD 0.05 的效应有机会被分辨出来。
- R² = 0.2%，结局样本 1 万：SE ≈ 1 ÷ √20 = 0.22。只有很大的效应才出得了窄区间。

瓶颈几乎总是"工具解释的方差"和"结局样本量"，不是暴露 GWAS 的 p 值有多小。二分类结局要看病例数，不是总人数。

区间很窄且覆盖 0，才是对"较大效应"的否定。区间既盖住重要的获益、又盖住重要的危害，结论是精度不够。

### 12.6 报告规范

按 STROBE-MR（Skrivankova 等，JAMA 与 BMJ，2021）。最低限度包括：

- 因果句子和估计目标：人群、单位、总效应还是直接效应、终身还是短期；
- 两个 GWAS 的人群、祖源、样本量、重叠；
- SNP 从多少变到多少，聚类、代理、回文各删了几个；
- R² 与平均 F，多变量还要条件 F；
- 事先指定的主分析；
- Q、I²、Egger 截距、留一法；
- 散点、漏斗、森林图；
- 哪一条假设最可疑。

### 12.7 几个经典案例

- **APOE 与胆固醇（Katan，1986）。** 反向因果问题最早的基因解法。
- **PCSK9。** 功能缺失变异降低 LDL，也降低冠心病（Cohen 等，NEJM 2006）。后来的药物试验出现在这种遗传证据之后。
- **HDL。** 观察性关联很强，但用遗传工具把 HDL 与其他脂蛋白分开之后，HDL 本身并不呈现观察性数据所暗示的保护（Voight 等，Lancet 2012）。第 10 章你已经看到了类似的现象。
- **CRP。** CRP 基因附近、改变 CRP 蛋白本身的变异，并不带来冠心病风险的升高（Elliott 等，JAMA 2009；CCGC，BMJ 2011）。全基因组的 CRP 工具则混入了上游的肥胖和炎症。同一个测量值，两套工具，两个参数。
- **IL-6 受体。** 与受体阻断方向一致的变异，冠心病风险下降，同时感染相关表型增加（IL6R MR 合作组，Lancet 2012）。
- **酒精。** 观察性曲线常呈 J 型。以乙醇脱氢酶位点为工具的分析不支持"少量饮酒保护心血管"（Holmes 等，BMJ 2014；中国人群 Millwood 等，Lancet 2019）。

## 13. ☆ 接到本仓库的代谢物研究

> 这一章带走什么：本仓库已有的四类分析怎么对接到 MR；13,512 人的样本能做什么、不能做什么；代谢物研究特有的几个坑。

本仓库做的是四件事：单个代谢物与死亡、长寿的关联（代谢组范围关联），代谢物集合富集（MSEA），WGCNA 模块，以及预测全因死亡的弹性网络评分。样本是 13,512 人的前瞻性随访。它们回答的是"哪些测量值与死亡一起变化"和"一组测量值能把风险预测到什么程度"。要接上 MR，需要把"暴露"重新定义成"能被基因变异推动的生物量"。

### 13.1 13,512 人能做什么、不能做什么

- 适合：发现观察性信号。
- 不适合：在这批人里自己找工具变量，再在同一批人里检验死亡。这个样本量下能超过 5×10⁻⁸ 的代谢物位点很少，赢家诅咒会很大，弱工具又会把估计拉向含混杂的观察性关联。
- 做法：工具来自独立且更大的代谢组 GWAS；结局来自独立的死亡或寿命 GWAS；两边祖源一致、样本尽量不重叠。

### 13.2 代谢物位点高度共享

FADS、GCKR、LPL、APOE 这类区域会同时推动几十个代谢物。"一百个代谢物都显著"可能只是同一条通路被重复计数。单变量 MR 估计的是"这个测量值所代表的整条遗传通路"的总效应。

要写成"就是这一个代谢物，把其他相关代谢物按住以后仍然有效"，需要多变量 MR，并报告条件 F。条件 F 很低时，说明这些代谢物在遗传上分不开，结论就停在"这一簇"。

### 13.3 四类分析怎么对接

| 已有分析 | 它回答了什么 | 要接 MR，暴露应改写成 |
|---|---|---|
| 单个代谢物与死亡、长寿 | 这个测量值是否与结局一起变化 | 一个有外部工具的代谢物；写明是总效应，还是按住相关代谢物后的直接效应 |
| 代谢物集合富集（MSEA） | 一类已知通路是否整体相关 | 集合若对应一条有顺式基因的通路，就用那条通路的工具；否则拆回成员，逐个做 |
| WGCNA 模块 | 数据驱动的一簇代谢物是否相关 | 看成员各自的 MR 是否方向一致、是否由少数共享位点主导；模块特征向量本身没有现成的 GWAS，不能直接当暴露 |
| 弹性网络死亡评分 | 一组权重的预测能力 | 权重是为预测死亡而估计的，不适合当暴露；它的用处是生成假说：看高权重代谢物各自的 MR |

### 13.4 死亡和长寿的特殊问题

- **选择。** 活到采血、完成随访的人，早期致死因素已经作用过。影响早死的基因型在老年样本里变少。
- **APOE。** 寿命 GWAS 对 APOE 极其敏感。代谢物若主要通过脂蛋白通路与死亡关联，要事先规定 APOE 区域保留还是排除，并报告留一法。
- **长寿的定义。** 若定义在"活到高龄的人"上，估计还条件在生存上，与全因死亡风险不是同一个参数。

### 13.5 平台与单位

不同平台的单位不一样：核磁共振的绝对浓度、质谱的相对定量、GWAS 里的标准差。先把 bx 和 by 的单位统一，再谈效应大小。

比值型代谢物（例如两种脂肪酸之比）在 FADS 等酶基因附近常有很强的顺式工具。它更接近"酶活性"，目标参数也就变成了这个比值，不再是其中某一个绝对浓度。

### 13.6 建议的顺序

1. 从本仓库的代谢组范围关联结果里，按事先写好的标准挑出要检验的代谢物。
2. 为每个代谢物找独立的代谢组 GWAS。
3. 按第 5 章的流程选工具：p、聚类、F、对齐。
4. 结局用独立的死亡或寿命 GWAS。
5. 主分析 IVW，配第 6 章的敏感性分析。
6. 对共享位点区域（FADS、GCKR、LPL、APOE）做留一法，并考虑多变量 MR。
7. 加阳性对照：已知的脂蛋白工具对冠心病、BMI 工具对 2 型糖尿病，流程应当复现文献里的方向。复现不出来时，先查等位基因和单位。

## 14. ★ 自测题

先自己答，再看后面的答案。

1. 为什么 MR 能避开混杂？
2. 三条假设是什么？哪条能用数据检验？
3. 某 SNP 的 bx = 0.2（LDL，SD），by = 0.06（冠心病，log OR）。因果估计是多少？OR 是多少？
4. 这个 SNP 若有 π = 0.02 的后门，估计会变成多少？
5. IVW 的权重怎么算？为什么 bx 大的 SNP 权重大？
6. 8 个 SNP 的 Q = 32，df = 7，说明什么？下一步做什么？
7. 一个 SNP 的 F = 6，怎么办？
8. 为什么要对齐等位基因？忘了会怎样？
9. 加权中位数要求什么？比 IVW 好在哪里？
10. Egger 截距不显著，能说没有多效性吗？
11. 为什么 MR 的效应不能直接说成"吃药两年"的效果？
12. 各方法一致、Q 也正常，结论一定对吗？

### 参考答案

1. 基因变异是受孕时随机分配的，与生活方式等混杂因素无关。比较"带 A 的人"和"带 G 的人"时，混杂在两组里平均是一样的。
2. 够硬（相关性）、公平（独立性）、不走后门（排他性）。只有"够硬"能直接用数据检验（p 值、F 统计量）。
3. 0.06 ÷ 0.2 = 0.30；OR = e^0.30 = 1.35。
4. 0.30 + 0.02 ÷ 0.2 = 0.40。
5. 权重 = bx² ÷ SE(by)²，是比值方差 SE(by)² ÷ bx² 的倒数。bx 大，比值的方差小，更可信，所以权重大。
6. 各 SNP 的估计明显不一致。先检查等位基因对齐；再把 Q 分解到每个 SNP，找出贡献最大的；做留一法、加权中位数、加权众数；报告随机效应区间。
7. 这是弱工具。不选它，或者用对弱工具稳健的方法。不能靠大样本救。
8. 两份 GWAS 的效应等位基因可能相反。忘了翻转，该 SNP 的比值符号会反，Q 会暴涨（第 8 章 rs_demo04：Q 从 32 变成 91）。
9. 至少一半的权重来自没有后门的 SNP。少数有后门的 SNP 不会拉动中位数，而 IVW 会被拉动。
10. 不能。Egger 检验功效低；它只检测方向一致的平均后门；对单个离群 SNP 或按比例的后门没有保护。
11. 遗传变异的作用是终身的，包括发育期。MR 估计的是终身暴露差的效应，不是中年之后几年干预的效果。
12. 不一定。后门的大小若与 SNP 强度成比例（相关多效性），所有方法会一致地偏（第 7 章情形 C）。要靠设计：顺式 MR、共定位、多变量 MR、家系内设计。

## 15. ★ 一页速查卡

**一句话。** 单个 SNP：τ = by ÷ bx。多个 SNP：IVW，权重 bx² ÷ SE(by)²。

**三条假设。** 够硬（相关性）、公平（独立性）、不走后门（排他性）。

**12 步流程。**

1. 写清问题：人群、暴露单位、总效应还是直接效应。
2. 画因果图，标出中介、对撞、已知的多效性。
3. 选暴露 GWAS 和结局 GWAS：祖源一致，样本不重叠。
4. 筛 SNP：p 小于 5×10⁻⁸，聚类 r² 小于 0.001、窗口 10 Mb。
5. 算 F 和 R²：平均 F 要大于 10。
6. 与结局取交集，协调等位基因，处理回文 SNP。
7. 主分析：随机效应 IVW。
8. 看 Q、I²、留一法。
9. 敏感性分析：加权中位数、加权众数、Egger（先看 I²GX）、PRESSO。
10. 必要时：Steiger 方向、多变量 MR、顺式 MR、共定位。
11. 画图：散点、森林、漏斗、留一法。
12. 按 STROBE-MR 报告，写明最可疑的假设。

**数字速记。**

| 项目 | 数字 |
|---|---|
| 全基因组显著 | p 小于 5×10⁻⁸ |
| 聚类 | r² 小于 0.001，窗口 10 Mb |
| 工具强度 | F 大于 10 |
| 一致性 | Q 约等于 df |
| Egger 可用 | I²GX 大于 0.9 |
| 多变量 MR | 看条件 F |

**措辞。** 在所列假设下，估计与因果效应一致。

## 附录 A　公式推导

> 这一部分是严格推导，第一遍可以跳过。

### A.1 模型

```text
X = α0 + α G + δ U + ν
Y = β0 + τ X + γ U + ε
```

X 是暴露，Y 是结局，G 是遗传工具，U 是混杂。α 是工具对暴露的效应（也就是 bx 的真值），τ 是要估计的因果效应，δ、γ 是混杂对 X、Y 的作用，ν、ε 是剩余的随机变异。

### A.2 没有后门时

假设 G 与 U、ν、ε 都独立，α 不为 0，且 Y 的方程里没有 G 的项。则：

```text
Cov(G, X) = α Var(G) + δ Cov(G, U) + Cov(G, ν) = α Var(G)
Cov(G, Y) = τ Cov(G, X) + γ Cov(G, U) + Cov(G, ε) = τ α Var(G)
```

两式相除，Var(G) 和 α 都约掉：

```text
τ = Cov(G, Y) ÷ Cov(G, X)
```

样本里用两个回归系数之比：τ̂ = by ÷ bx。

### A.3 有后门时

若 G 对 Y 还有直接作用 π，即 Y = β0 + τ X + π G + γ U + ε，则：

```text
Cov(G, Y) = (τ α + π) Var(G)
比值 = (τ α + π) ÷ α = τ + π ÷ α
```

### A.4 后门与强度成比例

若 π = κ α，则：

```text
比值 = τ + κ
```

κ 不随工具变强而消失。再大的 GWAS、再小的标准误，也消不掉它。

### A.5 为什么普通回归有偏

```text
Cov(X, Y) = τ Var(X) + γ δ Var(U)
普通回归的斜率 = Cov(X, Y) ÷ Var(X) = τ + γ δ Var(U) ÷ Var(X)
```

第 7 章里 γ = δ = 0.8，Var(U) = 1，Var(X) 约 1.72，偏差约为 0.64 ÷ 1.72 = 0.37，与 0.671 − 0.30 = 0.371 吻合。

### A.6 异质效应

若每个人的因果效应不同，Wald 比值识别的是按"工具把每个人的暴露推动了多少"加权的平均效应。二分类暴露加单调性（没有被工具往反方向推的人）时，对应的是局部平均处理效应。多个 SNP 时，IVW 是各自局部效应的加权，不同 SNP 推动的不是同一群人。

## 附录 B　公式一览

```text
Wald 比值       θj = βYj ÷ βXj
比值的标准误    SE(θj) ≈ SEYj ÷ |βXj|
                （把 βX 的误差也算进去：SEYj² ÷ βXj² + βYj² × SEXj² ÷ βXj⁴ 的平方根）
IVW 权重        wj = βXj² ÷ SEYj²
IVW 估计        θIVW = Σ wj θj ÷ Σ wj
固定效应 SE     1 ÷ √(Σ wj)
Cochran Q       Q = Σ wj (θj − θIVW)²，自由度 df = J − 1
I²              (Q − df) ÷ Q，Q 不大于 df 时记 0
随机效应 SE     固定效应 SE × √(max(1, Q ÷ df))
F 统计量        F = (βX ÷ SEX)²
R²（标准化）    Σ 2 f (1 − f) βX²，f 是效应等位基因频率
Egger 回归      βY = a + θ βX，权重 1 ÷ SEY²，a 是截距
功效（粗略）    SE(θ) ≈ 1 ÷ √(N结局 × R²)
```

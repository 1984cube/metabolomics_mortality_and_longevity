# 01 · CHIP 与 VAF：数据从哪来

> 这一章带走什么：CHIP 是什么；VAF 怎么换算成"克隆有多大"；测序深度怎样决定你能不能看见小克隆；为什么单细胞数据里"带突变的细胞"很少。

### 2.1 CHIP 是什么

造血干细胞在人的一生中会积累体细胞突变。偶尔某个突变让这个干细胞获得生长优势，它的后代就会占据血细胞的一部分，形成一个"克隆"。如果这个人没有血液肿瘤，这种状态叫 CHIP。

三件事要记住：

- 发生率随年龄明显上升；
- 最常见的驱动基因是 DNMT3A、TET2、ASXL1；
- 克隆越大，对心血管等结局的影响通常越明显（报告提到已有研究显示大克隆的心血管风险更高，但这一分层在骨这一侧还没有人做过）。

### 2.2 VAF 怎么读

VAF = 支持突变的读段数 ÷ 覆盖该位点的总读段数。

对常染色体上的杂合突变，每个带突变的细胞只有一半的拷贝是突变的，所以：

```text
带突变的细胞比例 = 2 × VAF
```

```r
# 常染色体上的杂合体细胞突变：VAF 约等于“带突变的细胞比例”的一半
vaf <- c(0.02, 0.05, 0.10, 0.20)
data.frame(VAF = vaf, 带突变的细胞比例 = 2 * vaf)
```

```text
   VAF 带突变的细胞比例
1 0.02             0.04
2 0.05             0.10
3 0.10             0.20
4 0.20             0.40
```

所以报告里的"大克隆（VAF 不低于 0.1）"，意思是至少约 20% 的血细胞带这个突变。

### 2.3 VAF 的不确定性

VAF 是读段数的比例，读段数有限，所以有误差。例：100 条读段里有 12 条支持突变。

```r
alt <- 12; depth <- 100
c(VAF = alt / depth)
round(as.numeric(binom.test(alt, depth)$conf.int), 3)      # 精确二项 95% 区间
```

```text
 VAF 
0.12 
[1] 0.064 0.200
```

VAF = 0.12，精确二项 95% 区间是 0.064 到 0.200。单个样本的 VAF 在深度只有 100 左右时误差不小，所以按 VAF 是否不低于 0.1 来分大小克隆时，靠近 0.1 的样本分类本身就不稳。

### 2.4 能不能看见小克隆：测序深度

一个突变要被"检出"，通常要求至少有几条支持读段。下面假设至少 4 条（真实流程的阈值以原文为准）。

```r
# 假设：至少 4 条支持突变的读段才算检出（真实流程的阈值以原文为准）
detect_prob <- function(vaf, depth, k = 4) 1 - pbinom(k - 1, depth, vaf)
vafs <- c(0.01, 0.02, 0.05, 0.10)
depths <- c(30, 60, 100, 200)
tab <- outer(vafs, depths, detect_prob)
dimnames(tab) <- list(paste0("VAF=", vafs), paste0("深度", depths, "x"))
round(tab, 3)
```

```text
         深度30x 深度60x 深度100x 深度200x
VAF=0.01   0.000   0.003    0.018    0.142
VAF=0.02   0.003   0.032    0.141    0.569
VAF=0.05   0.061   0.353    0.742    0.991
VAF=0.1    0.353   0.863    0.992    1.000
```

读法：

- 深度 30x 时，VAF = 0.05 的克隆只有 6% 的机会被检出，VAF = 0.1 也只有 35%。
- 深度 100x 时，VAF = 0.05 约 74%，VAF = 0.02 只有 14%。
- 也就是说，**外显子测序对小克隆不敏感**，所谓"小克隆"在数据里是被截尾的。这也是为什么 CHIP 研究都有一个 VAF 下限（常用 2%），以及为什么"携带者 vs 非携带者"里的"非携带者"其实混着一些没被看见的小克隆携带者。

### 2.5 从外显子"调用"CHIP 的流程（概念）

报告说，UK Biobank 已在 2025 年 8 月发布了 CHIP 衍生字段（30106 是变异，30107 是 VAF），所以不需要自己调用。了解流程有助于理解这些字段的含义：

1. 用体细胞突变检出工具（如 Mutect2）在外显子数据上检出突变；
2. 只保留一份已知造血驱动基因清单里的位点；
3. 按读段数、深度、已知热点、人群频率等过滤，排除胚系变异；
4. 保留 VAF 不低于阈值的突变，记录基因和 VAF。

报告说这套流程按 Vlasschaert 等 2023 年发表在 Blood 上的方法整理。具体阈值和基因清单以原文为准。

### 2.6 单细胞数据里的"突变细胞"为什么很少

假设每个供体取 2,800 个细胞（报告里 CNGB TrueBlood 数据约 6.7 万细胞、24 个供体，平均约 2,800）。要在单个细胞的读段里"看到"突变位点，需要这个细胞恰好测到了那个位点，这一比例通常很低。下面假设 20%：

```r
# 单细胞数据里：每个供体约 2,800 个细胞（报告：约 6.7 万细胞 / 24 个供体）
cells <- 2800
eff   <- 0.2        # 假设：能在单个细胞的读段里读到突变位点的比例
vaf   <- c(0.02, 0.05, 0.10)
data.frame(VAF = vaf, 预期能确认带突变的细胞数 = round(cells * 2 * vaf * eff))
```

```text
   VAF 预期能确认带突变的细胞数
1 0.02                       22
2 0.05                       56
3 0.10                      112
```

VAF = 0.05 的克隆，一个供体里能直接确认带突变的细胞大约只有 56 个。所以报告说"以携带者 vs 对照为主，突变细胞标注作辅助"是有道理的：分析的主单位是供体，细胞层面的突变标注只做补充。

### 小结

- 带突变的细胞比例约等于 2 × VAF；大克隆（VAF 不低于 0.1）至少约 20% 的血细胞。
- 外显子深度有限，小克隆会被漏掉；"非携带者"里混着看不见的小克隆。
- 单细胞里能确认带突变的细胞很少，分析要以供体为单位。
